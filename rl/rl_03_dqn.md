# RL #3：值函数近似与 DQN 深度探索

> 前两课我们学会了基于**表格**的 RL 方法（Q-Table、SARSA、TD(λ)）。但当状态空间大到天文数字——比如围棋 (10¹⁷⁰ 种状态) 或连续控制（无穷多状态）——表格就不可能了。这一课我们用**函数近似**突围，最终走向 **Deep Q-Network (DQN)**，理解它在 Atari 游戏上的革命性突破。

---

## 1. 为什么表格方法行不通

### 1.1 维度灾难

| 问题域 | 状态数 | Q-Table 大小 |
|--------|--------|------------|
| 10×10 网格 | 100 | 几百条目 ✅ |
| 围棋 | ~10¹⁷⁰ | 宇宙中每个原子都存不下 ❌ |
| 连续控制（机器人） | ∞ | 不可能 ❌ |
| Atari 游戏（128×128 像素 ×4 帧） | ~256⁶⁵⁵³⁶ | 不可能 ❌ |

### 1.2 泛化能力缺失

表格方法的致命伤：**从未见过的状态 → 0 信息**。而函数近似可以学习和泛化——如果状态 A 和状态 B 相似，它们的 Q 值也应该相似。

**类比**：人类不需要玩过所有关卡的 Super Mario 才能通关，因为学会了「跳跃避开敌人」的模式，可以泛化到任何关卡。

## 2. 值函数近似：从表格到函数

### 2.1 基本思想

用参数化的函数 $Q(s, a; \theta)$ 来近似真实 Q 值：

$$Q(s, a) \approx Q(s, a; \theta)$$

两种函数形式：
1. **线性近似**：$Q(s, a) = w^T \cdot \phi(s, a)$ — 需要手工提取特征 $\phi$
2. **非线性近似**（神经网络）：$Q(s, a; \theta)$ — 自动学习特征表示

### 2.2 监督学习的视角

值函数近似本质上是一个**回归问题**：给定 $(s,a)$，训练模型预测 Q 值。

训练目标（最小化 Bellman 误差）：

$$\mathcal{L}(\theta) = \mathbb{E}_{(s, a, r, s')} \left[ \left( r + \gamma \max_{a'} Q(s', a'; \theta^-) - Q(s, a; \theta) \right)^2 \right]$$

- **TD Target**（监督标签）：$r + \gamma \max_{a'} Q(s', a'; \theta^-)$
- **当前预测**：$Q(s, a; \theta)$
- **关键**：$\theta^-$ 是**目标网络**的参数，每 N 步从 $\theta$ 复制一次（后面解释为什么要这么做）

### 2.3 收敛性问题

线性近似有理论收敛保证（在特定条件下），但神经网络函数近似带来了三个核心挑战：

| 问题 | 原因 | 后果 |
|------|------|------|
| **样本相关性** | 连续 time step 的状态高度相关 | 梯度更新方差大，训练不稳定 |
| **非平稳目标** | TD target 依赖当前参数 $\theta$ | 监督信号在移动，打靶的靶子在动 |
| **探索-利用平衡** | 需要同时收集数据和优化策略 | 行为策略和数据分布相互影响 |

这就是为什么 DQN 不是一个简单的「Q-Learning + 神经网络」，而需要一系列精巧的设计来解决上述问题。

---

## 3. Deep Q-Network (DQN) — 三大突破

### 3.1 经验回放 (Experience Replay)

**解决的问题**：样本相关性和数据利用率低

**做法**：
- 把智能体的经验 $(s, a, r, s', done)$ 存入**回放缓冲区**（Replay Buffer）
- 训练时从缓冲区**随机采样**一个小批量（Mini-Batch）

**效果**：
- ✅ 打破样本相关性 → 降低方差
- ✅ 提高数据利用率 → 一条经验用多次
- ✅ 避免灾难性遗忘 → 旧经验也能复习

```
缓冲区大小：通常 1M 条经验
采样批量：32-64
采样方式：均匀随机（或带优先级的）
```

### 3.2 目标网络 (Target Network)

**解决的问题**：非平稳目标（Bellman target 随 $\theta$ 变化）

**做法**：
- 维护**两套**网络参数：$\theta$（在线网络）、$\theta^-$（目标网络）
- $\theta$ 每步更新，$\theta^-$ 每 N 步从 $\theta$ 复制
- 计算 TD target 时使用 $\theta^-$（锁定靶子）

```
TD Target = r + γ · max_a' Q(s', a'; θ⁻)   ← 目标网络，不动
当前预测 = Q(s, a; θ)                       ← 在线网络，更新
损失 = MSE(TD Target - 当前预测)
```

**效果**：训练稳定性大幅提升，能收敛到更好的策略。

### 3.3 梯度裁剪 (Gradient Clipping)

将梯度限制在 $[-1, 1]$ 范围内，防止 Q 值发生剧烈震荡导致梯度爆炸。

## 4. DQN 训练算法（伪代码）

```
初始化 在线网络 Q(s,a;θ)
初始化 目标网络 Q(s,a;θ⁻)，θ⁻ = θ
初始化 回放缓冲区 D，容量 N

FOR episode = 1 to M:
    初始化环境，获取初始状态 s
    FOR step = 1 to T:
        # ε-贪心探索
        IF random() < ε:
            a = 随机动作
        ELSE:
            a = argmax_a Q(s,a;θ)       # 当前策略
        
        # 执行动作，收集经验
        执行 a → 得到 r, s'
        存入 D: (s, a, r, s', done)
        
        # 每 C 步更新一次（不是每步都训）
        IF 已收集够批量:
            # 1. 从 D 随机采样 batch
            batch = D.sample(batch_size)
            
            # 2. 计算目标 Q 值（用目标网络！）
            y_i = r_i + γ · max_a' Q(s'_i, a'_i; θ⁻)   # 非终止状态
            y_i = r_i                                   # 终止状态
            
            # 3. 梯度下降（最小化 MSE）
            loss = (y_i - Q(s_i, a_i; θ))²
            θ ← θ + α · ∇loss
        
        # 每 N 步同步目标网络
        IF step % N == 0:
            θ⁻ = θ
        
        # 衰减 ε
        ε = max(ε_min, ε · ε_decay)
        
        s = s'
```

### 核心参数

| 参数 | 典型值 | 作用 |
|------|--------|------|
| Replay Buffer 容量 | 1,000,000 | 存储多少历史经验 |
| Batch Size | 32 | 每次采样多少条 |
| Target Network 更新频率 | 10,000 步 | 多久同步一次目标网络 |
| ε 起始值 | 1.0 | 初始全探索 |
| ε 终值 | 0.01 | 后期几乎全利用 |
| ε 衰减 | 0.999/ep | 探索率衰减速度 |
| 折扣因子 γ | 0.99 | 重视近期 vs 远期奖励 |
| 学习率 α | 0.00025 (Adam) | 优化器步长 |

## 5. DQN 的改进版本

### 5.1 Double DQN (DDQN)

**问题**：标准 DQN 的 $\max_{a'} Q(s', a'; \theta^-)$ 会**高估** Q 值——因为取 max 天然倾向于高估噪声较大的动作。

**解决**：用**在线网络**选动作，用**目标网络**做评估：

$$y_i = r_i + \gamma \cdot Q(s', \arg\max_{a'} Q(s', a'; \theta); \theta^-)$$

- 选动作：$a^* = \arg\max_{a'} Q(s', a'; \theta)$（在线网络）
- 评估：$Q(s', a^*; \theta^-)$（目标网络）

**效果**：减少 Q 值高估，学习更稳定。

### 5.2 Prioritized Experience Replay (PER)

**问题**：均匀采样浪费——有些经验（如意外拿到高分）比普通经验更有价值。

**解决**：按 TD 误差的绝对值给每条经验打分，采样时用重要性权重：

$$P(i) \propto |\delta_i| + \epsilon$$

其中 $\delta_i = y_i - Q(s_i, a_i; \theta)$ 是 TD 误差。

**效果**：训练加速 2-3 倍。

### 5.3 Dueling DQN

**思想**：将 Q(s, a) 拆分为**状态价值** V(s) 和**动作优势** A(s, a)：

$$Q(s, a) = V(s) + A(s, a)$$

- **V 流**：学习「这个状态本身好不好」（不依赖于动作）
- **A 流**：学习「选这个动作比平均值好多少」（动作间的相对好坏）

**结构**：同一个神经网络提取特征后分叉为两条路径。

**直觉**：在很多状态下，选什么动作不重要（空旷的路中间），而有的状态下动作选择决定生死（弯道超车）。Dueling 让网络学会专注于真正差异化的东西。

### 5.4 Noisy DQN

**解决**：用**参数噪声**替代 ε-贪心探索，让智能体在状态空间的探索更有目的性。

将网络权重改为 $\theta + \sigma \cdot \epsilon$，其中 $\epsilon$ 是随机噪声（训练时可学习噪声幅度 $\sigma$）。

**效果**：探索更有针对性，后期也能保持一定探索。

## 6. DQN 的 Atari 实验

### 6.1 实验设置

- **环境**：49 款 Atari 2600 游戏（Arcade Learning Environment）
- **输入**：4 帧最近游戏的堆叠（84×84 灰度图）
- **网络**：3 层卷积 + 2 层全连接
- **训练**：每个游戏 2 亿帧（约 7-10 天 GPU）

### 6.2 关键结果

| 游戏 | 人类水平 | DQN | 说明 |
|------|---------|-----|------|
| Breakout | 31 分 | **401** 🏆 | 学会挖隧道策略 |
| Pong | 14.5 分 | **20** 🏆 | 完胜的对手（左墙反弹法） |
| Space Invaders | 1,403 分 | **1,689** 🏆 | 优先消灭底排 |
| Seaquest | - | - | 低于人类（记忆密集型） |
| Montezuma's Revenge | **4,753** | 0 ❌ | 稀疏奖励，完全不会 |

### 6.3 涌现行为

DQN 在 Breakout 中自己发现了**挖隧道（tunneling）** 策略：
1. 第一阶段：简单挡球 → 随机移动
2. 第二阶段：学会移动到球落点 → 准确挡球
3. 第三阶段：**把砖墙边缘打出缺口，让球飞到砖墙后面** → 从背面消灭多层砖块

这是纯从奖励信号（+1 分）中**涌现**出的高级策略，没有人告诉它这么做。

**这个发现的意义**：Agent 不只是在记忆最佳路径，它在**学习环境的内在物理规律**。

## 7. 我们自己的 DQN 实验回顾

我们已经跑过 3 轮 DQN 版本的回测：

| 版本 | 架构 | 超额收益 | 最大回撤 |
|------|------|---------|---------|
| DQN v1 | 3层MLP(128→128→3) | **+9.19%** | -12.0% |
| LSTM+DQN v2 | LSTM(64h) + DQN | **+18.22%** | -12.4% |
| RL v3 TD(λ=0.3) | 资格迹 | **+35.91%** | -2.5% ✅ |

**一个有趣的发现**：在量化交易这个连续动作空间上（买入/持有/卖出），非 DQN 的 TD(λ) 反而表现最好。这是因为：

1. **动作空间小**（3 个离散动作）→ 不需要 DQN 的高维逼近能力
2. **时间关联性强** → 资格迹的「跨时间步 credit assignment」非常合适
3. **参数稀疏**（25 个离散状态 vs DQN 数万参数）→ 不易过拟合

**启示**：DQN 真正发光的地方是**视觉输入**（Atari 像素→策略）和**高维状态**（机器人传感器），而不是每个场景都适合。
