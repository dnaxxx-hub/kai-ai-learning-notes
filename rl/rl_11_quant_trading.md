# RL #11：强化学习在量化交易中的应用

> 开发日期：2026-05-12~14
> 前置知识：DQN、策略梯度、TD(lambda)、量化交易基础

## 动机

传统的量化策略（MA金叉、RSI超买超卖、布林带反转等）都是基于固定规则的。市场状态变化时，规则需要人工调整。强化学习让 Agent **自主发现交易规律**，适应市场变化。

## 三种 RL 交易方案

### 方案1：DQN v1（简单MLP，3层）

```
[价格+指标特征] → [FC128] → [FC64] → [FC3(动作)] 
```

- **状态空间**：close, ma5, ma10, ma20, rsi, kdj_k, kdj_d, macd_dif, macd_dea, macd_bar（10维）— 归一化到 [-1, 1]
- **动作空间**：3个 — 买入、卖出、持有
- **奖励**：每次交易后结算：
  - 买入：不收reward
  - 卖出：reward = (卖出价 - 买入价) × 手数
  - 持有：reward = 0
- **结果**：超额 +9.19%（50→80 episodes 后学会克制交易）
- **关键发现**：早期 episode 频繁交易亏钱，训练后期学会等待、减少操作

### 方案2：LSTM+DQN v2

```
[历史N日特征] → [LSTM(64)] → [FC32] → [FC3(动作)]
```

- 改进点：LSTM 捕捉时间序列模式（趋势、反转）
- **结果**：超额 **+18.22%**，回撤 12.4%（DQN v1 的2倍表现）
- 关键：LSTM 让 Agent 意识到"趋势中持有比短线交易更好"

### 方案3：RL v3 — TD(lambda) 增强

```
[状态] → [策略网络] → [动作] → [环境] → [TD(lambda)更新]
```

- **核心改进**：不再等整个 episode 结束才更新
- **TD(lambda)**：对中-近期奖励权重更高（λ=0.7）
- **结果**：超额 **+32.17%**，最大回撤仅 **-4.0%**
- 关键设计：
  - 买入限制：已有仓位时不能重复买
  - 卖空限制：空仓时不能卖
  - 资格迹（Eligibility Traces）：适合短期交易，对近几笔交易的梯度保留更多

## 三种方案对比

| 方案 | 超额收益 | 回撤 | 训练轮数 | 复杂度 |
|:----|:-------:|:---:|:-------:|:-----:|
| DQN v1 | +9.19% | ~15% | 80 | 低 |
| LSTM+DQN v2 | +18.22% | 12.4% | 100 | 中 |
| TD(lambda) v3 | **+32.17%** | **-4.0%** | 120 | 高 |

## 经验教训

1. **奖励设计决定成败** — 用最终资金变化作为奖励最简单有效，不要设计复杂的奖励函数
2. **限制动作空间** — 禁止重复买入/卖空可以减少无效探索
3. **TD(lambda) > Monte Carlo** — 市场是持续变化的，等整个episode结束再更新已经太晚了
4. **简单模型先跑** — DQN v1 跑了20个episode 负收益，坚持到50+才开始赚钱
