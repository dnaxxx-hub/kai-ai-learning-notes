# 生成模型：VAE → GAN → Diffusion

> 日期：2026-05-07 17:56 | 课程：ML/DL路线 Phase 4-1
> 目标：理解"让AI创造新东西"的三种范式

## 核心问题

> **给我一些猫的图片 → 生成一张不存在但看起来像真的猫**

生成模型 = 学习数据分布 P_data(x)，从中采样

## 三种范式

### 1. VAE（变分自编码器）

#### 思想
```
不是直接学"怎么生成"，而是学"数据的低维表示"
```

Autoencoder = Encoder(压缩) + Decoder(还原)
VAE = AE + **概率化**

#### 关键创新
```python
# AE:     编码器输出一个点 z
# VAE:    编码器输出一个分布 N(μ, σ²)
#         然后采样: z = μ + σ * ε, ε ~ N(0, I)

# 为什么这样更好？
# AE:     隐空间有空洞（两个类之间是"不存在"的区域）
# VAE:    隐空间是连续的（两个点之间都可以插值）
#         在猫和狗之间采样 → 得到"像猫又像狗"的合理图片
```

#### 损失函数
```python
# VAE Loss = 重构损失 + KL散度
# 
# 重构损失: 生成的图片要和原图尽可能像 (MSE/交叉熵)
# KL散度:   编码器输出的分布要接近标准正态 N(0, I)
#           → 隐空间被"规范化"，无空洞
#
# β-VAE:   loss = recon + β * KL
#           β>1 → 更重视隐空间规整（但重建质量下降）
#           β<1 → 更重视重建质量
```

### 2. GAN（生成对抗网络）

#### 思想
> **造假者和警察的对弈**

```
生成器(Generator):  想办法造出以假乱真的图片
判别器(Discriminator): 想办法分辨真假图片

训练目标：造假者越来越强，警察也越来越强
最终：生成器造出警察分不出真假的图片
```

#### 训练过程
```python
# 判别器目标: 真图判真(D(x)→1)，假图判假(D(G(z))→0)
# 生成器目标: 让判别器把假图判真(D(G(z))→1)

# 这就是"对抗"——零和博弈
# 纳什均衡：生成器完美模仿真实分布

# 问题：
# 1. 训练不稳定（模式坍塌）
# 2. 生成器可能只学会少数几个模式
# 3. 没有显式的隐空间表示
```

### 3. Diffusion模型（扩散模型）

#### 思想
> **"先慢慢把图片变成噪声，再学怎么把噪声变回图片"**

```python
# 前向过程（Fixed）:   x₀ → x₁ → x₂ → ... → x_T
#                      干净图片 → 逐步加噪声 → 纯噪声

# 反向过程（Learned）:  x_T → x_{T-1} → ... → x₀
#                      纯噪声 → 逐步去噪 → 生成图片

# 模型学的不是"生成"，而是"去噪"
# 每一步去一点噪声，很多步后噪声全去掉
```

#### 为什么Diffusion比GAN好？
```
GAN:    一步生成（快，但质量不稳定，模式坍塌）
Diffusion: 很多步迭代去噪（慢，但质量极高，多样性强）

所以:
- Midjourney / DALL-E 3 / Stable Diffusion 都用 Diffusion
- GAN 用于实时生成（换脸、风格迁移）
- VAE 用于压缩/降维/隐空间操作
```

## 应用对比

| 模型 | 代表 | 优点 | 缺点 |
|------|------|------|------|
| VAE | VQ-VAE, β-VAE | 隐空间可控 | 生成图片模糊 |
| GAN | StyleGAN, BigGAN | 生成快 | 训练不稳定 |
| Diffusion | DDPM, Stable Diffusion | 质量最高 | 生成慢（秒级） |

## 今日收获
- VAE = 概率化AE，得到连续可插值的隐空间
- GAN = 生成器+判别器对抗训练，快但不稳
- **Diffusion = 当前最佳生成范式**（Stable Diffusion/DALL-E/Midjourney的底层）
- Diffusion的核心是"去噪"，不是一步生成
- 三者的共同目标：**学习数据分布，从中采样出新样本**
