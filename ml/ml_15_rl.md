# 强化学习：智能体与环境交互中学习

> 日期：2026-05-07 ~18:00 | 课程：ML/DL路线 Phase 4-2
> 目标：理解"试错学习"的数学框架

## 核心直觉

之前的监督/无监督学习都是**从静态数据中学习**。
强化学习是**在动态交互中学习**。

```
监督学习:  给你猫的图片 → 学"什么是猫"
强化学习:  丢进一个环境 → 试各种动作 → 发现"这样做能得分" → 学会策略
```

## 核心概念

| 概念 | 符号 | 解释 |
|------|------|------|
| 智能体 | Agent | 做决策的AI |
| 环境 | Environment | 智能体交互的对象 |
| 状态 | s | 环境当前的情况 |
| 动作 | a | 智能体可以做的事 |
| 奖励 | r | 做了动作后环境给的反馈 |
| 策略 | π(a|s) | 在状态s下选动作a的概率 |
| 回报 | G | 累计奖励（带折扣）|

## 马尔可夫决策过程（MDP）

```
MDP = (S, A, P, R, γ)

S: 状态集合
A: 动作集合  
P(s'|s,a): 状态转移概率（做动作a从状态s转到s'的概率）
R(s,a): 奖励函数
γ: 折扣因子（0~1，越远期的奖励越不重要）
```

## 两类方法

### 1. 基于价值（Value-based）— Q-learning
```python
# Q(s,a) = 在状态s做动作a，之后能获得的总回报
# 最优策略 = 在每个状态选Q值最大的动作

# Q-learning更新:
Q(s,a) ← Q(s,a) + α[R + γ·max(Q(s',a')) - Q(s,a)]
```

### 2. 基于策略（Policy-based）— Policy Gradient
```python
# 直接学策略 π(a|s)，而不是通过Q值间接得到
# 策略梯度定理: 让好动作的概率增加，坏动作的概率降低

# 梯度: ∇J = E[ Σ∇log π(a|s) · G ]
# 如果回报G为正 → 增加这个动作的概率
# 如果回报G为负 → 减少这个动作的概率
```

### 3. Actor-Critic（两者结合）
```python
# Actor（演员）= 策略网络 π(a|s) → 做什么动作
# Critic（评论家）= 价值网络 V(s) → 评价这个动作好不好

# Actor根据Critic的评价调整策略
# Critic根据实际奖励更新自己的判断
# 这是目前RL的主流框架
```

## 与深度学习结合（Deep RL）

| 算法 | 特点 | 应用 |
|------|------|------|
| DQN | Q-learning + DNN | Atari游戏 (2013, DeepMind) |
| PPO | 策略梯度 + 裁剪更新 | ChatGPT的RLHF训练 |
| SAC | 最大化回报+熵 | 机器人控制 |
| AlphaGo | MCTS + DNN | 围棋、象棋 |

### ChatGPT中的RLHF
```python
# 1. SFT: 用人类标注数据微调GPT
# 2. Reward Model: 让人类排序多个输出 → 训练奖励模型
# 3. RL (PPO): 用奖励模型训练GPT → 生成人类喜欢的输出

# 关键点：RLHF不是让模型"变聪明"
# 而是让模型"说人喜欢听的话"
# 对齐(Alignment)的核心技术
```

## 今日收获
- RL = 智能体在环境中通过"试错"学习
- MDP = RL的数学框架
- Q-learning: 学"这个动作值多少"
- Policy Gradient: 学"这个状态该做什么动作"
- Actor-Critic = 两者结合 = 当前主流
- **PPO是RLHF的基础，而RLHF = ChatGPT背后的人类对齐技术**
