# 概率论与数理统计：ML中的不确定性语言

> 日期：2026-05-07 12:30 | 课程：ML/DL路线 Phase 1-3
> 目标：理解概率是ML描述不确定性的工具语言

## 核心直觉

### 为什么ML需要概率？

ML的本质是**从有限数据中学习**，而有限数据意味着不确定性。
- 给定一个患者的症状，她是否患病？—— 不是确定的是/否，而是**概率**
- 训练集里没见过这种情况，但见过类似的 —— 需要**泛化**，本质是**概率推理**
- 模型输出"猫置信度0.92" —— 这就是概率

## 三个必懂分布

### 1. 正态分布（高斯分布）N(μ, σ²) — ML中出现最多的分布
```
概率密度: p(x) = (1/√(2πσ²)) · exp(-(x-μ)²/(2σ²))
```
在哪出现：
- 参数初始化（Kaiming/Xavier初始化）
- 噪声建模（观测噪声 = 高斯噪声）
- 批量归一化（BN层强制输出为N(0,1)）
- 变分自编码器（VAE的隐变量先验）
- **中心极限定理**：大量独立随机变量的和趋于正态

### 2. 二项分布 — 分类问题的基础
```
P(k) = C(n,k) · p^k · (1-p)^(n-k)
```
在哪出现：
- 分类问题的本质：n个样本中有k个"正确"
- 准确率本身就是二项分布
- 小样本时n→正态分布（可视化中可以看到）

### 3. Beta分布 — 贝叶斯的核心
```
p(θ) ∝ θ^(α-1) · (1-θ)^(β-1)
```
在哪出现：
- 贝叶斯推断的共轭先验
- Beta分布是"概率的概率分布"

## 贝叶斯定理（ML的灵魂）

```
P(A|B) = P(B|A) · P(A) / P(B)
```
拆解：
- P(A|B) = 观察到B后对A的**信念**（后验）
- P(B|A) = 如果A是真的，B有多可能？**似然**
- P(A) = 看到B之前的信念（先验）
- P(B) = 证据（归一化常数）

### 贝叶斯更新（可视化右下角）
抛10次硬币看到7次正面：
- 先验：Beta(2,2) —— 认为θ≈0.5左右
- 后验：Beta(9,5) —— 更新后右偏（因为数据支持正面概率更高）
- 这就是ML中的"学习"：**看到数据后更新信念**

## 最大似然估计（MLE）— 大多数模型训练的方式

```python
# 给定数据，找出最可能产生这些数据的参数
# θ_MLE = argmax P(data|θ)

# 等价于最小化负对数似然（NLL）
# 交叉熵损失 = 分类问题的NLL
# MSE损失 = 回归问题（假设高斯噪声）的NLL
```

## 信息论基础（交叉熵/KL散度）

### 信息量
```
I(x) = -log₂ P(x)  （单位：bit）
```
- 越不可能的事件，信息量越大
- 必然事件(概率1) → 信息量0

### 熵 = 平均信息量
```
H(X) = -Σ P(x)·log P(x)
```
- 系统的不确定性度量
- 均匀分布 → 熵最大（完全不确定）
- 确定性分布 → 熵=0

### 交叉熵（分类任务最常用的损失）
```
H(p,q) = -Σ p(x)·log q(x)
```
- p = 真实分布（one-hot标签）
- q = 预测分布
- **最小化交叉熵 = MLE**

### KL散度（两个分布的距离）
```
KL(p||q) = Σ p(x)·log(p(x)/q(x))
         = H(p,q) - H(p)
```
- KL≥0 恒成立，当且仅当 p=q 时=0
- **GAN用KL散度 / JS散度作为训练目标**

## 与ML的关键连接

| 概率概念 | ML中的应用 |
|---------|-----------|
| 正态分布 | 初始化/BN/VAE/噪声建模 |
| 贝叶斯定理 | 贝叶斯线性回归/朴素贝叶斯 |
| 最大似然估计 | 几乎所有模型的训练目标 |
| 交叉熵 | 分类损失函数 |
| KL散度 | VAE/GAN/知识蒸馏 |
| 条件概率 | 所有预测问题(P(y|x)) |

## 纯numpy实现

```python
import numpy as np

# 1. 正态分布PDF
def norm_pdf(x, mu=0, sigma=1):
    return np.exp(-0.5*((x-mu)/sigma)**2) / (sigma * np.sqrt(2*np.pi))

# 2. MLE = 样本均值  (对于正态分布)
data = np.random.randn(100) * 2 + 5
mu_mle = np.mean(data)        # ≈ 5
sigma_mle = np.std(data)      # ≈ 2

# 3. 交叉熵分类损失
def cross_entropy(y_true, y_pred):
    # y_true: one-hot [0,0,1,0],  y_pred: [0.1,0.1,0.7,0.1]
    return -np.sum(y_true * np.log(y_pred + 1e-8))

# 4. KL散度
def kl_divergence(p, q):
    return np.sum(p * np.log(p / q + 1e-8))
```

## 今日收获
- 概率是ML描述不确定性的语言
- 大多数ML训练 = 最小化交叉熵损失
- 交叉熵 = MLE视角的损失函数
- KL散度是分布之间的"距离"，在VAE/GAN/蒸馏中广泛应用
- 贝叶斯更新 = 看到数据后更新信念，这是"学习"的数学定义
