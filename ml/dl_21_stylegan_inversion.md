## 1. GAN存在的问题回顾

原始GAN的问题：
```
1. 训练不稳定 —— D/G的纳什均衡很难达到
2. 模式坍塌 —— G只生成少数几种模式
3. 不可控 —— 无法指定生成内容属性
4. 低分辨率 —— 256×256已很难
```

StyleGAN 逐一解决。

## 2. StyleGAN 核心创新

### 2.1 映射网络（Mapping Network）

```
传统GAN:
  z (512维噪声) → Generator → 图像
  
  问题: z的每个维度纠缠在一起
        改变z[0] → 同时改变头发/眼睛/背景

StyleGAN:
  z → MappingNet (8层MLP) → w (中间潜码) → Generator
                                          ↑
                                    风格控制从这里注入
```

**效果**: w空间是解纠缠的（disentangled），每个维度控制一个独立属性。

### 2.2 自适应实例归一化（AdaIN）

核心公式：
```
AdaIN(x, y) = y_std * (x - μ(x)) / σ(x) + y_mean
            ↑风格缩放    ↑内容归一化     ↑风格偏移
```

原理：
```
Feature Map:     [通道1] [通道2] [通道3] ... [通道512]
                   ↓归一化
                 [0.3]   [1.2]   [-0.5]       [0.8]  
                   ↓风格缩放 (y_std)
                 [1.5]   [4.8]   [-2.0]       [3.2]
                   ↓风格偏移 (y_mean)
输出:           [6.5]   [9.8]   [3.0]        [8.2]
```

**关键**: 每个分辨率层都有自己的AdaIN参数 → 不同层级控制不同粒度

### 2.3 风格混合（Style Mixing）

```
Layer 分辨率       控制的特征
──────────────────────────────────
4×4, 8×8    → 粗粒度（姿势/脸型/发型轮廓）
16×16, 32×32 → 中粒度（面部特征/眼睛/嘴型）
64×64, 128×128 → 细粒度（皮肤纹理/光影/发丝）
256×256+  → 高频细节（背景/微纹理）
```

风格混合：用两个不同的w生成混合结果
- 低层用w_A（控制姿势）
- 高层用w_B（控制纹理）
→ 组合出"姿势像A+皮肤像B"的图像

### 2.4 随机变化注入（Stochastic Variation）

```
问题: 生成人像时头发纹理/毛孔等细节总是太"平均"
原因: 潜码w只有512维，不足以编码所有随机细节

方案: 每层注入独立噪声图 (noise maps)
      noise_i ∼ N(0,1) → LearnedScale → +
                                       ↓
                                  FeatureMap_out = FeatureMap_in + scale_i * noise_i
```

效果：噪声控制细粒度随机性（发丝方向/毛孔位置），而不改变整体结构。

### 2.5 渐进式生长

StyleGAN v1 使用ProGAN的渐进式训练：
```
训练顺序: 4×4 → 8×8 → 16×16 → 32×32 → 64×64 → 128×128 → 256×256 → 1024×1024
          ↑             ↑             ↑
       (新增层)       (新增层)       (新增层)

每个阶段: 
  1. 添加新层时用 alpha 混合 (从0渐变到1)
  2. 新层先"透明"再逐渐激活
  3. 稳定后再加下一层
```

StyleGAN v2 废弃了渐进式（用更好的设计替代，训练更快）。

## 3. StyleGAN v2 改进

### 3.1 移除渐进式生长

```
StyleGAN v1:   4→8→16→32→64→128→256→512→1024 （9个阶段）
StyleGAN v2:   直接从32×32训练到1024×1024 （2个阶段）

为什么可以：因为AdaIN + 噪声注入 + 映射网络已经提供了足够的条件控制
```

### 3.2 路径长度正则化

```
问题: w空间虽然解纠缠，但w的微小变化可能导致图像的巨大跳跃

L_path = E[ ||J_w * y||₂ - a ||² ]

其中: J_w = 生成图像的雅可比矩阵
      y = 随机方向
      a = 常数（路径长度的期望值）

效果: 使w空间更平滑——"改变一点w，图像只改变一点"
```

### 3.3 权重调制 + 解调

```
StyleGAN v1:  AdaIN   (归一化→调制)
StyleGAN v2:  权重调制 (直接修改卷积核权重)
              解调     (保持特征统计量稳定)

优点: 不需要额外的归一化层，训练更稳定
```

## 4. StyleGAN v3 (Alias-Free)

关键问题：

```
StyleGAN v1/v2: 生成图像中纹理"粘"在像素坐标上
                旋转人脸 → 牙齿纹理保持原位（像贴图）

原因: 上采样+下采样导致混叠（aliasing）
```

解决方案：**Alias-Free GAN**

```
核心:
  1. 所有上采样使用理想低通滤波器（sinc插值）
  2. 所有下采样前加anti-aliasing
  3. 放弃像素坐标 → 使用连续的傅里叶特征

结果: 
  - 纹理随姿态自然移动
  - 可以无限放大（超出训练分辨率也保持清晰）
  - 支持精确的姿态控制
```

## 5. GAN 反演（GAN Inversion）

### 5.1 什么是反演

```
GAN生成:  w → Generator → Image (512维→1024×1024×3)
GAN反演:  Image → Encoder → w' (1024×1024×3→512维)

目标: 找到"最匹配"给定真实图像的潜码w'
```

### 5.2 三种反演方法

```
┌──────────────────────────────────┐
│  优化式 (Optimization-based)      │
│  w* = argmin || G(w) - I ||²     │
│  + p 程正则化           │
│  + 可能加噪声项                    │
│  精度: ★★★★ (质量最好)           │
│  速度: ★ (~1分钟/张)              │
├──────────────────────────────────┤
│  编码式 (Encoder-based)           │
│  w' = E(I)                        │
│  E是预训练编码器                    │
│  精度: ★★ (细节丢失)              │
│  速度: ★★★★★ (~10ms/张)          │
├──────────────────────────────────┤
│  混合式 (Hybrid)                   │
│  w_init = E(I) → 优化优化           │
│  精度: ★★★★ (近乎优化式)         │
│  速度: ★★★ (~3秒/张)             │
└──────────────────────────────────┘
```

### 5.3 反演的应用

```
1. 图像编辑（核心应用）
   原始图像 → 反演 → w → 修改w → 新图像

2. 图像增强
   低分辨 → 反演 → 用更好的模型生成

3. 属性编辑
   人像 → 反演 → 修改w[年龄] → 老照片

4. 域迁移
   真实人像 → 反演 → 动画风格生成
```

### 5.4 经典反演方法

**e4e (encoder4editing)**：
```
编码器设计:
  ResNet50 + Feature Pyramid → 多个特征图
  → 每个特征图对应StyleGAN的一个输入层
  → 残差连接（w_init + Δw 比直接预测w更稳定）

训练损失:
  L = L_pixel + L_perceptual + L_id + L_reg

其中:
  L_pixel = ||G(w) - I||₁           ← 像素匹配
  L_perceptual = ||VGG(G(w)) - VGG(I)||₂  ← 感知匹配
  L_id = cos_sim(ArcFace(G(w)), ArcFace(I)) ← 身份保持
  L_reg = ||w - w_avg||₂            ← 正则化到平均潜码
```

**PTI (Pivotal Tuning Inversion)**：
```
两步法:
  1. 找到关键w (pivotal w) 
  2. 微调Generator (使w产生更精确的匹配)

  反演精度远超e4e，但需要额外训练时间
```

## 6. 实战：使用StyleGAN生成人脸

```python
import torch
import PIL.Image
import numpy as np

# 加载预训练模型（在FFHQ上训练）
# 注意: StyleGAN官方代码在https://github.com/NVlabs/stylegan3
# 以下为概念代码

# 加载生成器
G = torch.load('stylegan3-ffhq-1024x1024.pkl')

# 生成
z = torch.randn(1, 512)  # 随机噪声
w = G.mapping(z, None)  # 映射到w空间
img = G.synthesis(w)    # 生成图像

# 风格混合
z1, z2 = torch.randn(2, 512)
w1 = G.mapping(z1, None)
w2 = G.mapping(z2, None)

# 混合：粗粒度取z1的，细粒度取z2的
w_mix = torch.cat([
    w1[:, :4],   # 低层（姿势）
    w2[:, 4:]    # 高层（纹理）
], dim=1)

img_mix = G.synthesis(w_mix)  # 混合结果

# w空间插值
alpha = 0.5
w_interp = w1 * (1 - alpha) + w2 * alpha
img_interp = G.synthesis(w_interp)  # 中间态人脸
```
