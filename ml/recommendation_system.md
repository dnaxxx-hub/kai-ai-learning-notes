# 推荐系统学习笔记

## 1. 推荐系统整体架构：工业级三层漏斗

推荐系统本质是**信息过滤系统**，在用户与海量物品之间建立高效匹配。工业级系统普遍采用三层漏斗架构：

```
用户请求 → [召回层] → [排序层] → [重排层] → 最终推荐
                ↓            ↓           ↓
           百万→千条     千→百条       百→十条
```

### 各层职责

| 层级 | 输入 | 输出 | 目标 |
|------|------|------|------|
| **召回 (Recall)** | 全量物品（百万级） | 候选集（千级） | 覆盖广、速度快 |
| **排序 (Ranking)** | 多路召回合并结果 | 精细排序结果 | 准确性高、CTR 最大化 |
| **重排 (Re-ranking)** | 排序结果 | 最终推荐列表 | 多样性、新颖性、业务规则 |

### 关键设计原则
- **算力漏斗**：越上层算力消耗越大，候选集越小
- **信息增量**：每层提供增量特征，越来越精细
- **实时性**：召回层可接受分钟级更新，排序层需秒级实时

## 2. 协同过滤 (Collaborative Filtering)

### 2.1 User-based CF

**核心思想**：找到与目标用户相似的用户群体（邻居），推荐邻居喜欢的物品。

**计算步骤**：
1. 计算用户间相似度
2. 找到 Top-K 相似用户
3. 对未交互物品进行评分预测：加权平均邻居的评分
4. 返回 Top-N 推荐

**相似度计算**：
- 余弦相似度：$sim(u,v) = \frac{r_u \cdot r_v}{\|r_u\| \|r_v\|}$
- Pearson 相关系数：$sim(u,v) = \frac{\sum (r_{ui}-\bar{r_u})(r_{vi}-\bar{r_v})}{\sqrt{\sum (r_{ui}-\bar{r_u})^2} \sqrt{\sum (r_{vi}-\bar{r_v})^2}}$
- Jaccard 系数：$sim(u,v) = \frac{|I_u \cap I_v|}{|I_u \cup I_v|}$

**优点**：简单、可解释性强
**缺点**：用户数远大于物品数时计算量大，冷启动困难

### 2.2 Item-based CF

**核心思想**：用户喜欢某个物品，推荐与之相似的物品。

**优势**：物品间相似度相对稳定，可离线预计算；系统扩展性好。

**预测公式**：
$$score(u,i) = \frac{\sum_{j \in N(u) \cap S(i)} sim(i,j) \cdot r_{uj}}{\sum_{j \in N(u) \cap S(i)} |sim(i,j)|}$$

其中 $S(i)$ 是物品 $i$ 的相似物品集合。

### 2.3 Matrix Factorization (矩阵分解)

**核心思想**：将用户-物品评分矩阵分解为两个低维矩阵的乘积。

$$R_{m \times n} \approx P_{m \times k} \cdot Q_{n \times k}^T$$

**SVD**：传统奇异值分解，要求矩阵稠密，实际场景中评分矩阵极度稀疏，需先填充。

**SVD++**：引入隐式反馈（用户是否点击/浏览过），比纯显式评分更稳定。

$$\hat{r}_{ui} = \mu + b_u + b_i + p_u^T q_i + |N(u)|^{-1/2} \sum_{j \in N(u)} y_j^T q_i$$

**ALS (交替最小二乘)**：
- 固定 Q 优化 P，再固定 P 优化 Q，交替迭代
- 每一步是凸优化，可并行计算
- 适合分布式 Spark 实现

**损失函数**（带 Bias + L2 正则）：
$$\min_{P,Q,b} \sum_{(u,i) \in R} (r_{ui} - \mu - b_u - b_i - p_u^T q_i)^2 + \lambda (\|p_u\|^2 + \|q_i\|^2 + b_u^2 + b_i^2)$$

## 3. 向量召回

### 3.1 i2i (Item-to-Item)
- 将物品映射到向量空间，检索最相似的物品
- 基于用户行为共现：$sim(i,j) = \frac{co\_count(i,j)}{count(i) \cdot count(j)^\alpha}$
- 常用于"看了又看"、"买了又买"

### 3.2 u2i (User-to-Item)
- 用户行为序列生成用户 Embedding，检索匹配的物品
- 常用方法：物品 Embedding 平均 / RNN / Attention 序列模型

### 3.3 Swing 图算法
- 工业级召回算法，利用**用户交叠**来做物品相似度
- 核心观察：如果两个物品被同一组用户点击，它们很可能相似
- 对"刷单用户"有天然免疫（若一个用户与大量用户交互，其权重被降）

$$\text{Swing}(i,j) = \sum_{u \in U_i \cap U_j} \sum_{v \in U_i \cap U_j, v \neq u} \frac{1}{|U_i|^\alpha \cdot |U_j|^\alpha} \cdot \frac{1}{\text{sim}(u,v) + \delta}$$

其中 $U_i$ 是点击物品 $i$ 的用户集合。

### 3.4 Deep Retrieval
- 端到端的深度检索算法，使用多层索引结构
- 将召回转化为分类问题：物品属于哪个聚类

## 4. 排序模型

### 4.1 LR (逻辑回归)
- 最基础 CTR 模型：$P(y=1|x) = \sigma(w^T x + b)$
- 需要大量人工特征工程（特征交叉）
- 可解释性强，在线部署简单

### 4.2 FM (因子分解机)
$$y(x) = w_0 + \sum_{i=1}^n w_i x_i + \sum_{i=1}^n \sum_{j=i+1}^n \langle v_i, v_j \rangle x_i x_j$$

- 自动学习二阶特征交叉
- 时间复杂度优化到 $O(kn)$
- **FFM (Field-aware FM)**：每个特征对不同 field 有不同 embedding

### 4.3 DeepFM
- Wide 部分 = FM（低阶特征交叉）
- Deep 部分 = DNN（高阶隐式交叉）
- 共享 Embedding 层：不分别训练
- 端到端训练，无需预训练

### 4.4 Wide & Deep
- **Wide 部分**：广义线性模型 + 人工交叉特征（记忆能力）
- **Deep 部分**：DNN 学习隐式交叉（泛化能力）
- Google Play 应用推荐经典方案

### 4.5 DCN (Deep & Cross Network)
- **Cross Network**：显式学习高阶特征交叉
  $$x_{l+1} = x_0 \cdot (W_l^T x_l + b_l) + x_l$$
- 每一层保持特征交叉的维度不变
- 比 DNN 更高效地建模特征交互

### 4.6 DIN (Deep Interest Network)
- 阿里广告 CTR 模型
- **注意力机制**：根据候选物品自适应地聚合用户行为序列
- 用户兴趣是多样的，不同候选物品应关注不同历史行为

## 5. 多目标排序

### 5.1 MMOE (Multi-gate Mixture of Experts)
- 多个 Expert 网络 + 多个 Gate
- 不同任务（CTR、CVR、时长）共享底层，但通过 Gate 路由到不同 Expert
- $y_k = h_k(\sum_{i=1}^n g_{k,i}(x) \cdot f_i(x))$

### 5.2 PLE (Progressive Layered Extraction)
- MMOE 增强版：显式区分共享特征和任务独有特征
- 多层渐进式提取，缓解"跷跷板现象"

### 5.3 ESMM (Entire Space Multi-Task Model)
- 阿里 CVR 预估模型
- 解决**样本选择偏差**：CTR + CVR 联合建模
- 利用"点击→转化"的序列依赖

## 6. 特征工程

### 6.1 特征类型
| 类型 | 示例 | 处理方式 |
|------|------|----------|
| 类别特征 | user_id, item_id, 城市 | One-hot / Embedding |
| 数值特征 | 年龄、价格 | 归一化 / 分桶 |
| 序列特征 | 浏览历史 | RNN / Attention |
| 交叉特征 | (性别, 品类) | FM / 手工组合 |

### 6.2 特征交叉
- **手工交叉**：LR + 人工特征工程（可解释）
- **模型自动交叉**：FM、DCN（学习式）
- **Embedding**：每个类别特征映射为稠密向量，DNN 隐式交叉

### 6.3 特征归一化
- **Min-Max**：$x' = \frac{x - min}{max - min}$
- **Z-Score**：$x' = \frac{x - \mu}{\sigma}$
- **Log 变换**：$x' = \log(1 + x)$（对长尾分布）

## 7. 冷启动问题

### 7.1 UGC 探索
- 利用用户的主动标签（关注、收藏）直接匹配
- 通过类别/属性匹配，无需用户行为

### 7.2 兴趣迁移
- 用其他平台/渠道的用户数据预热
- 站外行为映射到站内

### 7.3 人口统计
- 基于年龄、性别、地域的热门推荐
- 粗粒度匹配，适合新用户首屏

### 7.4 探索策略
- **ε-greedy**：以概率 ε 随机推荐，以概率 1-ε 利用模型
- **UCB**：置信区间上界，对"不确定性高"的物品提权
- **Thompson Sampling**：贝叶斯方法，从后验分布采样

---

## 8. 评估指标

### 8.1 离线指标
| 指标 | 含义 | 说明 |
|------|------|------|
| **CTR** | 点击率 = 点击/曝光 | 最基础的商业指标 |
| **AUC** | ROC 曲线下面积 | 分类排序能力，对正负样本不均衡鲁棒 |
| **GAUC** | Group AUC | 按用户分组的 AUC 平均，更贴近线上真实 |
| **NDCG** | 归一化折损累计增益 | 考虑排序位置，越靠前权重越大 |
| **HR** | 命中率 | Top-N 中是否有正样本 |
| **MRR** | 平均倒数排名 | 第一个正样本的位置 |

### 8.2 多样性指标
- **ILD (Intra-List Distance)**：列表中物品间平均距离
- **Coverage**：推荐覆盖物品的比例

---

## 9. AB 测试框架

### 基本流程
1. **分流**：将用户随机分为实验组和对照组
2. **实验组**：新模型/策略
3. **对照组**：基线模型/策略
4. **指标对比**：CTR、GMV、时长等
5. **统计显著性检验**：t 检验 / 卡方检验 / AA 测试

### 注意事项
- **样本量**：每组需要足够样本（至少数千）
- **时长**：至少跑 1-2 周覆盖周期性
- **互斥**：不同实验不能互相干扰
- **哈希分流**：一致性哈希保证用户固定在一组

## 总结：全链路数据流

```
                         用户请求
                            ↓
                    ┌───────────────────┐
                    │   多路召回策略      │
                    │  · Item-CF         │
                    │  · User-CF         │
                    │  · Swing           │
                    │  · 热门/新品补充    │
                    └────────┬──────────┘
                             ↓
                    ┌───────────────────┐
                    │   召回合并 & 去重   │
                    │   ~1000 候选       │
                    └────────┬──────────┘
                             ↓
                    ┌───────────────────┐
                    │   排序模型(DeeFM)  │
                    │    + 特征工程      │
                    │   ~100 候选        │
                    └────────┬──────────┘
                             ↓
                    ┌───────────────────┐
                    │   重排             │
                    │   多样性控制       │
                    │   业务规则过滤     │
                    │   Top-10 输出      │
                    └───────────────────┘
```

**本实现覆盖**：召回（Item-CF / User-CF / Swing）+ 排序（FM / DeepFM）+ 全链路集成，纯 Python + NumPy 实现。
