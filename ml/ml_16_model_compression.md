# 模型压缩：大模型上生产环境的必修课

> 日期：2026-05-07 ~18:00 | 课程：ML/DL路线 Phase 4-3
> 目标：理解"怎么把大模型变小变快"

## 核心问题

大模型效果越来越好，但：
- GPT-4: ~1.7万亿参数，几个TB
- LLaMA-65B: 65B参数，需要~130GB显存
- 手机上根本跑不动

**模型压缩 = 让模型更小更快，尽量保持精度**

## 四种核心技术

### 1. 量化（Quantization）

核心思想：用更少的bit表示权重

```python
# FP32:   每个权重用32bit浮点数 → 4字节
# FP16:   16bit → 2字节（速度翻倍）
# INT8:   8bit → 1字节（速度快4倍）
# INT4:   4bit → 0.5字节（速度快8倍）

# 量化过程: 把连续值映射到离散值
# scale = (max - min) / (127 - (-128))
# quantized = round((value / scale)) 

# 你在用的DeepSeek就是量化版的 🤖
```

| 精度 | 大小 | 速度 | 精度损失 |
|------|------|------|---------|
| FP32 | 100% | 1x | 基准 |
| FP16 | 50% | 2x | 几乎无损失 |
| INT8 | 25% | 4x | 轻微 |
| INT4 | 12.5% | 8x | 可接受 |

### 2. 剪枝（Pruning）

核心思想：去掉不重要的连接/神经元

```python
# 结构化剪枝: 整层删除/整个通道删除
#   - 优点: 直接减少计算量
#   - 缺点: 可能损伤精度

# 非结构化剪枝: 删掉权重值接近0的连接
#   - 优点: 保留精度
#   - 缺点: 变成稀疏矩阵，需要特殊硬件加速

# Lottery Ticket Hypothesis（彩票假设）:
# 一个大规模网络里，存在一个"中奖"的子网络
# 单独训练这个子网络能达到和原网络一样的精度
```

### 3. 知识蒸馏（Knowledge Distillation）

核心思想：小模型学生向大模型老师学习

```python
# Teacher: 大模型（精确但慢）
# Student: 小模型（快但精度不够）

# 蒸馏损失 = α · CE(student, true_labels) 
#          + (1-α) · KL(soft(student/T), soft(teacher/T))

# 温度 T: 控制"软标签"的平滑程度
# T越高 → 分布越平滑 → 负标签的"相对关系"被保留

# 关键洞察：老师教学生的不仅是"正确答案"
# 还有"猫和狗比猫和桌子更像"——这种关系知识
```

### 4. 模型结构设计（Architecture Design）

核心思想：一开始就设计小而高效的架构

```python
# MobileNet:    深度可分离卷积（参数少10倍）
# EfficientNet: 神经架构搜索找到的最优结构
# TinyBERT:     BERT的轻量化版本
# DistilBERT:   蒸馏版BERT（40%参数，97%性能）
# DeepSeek-R1:  混合专家(MoE)架构
```

## 实际应用中的组合

```python
# 一个典型的模型压缩流程:
# 1. 训练大模型（FP32）
# 2. 知识蒸馏 → 小模型（FP32）
# 3. 量化 → INT8/INT4
# 4. （可选）剪枝
# 5. 部署到移动端/推理卡

# GPU推理:    FP16 + 少量剪枝
# 手机推理:   INT4 + 蒸馏
# 云端推理:   FP16（精度优先）
```

## 今日收获

| 方法 | 效果 | 代价 |
|------|------|------|
| 量化 | 4~8倍压缩 | 轻微精度损失 |
| 剪枝 | 2~5倍压缩 | 需要重训练 |
| 蒸馏 | 2~10倍压缩 | 需要教师模型 |
| 结构设计 | 10~100倍 | 需要专业知识 |

**模型压缩 = 大模型落地的最后一公里。没有它就没有手机上的AI。**
