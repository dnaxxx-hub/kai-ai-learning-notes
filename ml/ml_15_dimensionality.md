## 1. PCA (主成分分析)

### SVD实现
1. 中心化: X' = X - μ
2. SVD: X' = UΣV^T
3. 主成分 = V的列 (按奇异值排序)
4. 投影: X'·V_k

### 关键指标
- 解释方差比: σ²_i / ∑σ²
- 累积解释方差
- 重建误差

### 结果
```
50维高维低秩数据 (5维真实信号):
  PC1~5: 30%+23%+22%+15%+9% = 98.33% ✅
  正确识别真实维数=5

2D相关数据 → 1D: 95.8%方差保留, 重偏误差0.029
```
