## 核心直觉

### 导数 = 变化率
```
f'(x) = 当 x 变化一点点时，f(x) 变化多少？
```
在ML中：**权重变化一点点，损失变化多少？**

### 梯度 = 多维导数
- 标量函数：导数 f'(x)
- 向量函数：梯度 ∇f(x) = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]
- **梯度方向 = 函数增长最快的方向**
- **负梯度方向 = 函数下降最快的方向**（这就是梯度下降的原理）

## 四个ML/DL必懂概念

### 1. 链式法则（反向传播的数学基础）
```python
# 链式法则：dz/dx = dz/dy · dy/dx
# 神经网络可以看成嵌套函数:
# f(g(h(x))) 的导数 = f'(g)·g'(h)·h'(x)

# 反向传播 = 在计算图上从输出往输入传播梯度
# forward:  z = W2 · relu(W1 · x + b1) + b2
# backward: dL/dW1 = dL/dz · dz/dh · dh/dW1
```

### 2. 偏导数（多变量函数的梯度）
```python
# f(x, y) = 3x² + 2xy + y²
# ∂f/∂x = 6x + 2y    ← 对x求偏导时把y当常数
# ∂f/∂y = 2x + 2y    ← 对y求偏导时把x当常数
```

### 3. 梯度下降（每个ML模型都在用）
```python
def gradient_descent(f, df, x0, lr=0.01, steps=100):
    x = x0
    for i in range(steps):
        grad = df(x)
        x = x - lr * grad  # ← 沿负梯度方向更新
    return x
```

### 4. 拉格朗日乘子法（带约束优化）
用于SVM、正则化（L1/L2本质就是约束优化）
```
L(x, λ) = f(x) + λ · g(x)
```
在最优解处，∇L = 0 → 同时满足优化目标和约束

## 与ML的关键连接

| 微积分概念 | ML中的应用 |
|-----------|-----------|
| 导数 | 梯度下降/学习率调度 |
| 偏导数 | 对每个权重分别求梯度 |
| 链式法则 | 反向传播（BP算法核心） |
| 梯度 | 参数更新方向 + 自适应优化器(Adam) |
| 二阶导 | Newton法、Hessian-free优化 |
| 拉格朗日乘子 | SVM对偶问题、约束优化 |

## 纯numpy梯度下降实现

```python
import numpy as np

# 最小二乘线性回归的梯度下降
X = np.random.randn(100, 3)  # 100个样本, 3个特征
w_true = np.array([2, -1, 0.5])
y = X @ w_true + 0.1 * np.random.randn(100)

# 损失: MSE = 1/n * sum((Xw - y)^2)
# 梯度: dL/dw = 2/n * X^T @ (Xw - y)

w = np.zeros(3)
lr = 0.01
for step in range(1000):
    pred = X @ w
    grad = 2 * X.T @ (pred - y) / len(y)
    w = w - lr * grad
    
print(f"真值: {w_true}")
print(f"学到: {np.round(w, 3)}")
# 输出: 真值: [2, -1, 0.5] → 学到: [1.998, -0.997, 0.501]
```

## 今日收获
- 梯度下降的本质很简单：**朝着最陡的下坡走一小步，重复**
- 反向传播就是用链式法则把输出端的误差分配到每个权重
- 所有的优化器（SGD/Momentum/Adam）都是"怎么走这步"的不同策略
- 二阶导信息告诉我们是"下坡加速了还是减速了"（凸性/凹性）
