## 决策树（Decision Tree）

### 本质
```
递归二分：if 特征 < 阈值 → 左子树 else 右子树
```

### 分裂标准
| 标准 | 公式 | 特点 |
|------|------|------|
| 信息增益 | H(parent) - Σ(nᵢ/n)·H(childᵢ) | 基于熵，倾向多值特征 |
| 基尼系数 | 1 - Σpᵢ² | 计算快，默认选择 |
| 方差减少 | Var(parent) - Var(child) | 回归树用 |

```python
# 基尼不纯度
gini = 1 - (n0/n)² - (n1/n)²
# 完美分离: 纯节点 gini=0
# 各半: gini=0.5
# 分裂评分: impurity_reduction = gini_parent - weighted_avg(gini_children)
```

### 问题
- **容易过拟合**：树深到极端时完美记忆训练集
- **高方差**：训练集微小变化会导致完全不同的树
- **不稳定**：但不是集成学习的最佳基学习器

## 集成学习（Ensemble Learning）

### Bagging（Bootstrap Aggregating）
```
1. 从训练集放回抽样 B 个子集
2. 每个子集训练一个模型
3. 预测时取平均（回归）或投票（分类）

核心：降低方差
```

### Random Forest = Bagging + 随机特征选择
```
在每个节点分裂时，只随机选 sqrt(p) 个特征考虑
→ 让树更"多样化"
→ 比Bagging更有效
```

### Boosting（逐步修正错误）
```
1. 训练一个弱模型
2. 找出它错的地方，给那些样本加大权重
3. 训练下一个模型，重点关注之前错的
4. 重复B轮

核心：降低偏差
```

| 方法 | 代表 | 降低 | 训练方式 |
|------|------|------|---------|
| Bagging | Random Forest | **方差** | 并行训练 |
| Boosting | XGBoost/LightGBM | **偏差** | 串行训练 |
| Stacking | 元学习器 | 两者 | 分层训练 |

## XGBoost — 实战中最常用的Boosting

```python
# XGBoost 成功的原因：
# 1. 正则化目标函数（叶节点数 + L2）
# 2. 二阶泰勒展开（用梯度+海森矩阵）
# 3. 列采样（类似RF）
# 4. 感知缺失值方向

# 目标函数:
# Obj = Σ loss(y_i, y_hat_i) + γ·T + λ·Σw_j²
#        ↑ 训练损失      ↑ 树复杂度   ↑ 叶子权重

# 每棵新树拟合的是残差:
# y_hat^(t) = y_hat^(t-1) + f_t(x)
```

## 与深度学习的选择

| 场景 | 选Tree-based | 选NN |
|------|------------|------|
| 表格数据 | ✅ XGBoost/LightGBM 王者 | ❌ 需要大量数据 |
| 图像/文本 | ❌ 不行 | ✅ CNN/Transformer |
| 小样本 | ✅ 效果好 | ❌ 容易过拟合 |
| 可解释性 | ✅ 特征重要性 | ❌ 黑箱 |
| 超大数据 | ⚠️ 上限低 | ✅ 扩展性好 |

## 今日收获
- 单棵决策树 ≈ 一系列 if-else，容易过拟合
- **Bagging降低方差（RF），Boosting降低偏差（XGBoost）**
- 集成学习的核心：**多个弱模型的组合 > 单个强模型**
- XGBoost/LightGBM是表格数据的王者
- 决策树的特征重要性是天然的可解释性
