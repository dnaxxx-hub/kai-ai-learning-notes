# 第13课：贝叶斯方法 — NB + 高斯过程

> 日期: 2026-05-08
> 代码: `ml_bayesian.py`

## 1. 高斯朴素贝叶斯 (Gaussian NB)

### 原理
- 每个类别的每个特征服从独立正态分布
- P(y|x) ∝ P(y) · ∏ P(x_i|y)
- 对数空间计算避免浮点下溢

### 实现
- 训练: 计算每个类均值 + 方差
- 预测: 计算后验概率 → argmax

## 2. 多项式朴素贝叶斯 (Multinomial NB)

- 适用于词频/计数数据
- Laplace平滑避免零概率

## 3. 高斯过程回归 (GPR)

### 核心公式
```
P(f* | X*, X, y) = N(μ*, Σ*)

μ* = K(X*, X) · [K(X,X) + σ²I]⁻¹ · y
Σ* = K(X*, X*) - K(X*,X)·[K(X,X)+σ²I]⁻¹·K(X,X*)
```

### RBF核
```
k(x_i, x_j) = σ²_f · exp(-||x_i - x_j||² / 2l²)
```

- l (length_scale): 控制平滑度
  - 太小 → 过拟合, 不确定区域大方差
  - 太大 → 太平滑, 欠拟合

### Cholesky 分解
- 用 L·L^T = K 代替直接求逆
- 数值更稳定, 更快

### 结果
```
Gaussian NB:
  2维/5维/10维 → 73%/99%/100%
  高维时效果更好 (更多区分度)

GP回归 (sin x + 噪声):
  l=0.3: MSE=0.092 (过拟合/抖动)
  l=1.0: MSE=0.008 (最优拟合)
  l=3.0: MSE=0.046 (太平滑/欠拟合)
```
