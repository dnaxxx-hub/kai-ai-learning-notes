## PCA（主成分分析）

### 核心思想
> **找到数据方差最大的方向，把数据投影上去**

直观理解：
- 数据在某个方向上"散得最开" → 那个方向上信息最多
- 投影到那个方向 → 保留最多信息
- 丢掉方差小的方向 → 丢弃噪声

### 数学本质：SVD分解
```python
# 1. 数据中心化
X_centered = X - X.mean(axis=0)

# 2. SVD分解（比协方差矩阵更稳定）
U, S, Vt = np.linalg.svd(X_centered / sqrt(n-1), full_matrices=False)

# 3. 主成分 = Vt.T 的列（按方差降序）
# 方差占比 = S_i² / ΣS_j²
# 前k个主成分解释了 Σ(S_i²)/Σ(S_j²) 的方差

# 4. 降维 = 投影
X_k_dim = X_centered @ Vt[:k].T   # shape: (n, k)
```

### 为什么SVD优于协方差矩阵
- 数值稳定性更好
- 不需要显式构造 n×n 的协方差矩阵
- 可以直接处理 n < d（样本少特征多）的情况

### 应用场景
| 场景 | 说明 |
|------|------|
| 可视化 | 降到2D/3D看数据整体分布 |
| 去噪 | 丢掉小方差方向 = 滤掉噪声 |
| 压缩 | 用k维表示d维（k≪d） |
| 白化 | 让特征之间去相关 |

## K-means聚类

### 核心思想
> **把数据分成K组，每组中心离组内点最近**

```python
def kmeans(X, k, iters=20):
    # 1. 随机初始化K个中心
    centroids = X[np.random.choice(len(X), k, replace=False)]
    
    for _ in range(iters):
        # 2. 每个点分配到最近的中心
        dists = 每个点到所有中心的距离
        labels = 每个点最近的中心的ID
        
        # 3. 更新中心 = 组内点均值
        centroids = 每组的均值
    
    return labels, centroids
```

### K-means的缺陷
1. **需要指定K** — 用肘部法则找最佳K
2. **K个初始中心影响结果** — 多次运行取最佳
3. **假设球形簇** — 非球形数据效果差
4. **对异常值敏感** — 可以用K-medoids代替

### GMM（高斯混合模型）— K-means的概率版本
- K-means：硬分配（点只属于一类）
- GMM：软分配（点以概率属于各类）
- GMM假设每个簇是高斯的，用EM算法求解

```python
# K-means vs GMM
# K-means:  每个点到中心距离最小的类
# GMM:      每个点有概率属于每个类
#           p(x) = Σπᵢ · N(x|μᵢ, Σᵢ)
```
