# 第4课：音频编码基础 — PCM/WAV

## 1. PCM（脉冲编码调制）
- **采样**：连续 → 离散
- **量化**：连续幅度 → 离散等级
  - 8-bit：256级
  - 16-bit：65536级
  - 24-bit：16777216级
- **编码**：量化值 → 二进制

## 2. WAV文件格式（RIFF结构）
```
RIFF头 (12 bytes)
├── "RIFF" (4) 
├── 文件大小 (4)
└── "WAVE" (4)

fmt块 (24 bytes)
├── "fmt " (4)
├── 块大小 (4) = 16
├── 音频格式 (2)  1=PCM
├── 声道数 (2)
├── 采样率 (4)
├── 字节率 (4)
├── 块对齐 (2)
└── 位深度 (2)

data块
├── "data" (4)
├── 数据大小 (4)
└── 采样数据 ...
```

## 3. 关键参数
- **采样率**：44.1kHz(CD), 48kHz(DVD), 96kHz(Hi-Res)
- **位深度**：16bit(CD), 24bit(Hi-Res)
- **声道数**：1(单声道), 2(立体声), 5.1(环绕)
- **比特率** = 采样率 × 位深度 × 声道数

```
CD: 44100 × 16 × 2 = 1411.2 kbps
```

## 4. 量化误差
- 量化噪声 ≈ ±0.5 LSB
- 动态范围 ≈ 6.02 × bits + 1.76 dB
- 16bit → 约 96dB 动态范围
