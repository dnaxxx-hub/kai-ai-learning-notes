# 第3课：数字滤波器

## 1. 滤波器类型
- **低通**：保留低频，衰减高频
- **高通**：保留高频，衰减低频
- **带通**：保留某频段
- **带阻**：衰减某频段（含陷波器 notch filter）

## 2. FIR vs IIR

| 特性 | FIR | IIR |
|------|-----|-----|
| 冲激响应 | 有限长 | 无限长 |
| 反馈 | 无（全前馈） | 有反馈 |
| 稳定性 | 绝对稳定 | 可能不稳定 |
| 相移 | 线性相位（不失真） | 非线性相位 |
| 计算量 | 阶数高，计算大 | 阶数低，效率高 |
| 设计难度 | 简单 | 需要专业知识 |

## 3. 卷积
- 滤波的本质：输入信号 × 滤波器冲激响应
- y[n] = Σx[k]·h[n-k]
- Python: `np.convolve(x, h)`

## 4. 实用滤波器
- **巴特沃斯**：通带最平坦
- **切比雪夫**：更陡峭的过渡带
- **椭圆**：最陡峭但有波纹

## 5. Python中的滤波器设计
```python
from scipy import signal

# 低通滤波（巴特沃斯）
b, a = signal.butter(4, 1000/(fs/2), 'low')  # 4阶，截止1000Hz
y = signal.filtfilt(b, a, x)  # 零相位滤波

# FIR设计
taps = signal.firwin(51, 0.3)  # 51阶低通
```
