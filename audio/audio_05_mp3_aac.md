# 第5课：MP3/AAC编码原理

## 1. 有损编码核心思路
> 丢掉人耳**听不到**的信息，用更少的bit表示

## 2. 心理声学模型

### 掩蔽效应（Masking）
- **频率掩蔽**：响亮的频率遮盖邻近的弱频率
  - 临界频带：人耳频率分辨率的单位（Bark尺度）
- **时域掩蔽**：响音前后的短暂掩蔽
  - 前向掩蔽：响音之前 ~5ms
  - 后向掩蔽：响音之后 ~100ms

### 绝对听阈
- 人耳对不同频率敏感度不同
- 2-4kHz最敏感，低频和高频不敏感

## 3. MP3编码流程
```
PCM → 滤波器组(32子带) → MDCT → 量化 → 霍夫曼编码 → 比特流
        ↑                           ↑
    心理声学模型                比特分配
```

## 4. 子带编码
- 32个等宽子带（滤波器组）
- 每个子带独立量化
- 量化噪声被掩蔽在信号下方

## 5. 霍夫曼编码
- 变长编码：高频值用短码，低频值用长码
- 无损压缩，MP3中用于量化后的数据

## 6. AAC的改进
| 特性 | MP3 | AAC |
|------|-----|-----|
| 滤波器 | 32子带 | MDCT (256/2048点) |
| 采样率 | ≤48kHz | ≤96kHz |
| 通道 | 2 | 48 |
| 效率 | 128kbps≈CD | 96kbps≈CD |

## 7. 比特率模式
- **CBR**：固定比特率（恒定文件大小）
- **VBR**：可变比特率（更高效，质量优先）
- **ABR**：平均比特率（折中）
