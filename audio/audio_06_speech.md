# 第6课：语音处理入门

## 1. 语音信号特点
- 非平稳信号（随时间变化）
- 短时平稳（10-30ms内近似不变）
- 分为：清音（unvoiced）和浊音（voiced）

## 2. 分帧与加窗
- **分帧**：25ms帧长，10ms帧移
- **加窗**：减少频谱泄漏
  - 汉明窗（Hamming）：h[n] = 0.54 - 0.46·cos(2πn/N)
  - 汉宁窗（Hanning）：h[n] = 0.5 - 0.5·cos(2πn/N)

## 3. MFCC（梅尔频率倒谱系数）
最常用的语音特征，步骤：
1. 预加重 → 2. 分帧加窗 → 3. FFT → 4. Mel滤波器组 → 5. Log → 6. DCT

- **Mel刻度**：模拟人耳对数频率感知
  - mel = 2595·log₁₀(1 + f/700)
- 通常取 13 个 MFCC 系数

## 4. 基频检测（Pitch Detection）
- 浊音有基频（F0），清音没有
- 方法：
  - **自相关法**：找信号与自身的最大延迟匹配
  - **倒谱法**：FFT → log → IFFT，峰值位置
  - **YIN算法**：改进的自相关
- 人声基频范围：男 ~100Hz，女 ~200Hz

## 5. 语音合成（TTS）基本原理
- **拼接合成**：预录音素数据库拼接
- **参数合成**：声学参数 → 波形生成
- **深度学习**：Tacotron/WaveNet/端到端

## 6. 语音识别（ASR）概览
- 特征提取(MFCC) → 声学模型 → 语言模型 → 文本输出
- 现代方法：端到端（CTC/RNN-T/Transformer）
