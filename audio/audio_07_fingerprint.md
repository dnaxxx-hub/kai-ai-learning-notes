# 第7课：音频指纹

## 1. 什么是音频指纹
- 音频片段的"数字指纹"——紧凑的特征表示
- 用于识别未知音频的身份

## 2. Shazam算法原理

### 核心思想
1. **频谱峰值提取**：找频谱中能量最大的点（峰值）
2. **星座图**：时间-频率平面上的峰值点
3. **哈希生成**：将峰值对组合成哈希值
4. **匹配搜索**：哈希表快速查找

### 算法流程
```
音频 → STFT频谱 → 找峰值 → 组合哈希 → 存入数据库
未知音频 → 同上 → 找匹配 → 时间对齐验证 → 识别
```

### 哈希生成
- 锚点峰值 + 目标峰值（在同一时间窗内）
- 哈希 = (f1, f2, Δt) 三元组
- 抗噪性强：少量峰值被破坏不影响识别

## 3. 频谱哈希
- 一种更简单的指纹方法
- 相邻频带比较：哪个能量大 → 1位
- 32个频带 → 32-bit哈希值
- 缺点：对时间偏移敏感

## 4. 匹配搜索
- 使用哈希表（字典）实现 O(1) 查找
- 时间偏移验证：匹配点的时间差应一致
- 多数投票决定最终结果

## 5. 其他音频指纹系统
| 系统 | 特点 |
|------|------|
| Chromaprint (AcoustID) | 基于MFCC + 滤波器 |
| dejavu | 类似Shazam的开源实现 |
