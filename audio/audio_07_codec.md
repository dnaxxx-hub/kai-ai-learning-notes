# 第7课：音频编解码器实现

## 1. 概述

> 音频编解码器负责在 **PCM 流 → 压缩比特流** 之间转换。
> 核心目标：**用最小比特率，保证听觉质量**。

本课覆盖：
| 话题 | 说明 |
|------|------|
| ADPCM | 差分量化，预测编码（G.721） |
| 子带编码 | QMF 滤波器组（32子带） |
| 心理声学 | 感知熵、掩蔽阈值 |
| AAC 基础 | MDCT + 联合立体声 + TNS |

## 2. ADPCM — 自适应差分脉冲编码调制

### 2.1 原理
```
PCM 样本 → [预测器] → 预测值 → [减法] → 残差 → [量化] → ADPCM 码字
                         ↑                              ↓
                     [更新预测] ←—— 解码残差 ←————— [反量化]
```

**关键观察**：相邻音频样本高度相关。直接量化 PCM 浪费 bits。
- 差分编码：只量化 **实际值 − 预测值** (预测残差)
- ADPCM = 预测器系数 + 量化步长 **自适应**调整

### 2.2 算法细节

**预测器**：一阶固定预测器
- `x̂[n] = x[n−1]` 或 `x̂[n] = 2·x[n−1] − x[n−2]`

**量化**：差分信号 δ 用 **N bit 均匀量化器**
- 步长 Δ 根据信号幅度自适应调整（乘法因子 1 ± 1/16）

**IMA ADPCM 编码**（常见实现）：
```
编码过程：
  1. 计算预测残差 d = x[n] − x̂[n]
  2. 用当前步长 index 量化 d → 4-bit 码字
  3. 查表更新步长 index
  4. 输出 4-bit → 压缩比 4:1 (16-bit PCM → 4-bit ADPCM)
```

### 2.3 步长自适应表
IMA 标准定义 89 个步长值：`[7, 8, 9, 10, ..., 65536]`
每个码字对应一个步长调整量：
```
码字 | 步长调整因子
 0   |   −1  (步长缩小 ~1/1.1)
 7   |   +8  (步长放大 ~2)
```

## 3. 子带编码 — QMF 滤波器组

### 3.1 核心思想
将音频分为多个 **频率子带**，每个子带独立量化：
- 低频子带：人耳敏感 → 高精度（更多 bits）
- 高频子带：人耳不敏感 → 低精度（更少 bits）

### 3.2 正交镜像滤波器 (QMF)

```
               [H0(z)] → 下采样 2 → 编码
输入 x[n] →
               [H1(z)] → 下采样 2 → 编码
```

**分析滤波器对**：
- `H0(z)` — 低通滤波器
- `H1(z) = H0(−z)` — 高通滤波器（镜像响应）

**完美重建条件** (PR)：
```
|H0(ω)|² + |H0(ω+π)|² = 2      (功率互补)
```

### 3.3 两通道 QMF 滤波器设计

使用余弦调制生成 H0/H1：
```
h0[n] = w[n] · cos(πn/2N)           (低通)
h1[n] = w[n] · cos(π(2n+1)/4N)      (高通)
```

### 3.4 子带分解 → 多级 QMF 级联
```
输入 → QMF(→低→QMF→低→子带0
             →高→QMF→高→子带1
        →高→子带2
        →高→子带3)
```
每一层将子带数翻倍。K 层树状结构 → 2^K 个子带。

## 4. 心理声学模型

### 4.1 听觉掩蔽

**频率掩蔽**（同时掩蔽）：
- 一个响亮的纯音（掩蔽音）会在其频带附近抬起听觉阈值
- 被掩蔽音若低于新阈值，人耳听不到
- 掩蔽宽度约 1 个 Bark（临界频带）

**时域掩蔽**（非同时掩蔽）：
- 前向掩蔽（掩蔽前 ~5ms）
- 后向掩蔽（掩蔽后 ~50-200ms）

### 4.2 Bark 尺度与临界频带
```
Bark 频率映射：
  z(Bark) = 13·arctan(0.76·f/1000) + 3.5·arctan(f/7500)²

第 k 个临界频带的带宽随频率增加：~100Hz(低频) ~ 4000Hz(高频)
一共约 24 个 Bark（覆盖 0~20kHz）
```

### 4.3 感知熵 (Perceptual Entropy)
```
PE = Σ_k log₂(1 + E_k / T_k)

其中：
  E_k = 第 k 个临界频带的能量
  T_k = 第 k 个频带的掩蔽阈值
```

感知熵高的帧需要更多 bits 来保持听觉透明。
- PE < 2 bits/样本 → 容易压缩
- PE > 5 bits/样本 → 挑战性素材

### 4.4 掩蔽阈值计算
```
SPL → FFT → 临界频带分析 → 扩散函数 → 掩蔽阈值 → 全局阈值
```

**简化模型**：用 Bark 域三角扩散函数模拟掩蔽的传播。

## 5. AAC 编码基础

### 5.1 AAC 架构
```
PCM → 增益控制 → MDCT → TNS → 立体声编码 → 量化 → 霍夫曼 → 比特流
```

### 5.2 MDCT（修正离散余弦变换）
AAC 使用 **MDCT** 替代 MP3 的混合滤波器组：
```
X[k] = Σ x[n] · cos(π/2N · (2n+1+N/2) · (2k+1)) , n=0..2N-1

特性：
  - 50% 重叠（Time-Domain Aliasing Cancellation）
  - 更好的频率分辨率
  - 无块效应（与 FFT 不同）
```

### 5.3 TNS（时域噪声整形）
- 对 MDCT 频谱进行线性预测（等效于时域的噪声整形）
- 将量化噪声隐藏在瞬态信号下方
- **关键特性**：使量化噪声在时域跟随信号包络

### 5.4 联合立体声编码
```
M/S 立体声：左右声道 → 和/差声道
强度立体声：高频用单声道 + 方向信息
```

```
┌─────────────────────────────────────────────────────┐
│                   编码流程                           │
│                                                      │
│  PCM → [QMF子带分解] → [心理声学模型] → [比特分配]  │
│                                          ↓           │
│                     ←← [ADPCM/量化器] ←←←           │
│                                          ↓           │
│                                    [比特流打包]      │

│  ADPCM:   简单差分，4:1 压缩，低延迟                 │

│  AAC:     MDCT + TNS + PS，高效率 ~96kbps CD         │

```
