# ML音视频：AI编解码的未来

> 音视频编解码第8课 — 机器学习在视频处理中的应用

## 传统编解码 vs AI编解码

| 方面 | 传统（H.265/VVC） | AI辅助 | 端到端AI |
|------|-------------------|--------|---------|
| 核心 | 手工设计变换+运动估计 | 增强传统编码 | 全神经网络编解码 |
| 压缩比 | 基准 | 提升10-30% | 可提升50%+ |
| 复杂度 | 成熟优化 | 中等 | 极高 |
| 标准化 | MPEG/ITU | 正在标准化 | MPEG-5 LCEVC |
| 可用性 | iOS/Android原生 | 需专用芯片 | 实验阶段 |

## 超分辨率（Super Resolution）

### 原理
从低分辨率输入重建高分辨率细节。

```
LR帧 → DNN模型 → HR帧
         ↑
    训练数据: LR-HR配对
```

### 主流架构
| 模型 | 特点 | 速度 | 质量 |
|------|------|------|------|
| SRCNN | 3层CNN，开创性 | 快 | 一般 |
| ESRGAN | GAN-based，感知好 | 慢 | 好 |
| Real-ESRGAN | 盲超分，真实退化 | 慢 | 最好 |
| RSR | 实时超分（移动端） | 最快 | 可接受 |

### 在流媒体的应用
- **画质提升**：低码率视频超分恢复细节
- **老旧内容修复**：DVD→HD/4K升级
- **边缘渲染**：云端渲染低分辨率→端侧超分

## 帧插值（Frame Interpolation）

### 目标
在两个已有帧之间合成中间帧，提升帧率。

```
Frame1 ─── Frame? ─── Frame2
              ↑
        插值模型
```

### 经典模型
| 模型 | 原理 | 特点 |
|------|------|------|
| DAIN | 深度光流+自适应权重 | 质量好，速度慢 |
| RIFE | IFNet实时光流 | 速度快，质量好 |
| FILM | 多尺度特征提取 | Google出品 |
| FlowFormer | Transformer+光流 | SOTA |

### 应用场景
- **运动补偿**：低帧率视频→高帧率（24fps→60/120fps）
- **慢动作生成**：正常速度→慢动作
- **VR/AR**：提高临场感和流畅度

## 内容感知编码

### 原理
"人眼对不同的区域敏感度不同"——给视觉重要区域更多码率，不重要区域更少。

```
┌─────────────────────────────┐
│  人眼关注区域                  │
│  ┌──────┐                    │
│  │ 人脸  │  重要 → 高码率     │
│  └──────┘                    │
│  ┌─────────┐                 │
│  │  草地     │  不重要→低码率   │
│  └─────────┘                 │
└─────────────────────────────┘
```

### 实现方法
1. **ROI编码**：检测人脸/文字等感兴趣区域，为这些区域分配更多QP
2. **注视预测**：用DNN预测人眼关注的热力图
3. **SSIM优化**：以感知质量（SSIM/MS-SSIM）替代PSNR作为优化目标

### 码率节省
| 场景 | 节省码率 | 感知质量 |
|------|---------|---------|
| 视频会议 | 30-50% | - |
| 直播（游戏） | 20-40% | 几乎无差异 |
| 影视内容 | 15-30% | 关注区域保持最高质量 |

## AI编解码标准

### MPEG-5 LCEVC
- 分层增强编码架构
- 基础层用传统编码器（H.264/H.265）
- 增强层用AI重构细节
- 兼容现有播放器

### 端到端AI编解码
```
输入 → 编码器CNN → 量化 → 熵编码 → 比特流
                                       ↓
输出 ← 解码器CNN ← 反量化 ← 熵解码 ←
```

### 面临的挑战
1. **复杂度**：端到端AI编解码器比传统复杂100-1000倍
2. **算力**：需要专用NPU/VPU硬件加速
3. **标准兼容性**：完全替代传统标准需要数年
4. **时域一致性**：帧闪烁问题尚未完全解决

## 未来趋势

1. **混合架构**：传统编码 + AI增强（LCEVC方向）
2. **端侧AI**：手机SoC集成NPU，实时AI超分已可行
3. **场景自适应**：根据内容类型动态选择编码策略
4. **低延迟**：AI编解码在超低延迟场景的优势

## 总结
- ML在视频领域覆盖超分辨率、帧插值、去噪、内容感知编码四大方向
- 端到端AI编解码仍在实验阶段，混合架构是近期趋势
- 内容感知编码已在视频会议和直播中商用
- 端侧NPU的普及将加速AI视频处理在移动设备的落地
