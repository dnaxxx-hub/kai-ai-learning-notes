# 第1课：信号基础

## 1. 信号分类

### 连续信号 vs 离散信号
- **连续信号**：定义在连续时间上的信号，如模拟电压波形
- **离散信号**：仅在离散时间点有定义的信号，如采样后的数字音频

### 时域 vs 频域
- **时域**：信号随时间变化的表示
- **频域**：信号频率成分的表示
- 时域↔频域的桥梁：傅里叶变换

## 2. 采样定理（Nyquist）

### 核心定律
> 要以数字形式完美重建模拟信号，**采样频率必须≥信号最高频率的2倍**

- fs ≥ 2·f_max
- 人耳可听范围：20Hz ~ 20kHz
- CD音频采样率：44.1kHz（> 2×20kHz）

## 3. 混叠效应（Aliasing）

### 什么是混叠
- 采样不足时，高频信号"伪装"成低频信号
- 产生虚假的频率成分，无法通过滤波去除

### 防止混叠
1. **抗混叠滤波器**（低通滤波）：采样前滤除高于 fs/2 的频率
2. **提高采样率**：oversampling 过采样

## 4. Python验证

```python
import numpy as np
import matplotlib.pyplot as plt

fs = 100  # 采样率 100Hz
t = np.arange(0, 1, 1/fs)

# 高频信号 80Hz，Nyquist频率为50Hz → 产生混叠
f_high = 80
x = np.sin(2 * np.pi * f_high * t)

# 看上去像 20Hz 信号（混叠：80-50=30，镜像到50-30=20）
# 实际 alias 频率：|80 - 100| = 20Hz
```
