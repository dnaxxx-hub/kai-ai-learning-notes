## 安全三要素（CIA）

```python
# Confidentiality（机密性）— 数据只有授权的人能看到
# Integrity（完整性）— 数据没有被篡改
# Availability（可用性）— 系统正常运行

# 攻击类型可以按CIA分类：
# - 泄密 → 破坏机密性
# - 篡改 → 破坏完整性
# - DDoS → 破坏可用性
```

## 常见网络攻击类型

### 1. DDoS（分布式拒绝服务）

```python
# 用大量机器同时请求你的服务器
# 服务器处理不过来 → 正常用户无法访问

# 防御:
# - CDN分流（CloudFlare等）
# - 限流（Rate Limiting）
# - IP黑名单
# - 弹性扩容（自动加服务器）

# 著名的Mirai僵尸网络（2016）:
# 用物联网设备（摄像头/路由器）发起1.2Tbps的DDoS
# 导致Twitter/Netflix/Spotify下线
```

### 2. 中间人攻击（MITM）

```python
# 通信双方之间插入一个"窃听者"
# 你在用公共WiFi，旁边的人能看到你发的内容

# 防御:
# - HTTPS（加密通信）
# - 不连公共WiFi做敏感操作
# - VPN（端到端加密）
```

### 3. 社会工程学（Social Engineering）

```python
# 最危险的攻击方式——不攻击系统，攻击人

# 钓鱼邮件: "您的账户异常，请点击链接验证"
# 伪装电话: "我是IT支持，需要你的密码"
# 尾随: 跟着别人刷卡进入禁区

# 防御:
# - 不要点陌生链接
# - 不要泄露密码/验证码
# - 多因素认证（2FA）
```

### 4. 零日漏洞（Zero-Day）

```python
# 软件漏洞被发现，但厂商还不知道
# 从被发现到被修复 = "零日窗口"
# 窗口期内 → 没有任何防御方案

# 著名的零日:
# Stuxnet (2010) — 用Windows零日攻击伊朗核设施
# Log4j (2021) — Java日志库的远程代码执行
```

## 攻击链（Cyber Kill Chain）

```python
# 黑客攻击的"标准流程":

# 1. 侦察      → 收集信息（IP/域名/技术栈/员工邮箱）
# 2. 武器化   → 准备攻击工具（恶意软件/Payload）
# 3. 递送     → 发送钓鱼邮件/上传漏洞利用
# 4. 利用     → 触发漏洞，获取入口
# 5. 安装     → 建立后门/植入木马
# 6. 指挥控制 → 远程控制受感染机器
# 7. 目标行动 → 窃取数据/加密勒索/破坏系统
```

## 分层防御（Defense in Depth）

```python
# 不要依赖单点防御，要层层设防

# 用户层 → 安全意识培训/2FA
# 应用层 → WAF（Web应用防火墙）/输入验证
# 主机层 → 杀毒软件/HIDS/补丁管理
# 网络层 → 防火墙/IDS（入侵检测）/VPN
# 物理层 → 门禁/监控/机柜锁
```

## 今日收获
- 安全三要素：机密性/完整性/可用性
- 攻击类型：DDoS/MITM/社会工程/零日
- 攻击链 = 7步从侦察到最终目标
- **没有绝对安全，只有足够安全的防御**
- 分层防御 = 每一层都设防，突破一层还有下一层
