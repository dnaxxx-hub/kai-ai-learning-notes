## 1. 秘密共享（Secret Sharing）

### 1.1 问题模型

**秘密共享**解决的是：如何将一个秘密 $s$ 拆分成 $n$ 份「份额」（share），使得：
- 任意 $t$ 个份额可以重构 $s$
- 任意 $t-1$ 个份额得不到 $s$ 的任何信息

这称为 **t-out-of-n 门限方案**（threshold scheme）。

### 1.2 Shamir 秘密共享（1979）

Adi Shamir 利用拉格朗日插值定理提出了一种优雅的方案。

#### 核心思想

用一个 $t-1$ 次多项式来编码秘密：

$$
f(x) = s + a_1 x + a_2 x^2 + \cdots + a_{t-1} x^{t-1} \pmod{p}
$$

其中：
- $s = f(0)$ 是秘密
- $a_1, a_2, \ldots, a_{t-1}$ 是随机系数
- $p$ 是一个大素数（保证在有限域中运算）

**份额生成**：计算 $n$ 个点 $(i, f(i))$，$i=1,2,\ldots,n$

#### 为什么 t 个点就能恢复？

$t-1$ 次多项式有 $t$ 个未知系数。$t$ 个点给出 $t$ 个方程，恰好唯一确定多项式。

$t-1$ 个点只有 $t-1$ 个方程，解空间是一维的——秘密可以是任意值。

#### 拉格朗日插值恢复

给定 $t$ 个份额 $(x_j, y_j)$，恢复秘密 $s = f(0)$：

$$
f(0) = \sum_{j=1}^{t} y_j \cdot L_j(0)
$$

其中拉格朗日基多项式：

$$
L_j(0) = \prod_{\substack{1 \le m \le t \\ m \ne j}} \frac{0 - x_m}{x_j - x_m} = \prod_{\substack{1 \le m \le t \\ m \ne j}} \frac{-x_m}{x_j - x_m}
$$

由于所有计算在有限域 $\mathbb{F}_p$ 中进行，需要用模逆元处理除法。

#### 举例：2-out-of-3（t=2, n=3）

秘密 $s=42$，素数 $p=97$：
1. 选 $t-1=1$ 次多项式：$f(x) = 42 + 17x \pmod{97}$
2. 份额：$(1, f(1)=59)$, $(2, f(2)=76)$, $(3, f(3)=93)$
3. 用 $(1,59)$ 和 $(3,93)$ 恢复：
   - $L_1(0) = \frac{0-3}{1-3} = \frac{-3}{-2} = 3 \cdot 2^{-1} \pmod{97} = 3 \cdot 49 = 50$
   - $L_3(0) = \frac{0-1}{3-1} = \frac{-1}{2} = -1 \cdot 2^{-1} = 96 \cdot 49 = 48$
   - $s = 59 \times 50 + 93 \times 48 = 2950 + 4464 = 7414 \equiv 42 \pmod{97}$

### 1.3 秘密共享的性质

| 性质 | 说明 |
|------|------|
| **完美安全性** | $t-1$ 个份额的信息熵等于 0（关于秘密） |
| **同态加法** | 两份秘密的份额相加 = 和的份额 |
| **可扩展** | 可动态添加参与者而不改变现有份额 |
| **无信息泄露** | 少一个份额就得不到任何信息 |

### 1.4 线性秘密共享（LSSS）

Shamir 方案是**线性秘密共享方案（Linear Secret Sharing Scheme）** 的特例：
- 份额是秘密的线性函数
- 重构是份额的线性组合
- 支持加法同态

## 2. 安全多方计算基础

### 2.1 加法共享（Additive Secret Sharing）

将秘密 $s$ 拆成 $n$ 份随机数的和：

$$
s = s_1 + s_2 + \cdots + s_n \pmod{p}
$$

**特点**：
- 所有 $n$ 份才能恢复
- 任意 $n-1$ 份完全随机
- 加法同态：$(a_1 + b_1) + (a_2 + b_2) = a + b$

**两方加法共享**：
- $s$ 拆为 $s_1$（随机），$s_2 = s - s_1 \mod p$
- 恢复：$s = s_1 + s_2 \mod p$

**加法协议**：
- 两方分别有 $a$ 的份额 $[a]_1, [a]_2$ 和 $b$ 的份额 $[b]_1, [b]_2$
- 本地计算：$[c]_i = [a]_i + [b]_i$
- $[c]_1 + [c]_2 = (a_1 + b_1) + (a_2 + b_2) = a + b$

### 2.2 Beaver Triples 与安全乘法

加法很容易，但乘法会带来交叉项：

$$
[a] \cdot [b] = (a_1 + a_2) \cdot (b_1 + b_2) = a_1 b_1 + a_1 b_2 + a_2 b_1 + a_2 b_2
$$

$[a]_1 \cdot [b]_2$ 和 $[a]_2 \cdot [b]_1$ 涉及跨方数据，不能本地计算。

**Beaver Triples**（1991年由 Donald Beaver 提出）解决了这个问题：

一个 Beaver Triple 是 $([a], [b], [c])$，满足 $c = a \cdot b$，其中 $a, b$ 随机，三组份额分别给各方。

**用 Beaver Triple 做安全乘法**：

1. 各方有 $[x]_i$, $[y]_i$, 以及预共享的 $[a]_i$, $[b]_i$, $[c]_i$
2. 每方本地计算 $[d]_i = [x]_i - [a]_i$, $[e]_i = [y]_i - [b]_i$
3. 公开 $d = \sum [d]_i$, $e = \sum [e]_i$（这不会泄露 $x, y$，因为 $a, b$ 是随机掩码）
4. 每方本地计算输出份额：$[z]_i = [c]_i + d \cdot [b]_i + e \cdot [a]_i + d \cdot e$（最后一项只加在第一方）

**验证**：

$$
\begin{aligned}
z &= c + d b + e a + d e \\
  &= ab + (x-a)b + (y-b)a + (x-a)(y-b) \\
  &= ab + xb - ab + ya - ab + xy - xb - ya + ab \\
  &= xy
\end{aligned}
$$

### 2.3 完整计算流程

有了加法（本地）和乘法（Beaver），理论上可以计算任意算术电路：

```
输入 → 加法/乘法门 → 输出
```

每一方只需在本地维护份额，通过 Beaver 协议处理乘法，最后公开份额恢复结果。

## 3. SPDZ 协议（简化）

SPDZ 代表其创建者：D **S**mart, P **P**aillier, **D**amgård, **Z**akarias（2012），是当前最实用的恶意安全 MPC 协议之一。

### 3.1 半诚实安全 vs 恶意安全

| 维度 | 半诚实安全 | 恶意安全 |
|------|-----------|---------|
| 敌手行为 | 遵守协议，试图推断 | 可任意偏离协议 |
| 防护机制 | 不需要 | MAC、零知识证明、一致性检查 |
| 效率 | 高 | 低（但 SPDZ 做了大量优化） |
| 适用场景 | 互信较弱的合作方 | 完全互不信任 |

### 3.2 SPDZ 的核心创新

1. **离线/在线分离**：昂贵的密码操作放在离线阶段
2. **信息论 MAC**：每个值附带一个 MAC，防止篡改
3. ** Beaver Triples 预生成**：离线生成，在线直接使用

### 3.3 离线阶段

离线阶段生成以下材料（与具体计算无关，可预计算）：

1. **Beaver Triples**：大量 $([a], [b], [c])$ where $c = a \cdot b$
2. **随机数**：用于输入掩码
3. **MAC 密钥**：全局 MAC 密钥 $\alpha$

**MAC 机制**：每个值 $x$ 附带 MAC 值 $\gamma(x) = \alpha \cdot x$（在特定 MAC 域中）。

### 3.4 在线阶段

```
输入 → 输入共享 → 线性计算 → 乘法(Beaver) → 输出重构
```

**具体步骤**：

1. **输入共享**：每方秘密分享自己的输入 $x_i$
2. **加法计算**：本地加法（份额相加）
3. **乘法计算**：用 Beaver Triple 协议
4. **MAC 验证**：验证所有值的 MAC
5. **输出重构**：公开份额，重建输出

MAC 验证确保没有任何一方在计算中篡改过数据，从而实现恶意安全。

### 3.5 SPDZ 的局限

- 离线阶段计算量大（同态加密生成 Beaver Triples）
- 通信轮次仍然较高
- 后来的 Overdrive (2017) 改进了离线阶段效率

## 4. Garbled Circuit（姚氏混淆电路）

### 4.1 概述

Yao's Garbled Circuit（1986年，姚期智）是**两方安全计算（2PC）** 的奠基性协议。

核心思想：将函数表示为布尔电路，然后「混淆」每条线缆的 0/1 值。

### 4.2 参与者角色

| 角色 | 行为 |
|------|------|
| **Alice（Garbler）** | 生成混淆电路，发送给 Bob |
| **Bob（Evaluator）** | 用 OT 获取自己的输入，评估电路 |

### 4.3 混淆表生成（以 AND 门为例）

一个 AND 门有两条输入线 $a, b$ 和一条输出线 $c$。

1. 每条线生成两个随机标签（128-bit）：
   - $K_a^0$, $K_a^1$（代表 $a=0$ 和 $a=1$）
   - $K_b^0$, $K_b^1$（代表 $b=0$ 和 $b=1$）
   - $K_c^0$, $K_c^1$（代表 $c=0$ 和 $c=1$）

2. 加密输出标签（真值表的每一行）：
   - 0 AND 0 = 0：$E_{K_a^0}(E_{K_b^0}(K_c^0))$
   - 0 AND 1 = 0：$E_{K_a^0}(E_{K_b^1}(K_c^0))$
   - 1 AND 0 = 0：$E_{K_a^1}(E_{K_b^0}(K_c^0))$
   - 1 AND 1 = 1：$E_{K_a^1}(E_{K_b^1}(K_c^1))$

3. **打乱**：随机排列 4 行，这样 Bob 无法根据位置推断

### 4.4 不经意传输（Oblivious Transfer, OT）

**1-out-of-2 OT**：Alice 有两个消息 $m_0, m_1$，Bob 有一个比特 $b$。协议结束后：
- Bob 得到 $m_b$，不知道 $m_{1-b}$
- Alice 不知道 Bob 选了哪个

**在 GC 中的应用**：
- Bob 需要用 OT 获得自己输入的混淆标签
- Alice 知道两个标签 $K^0, K^1$
- Bob 知道自己的实际输入比特 $b$
- OT 后 Bob 得到 $K^b$，Alice 不知道 $b$

### 4.5 评估过程

1. **Alice**：生成电路 + 混淆表 + 自己的输入标签（直接发给 Bob）
2. **Bob**：
   - 用 OT 获取自己的输入标签
   - 逐门解密：用两个输入标签解密混淆表，得到输出标签
   - 最终拿到输出线标签
3. **Bob** 将输出标签发给 Alice（或双方用共享输出约定）
4. **Alice** 将标签映射回 0/1

### 4.6 优化技术

| 优化 | 效果 |
|------|------|
| **Free XOR** | XOR 门无需混淆（用标签异或计算） |
| **Row Reduction** | AND 门从 4 行减到 3 行 |
| **Half Gates** | AND 门只需 2 行 |
| **Point-and-Permute** | 用指针比特加速解密 |

### 4.7 GC vs SPDZ 对比

| 维度 | Garbled Circuit | SPDZ |
|------|----------------|------|
| 参与方 | 2 方 | n 方 |
| 安全模型 | 半诚实（基础）/ 恶意 | 恶意 |
| 电路类型 | 布尔电路 | 算术电路 |
| 通信复杂度 | $O(\|C\|)$ | $O(\|C\|)$ |
| 轮次 | 1（非交互式评估） | 多轮 |
| 预处理 | 不需要 | 需要（离线阶段） |

## 5. 差分隐私（Differential Privacy）

### 5.1 问题动机

秘密共享和 MPC 保护的是**计算结果**。但有时候**计算结果本身**就会泄露个体信息。

**例子**：医院发布查询「有多少患者患某种病」，如果知道总共有 100 人，发现结果是 99，就能推断第 100 人大概率患病。

### 5.2 ε-差分隐私定义

一个随机算法 $\mathcal{M}$ 满足 $\varepsilon$-差分隐私，如果对任意相邻数据集 $D$ 和 $D'$（只有一条记录不同），对所有输出集合 $S \subseteq \text{Range}(\mathcal{M})$：

$$
\Pr[\mathcal{M}(D) \in S] \le e^\varepsilon \cdot \Pr[\mathcal{M}(D') \in S]
$$

**直观理解**：算法对任意单条记录的变化不敏感。$\varepsilon$ 越小，隐私保护越强。

### 5.3 Laplace 机制

对查询结果加 Laplace 噪音：

$$
\mathcal{M}(D) = f(D) + \text{Lap}\left(\frac{\Delta f}{\varepsilon}\right)
$$

其中：
- $\Delta f = \max_{D, D'} \|f(D) - f(D')\|_1$ 是查询的**敏感度**
- $\text{Lap}(\lambda)$ 的 PDF：$\frac{1}{2\lambda} e^{-|x|/\lambda}$

**例子**：计数查询的敏感度 $\Delta f = 1$，所以 $\text{Lap}(1/\varepsilon)$ 噪音即可。

### 5.4 差分隐私与 MPC 的关系

| 方面 | MPC | 差分隐私 |
|------|-----|---------|
| 保护什么 | 计算过程中的中间数据 | 计算结果中的个体信息 |
| 攻击模型 | 恶意参与方 | 对查询结果的任意分析 |
| 输出 | 精确结果 | 加噪音的近似结果 |
| 互补 | 防止计算过程中泄露 | 防止结果泄露个体 |

**典型结合**：用MPC安全计算统计结果，再用差分隐私对结果加噪后发布。

## 总结

### 知识体系

```
秘密共享 ─┬─ Shamir 秘密共享（门限方案）
          └─ 加法共享（同态加法）

MPC ──────┬─ Beaver Triples → 安全乘法
          ├─ SPDZ ──┬─ 离线：Beaver + MAC
          │         └─ 在线：输入共享 → 计算 → MAC验证 → 输出
          └─ Yao's GC ──┬─ 混淆表 + OT
                        └─ 两方布尔电路计算

差分隐私 ──── Laplace 机制（加噪音保护个体）
```

### 核心思想

1. **秘密共享**是 MPC 的基石
2. **加法免费，乘法付费**：加法本地计算，乘法需要 Beaver Triple
3. **离线/在线分离**：预处理 + 在线快速计算
4. **MAC** 实现恶意安全
5. **混淆电路**针对布尔电路，**SPDZ** 针对算术电路
6. 差分隐私保护**输出结果**中的个体信息

### 学习路径建议

1. ✅ 先搞懂 Shamir 秘密共享（数学轻巧，概念基础）
2. ✅ 理解加法共享 → Beaver Triple 安全乘法
3. ✅ 理解组合计算（加法 + 乘法 = 任意算术电路）
4. ✅ 了解 SPDZ 的离线/在线架构
5. ✅ 了解 Garbled Circuit（不同的技术路线）
6. ✅ 了解差分隐私（互补的保护方向）
7. ➡ 进阶阅读：SPDZ 论文、Overdrive、ABY（混合协议）
