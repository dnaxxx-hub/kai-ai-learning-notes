# AI Security 第1课：提示注入攻击与检测

## 核心概念
- **提示注入**：攻击者通过精心构造的输入，覆盖或绕过模型的安全对齐
  - **直接注入**：明确指示模型忽略系统提示，"你是……" "从现在开始……"
  - **间接注入**：将恶意指令藏在正常文本块的 meta 标签或特殊标记中
  - **目标劫持**：让模型忘记原始任务并执行新任务
  - **越狱模板**：DAN、角色扮演、逻辑陷阱等标准化攻击模板

## 对抗性后缀
- Greedy Coordinate Gradient (GCG)：通过梯度搜索优化一个小后缀，使其能绕过安全检测
- 实际效果：短后缀（5-10 token）即可显著提高攻击成功率
- 本课实现：词汇表随机搜索替代梯度优化（简化版）

## 检测方法
1. **关键词匹配**：Ignore/Override/DAN/System Prompt 等
2. **正则模板**：Pretend you are… / From now on…
3. **字符异常**：杂音字符、特殊标记
4. **长度分析**：超长输入（>500字）带有隐藏指令可能性更高

## 本课的局限性（第2课改进方向）
- 中文注入完全无检测（多语言绕过）
- "Pretend to be my grandmother"这种经典越狱被漏报
- 阈值敏感，误报 vs 漏报需要权衡
- 没有困惑度（perplexity）分析作为辅助信号
