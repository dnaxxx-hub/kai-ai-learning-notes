## 1. 对抗训练（Adversarial Training）

### Min-Max 优化框架（Madry et al., 2018）

对抗训练的核心思想：**在与攻击者进行 Min-Max 博弈中训练模型**。

```
min_θ  E_{(x,y) ~ D}[ max_{δ ∈ S}  J(θ, x+δ, y) ]
```

- **内层最大化**（攻击者）：在允许的扰动集合 `S` 内寻找使损失最大的对抗样本
- **外层最小化**（防御者）：在这些最坏的对抗样本上训练模型参数 `θ`

### 本质

对抗训练相当于一种**数据增强**（data augmentation）——在训练过程中动态生成最恶劣的对抗样本，迫使决策边界远离数据流形。

### 实际考量

| 方面 | 说明 |
|------|------|
| **攻击方法** | PGD 是最常用的内层攻击（最强一阶攻击） |
| **计算成本** | 每步训练扩大 K 倍（PGD 步数），通常 3~10 步即可 |
| **干净准确率** | 对抗训练通常会降低干净样本上的准确率（trade-off） |
| **鲁棒准确率** | PGD 训练的模型对 PGD/FGSM 有最好的鲁棒性 |
| **FGSM 训练** | 只用 FGSM 做对抗训练 → 对 PGD 的鲁棒性差（梯度掩码问题） |

### FGSM 训练的陷阱

FGSM 训练（只使用 FGSM 生成对抗样本）容易被 PGD 攻破，原因：
- FGSM 的扰动方向有限（只沿梯度符号一个方向），模型学会了"记住"这个方向（梯度掩码）
- PGD 通过多步探索可以绕过这个方向

## 2. 防御蒸馏（Defensive Distillation）

### 原理

Papernot et al. (2016) 提出用**知识蒸馏（Knowledge Distillation）** 增强模型鲁棒性。

**三步流程**：
1. 训练一个**教师网络**（Teacher），使用温度 `T > 1` 的 softmax 输出软标签
2. 用教师网络在**相同数据集**上生成软标签
3. 训练一个**学生网络**（Student），在相同高温下学习匹配软标签

### 为什么有效？

- 高温 softmax 使输出概率分布更平滑（不只是 0 和 1）
- 平滑的决策边界 → 梯度在局部区域变化更平缓
- 攻击者更难找到有效的梯度方向

```
softmax(z_i, T) = exp(z_i / T) / Σ_j exp(z_j / T)
```

- `T = 1`：标准 softmax
- `T > 1`：概率分布更均匀

### 局限

- Carlini & Wagner (2016) 证明防御蒸馏只能降低攻击成功率约 0.5%，远非根本解决方案
- 对强攻击（PGD、C&W）效果有限
- 蒸馏本身不是独立的防御——需要与其他方法配合使用

## 3. 输入变换防御（Input Transformation）

通过在输入进入模型之前进行**预处理变换**，破坏对抗扰动的结构。

### JPEG 压缩

**原理**：对抗扰动通常包含高频分量，JPEG 压缩（DCT 域量化）可以有效滤除高频噪声。

**近似实现**：
```
1. 分块（8×8 blocks）
2. 近似 DCT → 舍入量化（舍去高频系数）
3. 重构图像
```

**局限**：
- 强压缩会降低干净样本的质量
- 攻击者可以针对 JPEG 压缩进行自适应攻击（Expectation Over Transformation）

### 高斯模糊（Gaussian Blur）

**原理**：用高斯核对图像做平滑，破坏扰动的高频结构。

```
G(x, y) = (1 / 2πσ²) · exp(-(x² + y²) / 2σ²)
```

**典型参数**：Kernel = 5, σ = 1.0（在滤除扰动的同时尽量保留图像细节）

### 随机裁剪与缩放（Random Resize & Pad）

**原理**：随机改变图像的尺寸和位置，使扰动的精确位置"错位"。

### 组合使用

实践中常将多种输入变换组合使用。但需要注意：
- 每种变换都会降低干净样本的质量
- 自适应攻击是最大威胁——如果攻击者知道变换参数，可以生成绕过变换的对抗样本

## 4. 梯度掩码（Gradient Masking）

### 定义

梯度掩码是指防御方法通过**隐藏或扭曲梯度信息**来阻止白盒攻击。

### 常见形式

| 形式 | 描述 | 问题 |
|------|------|------|
| **消失梯度** | 在模型前插入不可导操作（如 JPEG 压缩的舍入） | 可以用代理梯度通过 |
| **梯度爆炸** | 让梯度数值特别大或小 | 攻击者调整步长即可 |
| **梯度混淆** | 多个操作使梯度方向偏离真实方向 | 黑盒攻击不受影响 |
| **梯度裁剪** | 在训练时限制梯度大小 | 不影响攻击梯度的方向 |

### 为什么梯度掩码不是真正的防御？

- **黑盒迁移攻击**：为替代模型生成对抗样本 → 迁移到目标模型（梯度掩码只影响白盒攻击）
- **BPDA**（Backward Pass Differentiable Approximation）：用近似梯度替代不可导操作的梯度
- 真正的鲁棒性应该来自决策边界的改变，而非梯度的隐藏

### 安全第一性原理

> **不要依赖梯度不可见性来保证安全。** 攻击者总是可以找到绕过梯度掩码的方法。

## 5. 对抗样本检测（Adversarial Detection）

### 思路

不试图让模型正确分类对抗样本，而是**检测输入是否为对抗样本**，检测到后直接拒绝或报警。

### 常见方法

| 方法 | 原理 |
|------|------|
| **统计检测** | 对抗样本在 latent space 中的分布与干净样本不同 |
| **LID**（Local Intrinsic Dimensionality） | 对抗样本在其邻域内的本征维度更高 |
| **Mahalanobis 距离** | 检测输入与类中心之间的距离是否异常 |
| **训练一个二分类器** | 额外训练一个检测器来判断输入是否被扰动 |
| **检测熵** | 对抗样本的预测不确定性熵通常较高 |

### 局限

- 自适应攻击可以同时欺骗分类器和检测器
- 对抗检测和对抗训练之间存在**猫鼠游戏**——防御者增强检测，攻击者改进逃避方法
- 检测方法通常只在已知攻击上有效，对未知攻击泛化能力有限

## 6. 认证防御（Certified Robustness）

### 随机平滑（Randomized Smoothing）

Cohen et al. (2019) 提出一种**可证明的**防御方法——**随机平滑**。

**核心思想**：不是训练一个本身鲁棒的模型，而是将**任何模型**转换为一个具有认证鲁棒性的平滑分类器。

### 流程

```
g(x) = argmax_c  P( f(x + δ) = c )   其中 δ ~ N(0, σ²I)
```

1. 在输入 `x` 上添加高斯噪声 `δ`
2. 多次采样 `x + δ` 并通过基分类器 `f`
3. 统计基分类器最多的预测类别
4. 用 Neyman-Pearson 引理推导出认证半径

### 认证半径

对于平滑分类器 `g`，可以证明：
```
如果 P(f(x+δ)=c_A) > P(f(x+δ)=c_B)，则对任意 ||ε||₂ < R 的扰动，g(x+ε) = c_A
其中 R = (σ/2) · Φ^{-1}(p_A) - Φ^{-1}(p_B)
```

- `p_A`：基分类器对 `c_A` 类别的预测概率
- `p_B`：基分类器对第二大概率类别的预测概率
- `Φ^{-1}`：标准正态分布的逆 CDF

### 与经验防御的区别

| 方面 | 随机平滑（认证防御） | 对抗训练（经验防御） |
|------|---------------------|---------------------|
| **保证** | 有数学证明 | 只在测试的攻击上有效 |
| **计算成本** | 推理时需要大量采样 | 训练时需要对抗样本 |
| **适用半径** | 通常较小（σ ≤ 1.0） | 可以适应更大的 ε |
| **可扩展性** | 好（任何模型都可以包装） | 一般（需要修改训练） |

## 7. 实践感悟

1. **没有银弹**：单一防御方法都不足以抵御所有攻击
2. **对抗训练是最实用的基线**：PGD 对抗训练仍然是实证鲁棒性的最强基线之一
3. **输入变换是最轻量级的防线**：不需要重新训练模型，但容易被自适应攻击绕过
4. **梯度掩码是假安全感**：它只挡住"诚实"的攻击者，真正的攻击者会用 BPDA 或黑盒攻击绕过
5. **安全需要纵深防御**：对抗训练 + 输入变换 + 检测的防御组合远比单一方法有效
6. **认证防御是未来方向**：随机平滑提供了可证明的鲁棒性保证，但计算成本限制了大规模应用
