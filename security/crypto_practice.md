# 密码学深度实践 — AES + RSA 纯 Python 实现学习笔记

## AES 核心原理

### 总体结构
AES（Advanced Encryption Standard）是一种对称分组密码，分组大小为 128 位（16 字节）。AES-128 使用 128 位密钥，进行 10 轮加密。每轮包含四个操作（最后一轮省略 MixColumns）：

```
明文块 → AddRoundKey → SubBytes → ShiftRows → MixColumns → AddRoundKey → ... → 密文块
          └──────────── 第1轮 ────────────┘         └──── 第2~9轮 ────┘   └ 第10轮(无Mix) ┘
```

### 状态矩阵 (State)
AES 将 16 字节的块排列成 4×4 矩阵（列主序）：
```
[b0,  b4,  b8,  b12]    ← 第0列
[b1,  b5,  b9,  b13]    ← 第1列
[b2,  b6,  b10, b14]    ← 第2列
[b3,  b7,  b11, b15]    ← 第3列
```

### 1. S-Box (SubBytes)
S-Box 是一个 256 字节的查找表，提供非线性替换。构造方法：
1. 在 GF(2^8) 中求乘法逆元（0 → 0）
2. 应用仿射变换：`b'_i = b_i ⊕ b_{i+4 mod 8} ⊕ b_{i+5 mod 8} ⊕ b_{i+6 mod 8} ⊕ b_{i+7 mod 8} ⊕ c_i`
   - 其中 c = 0x63

**作用**：提供非线性，抵抗线性/差分密码分析。

### 2. ShiftRows
- 第 0 行：不变
- 第 1 行：循环左移 1 字节
- 第 2 行：循环左移 2 字节
- 第 3 行：循环左移 3 字节

解密时反向：循环右移。
**作用**：提供字节间的扩散。

### 3. MixColumns
将每一列视为 GF(2^8) 上的 4 项多项式，与固定多项式 `a(x) = {03}x³ + {01}x² + {01}x + {02}` 相乘后模 `x⁴+1`。

矩阵形式（加密）：
```
[s'0]   [02 03 01 01] [s0]
[s'1] = [01 02 03 01] [s1]
[s'2]   [01 01 02 03] [s2]
[s'3]   [03 01 01 02] [s3]
```

解密使用逆矩阵：
```
[s'0]   [0e 0b 0d 09] [s0]
[s'1] = [09 0e 0b 0d] [s1]
[s'2]   [0d 09 0e 0b] [s2]
[s'3]   [0b 0d 09 0e] [s3]
```

**GF(2^8) 运算**：使用不可约多项式 `x⁸ + x⁴ + x³ + x + 1` (0x11B)。
- 加法 = XOR
- 乘法 = 多项式乘法再模不可约多项式

**作用**：提供列内的扩散，每个输出字节依赖同一列的所有输入字节。

### 4. AddRoundKey
将状态矩阵与轮密钥逐字节 XOR。轮密钥由密钥扩展算法生成。

### 5. 密钥扩展 (KeyExpansion)
从 16 字节主密钥生成 11 个轮密钥（每轮一个 + 初始密钥），每个轮密钥 16 字节。

算法：
```
for i in range(4, 44):
    temp = w[i-1]
    if i % 4 == 0:
        temp = SubWord(RotWord(temp)) ⊕ Rcon[i/4]
    w[i] = w[i-4] ⊕ temp
```

- **RotWord**：4 字节循环左移 1 字节
- **SubWord**：对 4 字节分别应用 S-Box
- **Rcon**：轮常量 `[x^(i-1), 0, 0, 0]`，在 GF(2^8) 中

## AES 工作模式

### ECB (Electronic Codebook)
- 每个块独立加密
- **优点**：可以并行，错误不传播
- **缺点**：相同明文块产生相同密文块，不安全（模式可见）
- 不适合加密多块数据

### CBC (Cipher Block Chaining)
- 每个块与前一个密文块 XOR 后再加密
- 需要初始化向量 IV（随机，16 字节）
- 解密：解密后与前一个密文块 XOR
- **优点**：相同的明文块产生不同的密文块
- **缺点**：不能并行加密，错误传播（一个块损坏影响两个块）

### PKCS7 填充
- 填充值 = 需要填充的字节数
- 如果数据块大小正好是 16 的倍数，则额外填充 16 个字节（值 0x10）
- 解密时根据最后一个字节的值移除对应数量的填充字节

## RSA 核心原理

### 数学基础

**欧拉定理**：若 a 与 n 互质，则 a^φ(n) ≡ 1 (mod n)，其中 φ(n) 为欧拉函数。

**RSA 正确性**：
- 选择两个大素数 p, q
- n = p × q
- φ(n) = (p-1)(q-1)
- 选择 e 满足 1 < e < φ(n)，gcd(e, φ(n)) = 1
- 计算 d ≡ e^(-1) (mod φ(n))
- 加密：c = m^e mod n
- 解密：m = c^d mod n
- 正确性验证：c^d ≡ m^(ed) ≡ m^(1+k·φ(n)) ≡ m × (m^φ(n))^k ≡ m (mod n)

### 密钥生成
1. 生成两个大素数 p, q（≥ 512 位，乘积 ≥ 1024 位）
2. 计算 n = p × q
3. 计算 φ(n) = (p-1)(q-1)
4. 选择公钥指数 e = 65537（常用）
5. 计算私钥指数 d = modinv(e, φ(n))

### Miller-Rabin 素性测试
概率性算法，误判率 4^(-k)（k 为测试轮数）：
1. 将 n-1 写成 2^s × d 形式
2. 随机选底数 a
3. 计算 x = a^d mod n
4. 重复平方 s 次
5. 若 x ≡ ±1 (mod n)，可能为素数

### 数字签名
- 签名：s = H(m)^d mod n（用私钥加密/签名）
- 验证：H(m) == s^e mod n（用公钥解密/验证）

## 安全注意事项

### 教科书 RSA 的缺陷（本实现使用 OAEP 缓解）
1. **确定性**：相同明文产生相同密文 → 使用 OAEP 引入随机性
2. **乘法同态**：E(m1) × E(m2) = E(m1×m2) → OAEP 破坏代數結構
3. **小指数攻击**：e=3 时多个相关消息可被恢复
4. **低熵攻击**：两个共享同一个素数的密钥可被分解

### OAEP (Optimal Asymmetric Encryption Padding)

OAEP 为加密前提供随机化填充，使用两个哈希函数 G 和 H：

```
m' = 0x00 || m || 0x00...0 (填充到 k-1 字节)
r = 随机数
X = m' ⊕ G(r)
Y = r ⊕ H(X)
输出 = 0x00 || X || Y
```

OAEP 提供：
- **密文不可区分性**（IND-CCA2 安全）
- 抵抗选择密文攻击
- 破坏代數同态性质

### 侧信道攻击
- **时序攻击**：通过测量加解密时间推断密钥 → 使用常数时间比较
- **功耗分析**：通过测量功耗分析密钥比特
- **缓存攻击**：S-Box 查表可能泄露信息
- **防御**：恒定时间实现、随机化遮蔽（blinding）

### 实际使用建议
- RSA 密钥至少 2048 位
- 使用 OAEP 或 PSS 填充
- p 和 q 应随机独立生成，差值不能过小
- e 通常选 65537 (0x10001)
- 考虑混合加密：用 RSA 加密 AES 密钥，用 AES 加密数据

## 实现细节

### 模幂运算
自实现快速幂（平方-乘算法），不使用 `pow(base, exp, mod)`：
```
def mod_pow(base, exp, mod):
    result = 1
    base = base % mod
    while exp > 0:
        if exp & 1:  # 最低位为1
            result = (result * base) % mod
        base = (base * base) % mod
        exp >>= 1
    return result
```

### Galois 域乘法
```python
def gf_mul(a, b):
    """GF(2^8) 乘法，不可约多项式 0x11B"""
    result = 0
    for _ in range(8):
        if b & 1:
            result ^= a
        carry = a & 0x80
        a = (a << 1) & 0xFF
        if carry:
            a ^= 0x1B  # 模 0x11B（低8位）
        b >>= 1
    return result
```
