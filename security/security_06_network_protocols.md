## HTTPS（SSL/TLS）

### 握手流程

```
你访问 https://baidu.com 时发生的事:

1. 你 → 百度: "我要安全连接"
   附带: 支持的TLS版本/加密套件列表/随机数

2. 百度 → 你: "好的，用TLS 1.3 + AES-GCM"
   附带: 百度的数字证书（包含公钥）+ 随机数

3. 你 → 百度: "证书验证通过"
   用公钥加密一个"预主密钥" → 发送
   
4. 双方根据随机数+预主密钥 → 计算出"会话密钥"

5. 之后 → 用会话密钥对称加密通信（AES）

# 关键:
# 非对称(RSA/ECC)只用来交换密钥
# 真正的通信是AES对称加密（快1000倍）
```

### 为什么不加密也危险

```python
# HTTP: 明文传输
# 你在咖啡厅连WiFi → 旁边可以看到你的密码

# HTTPS: 加密传输
# 旁边只看到一堆乱码

# 补充: TLS 1.3 (2018)
# 比TLS 1.2快（1轮往返vs2轮）
# 去掉了不安全的加密算法
# 现在的主流标准
```

## SSH（安全外壳协议）

```python
# 远程登录服务器

# 密码登录:
# ssh user@server.com → 输入密码

# 密钥登录（推荐）:
# 1. 本地生成密钥对: ssh-keygen
# 2. 把公钥复制到服务器: ssh-copy-id user@server.com
# 3. 以后登录: ssh user@server.com → 自动认证

# 比密码更安全（不会被暴力破解）
# 支持端口转发（当作加密代理用）
```

## VPN

```python
# 虚拟专用网络

# 没VPN: 你直接连互联网
# 中间（你的ISP/网络管理员）能看到你在访问什么

# 有VPN: 你 → VPN服务器 → 互联网
# 中间只能看到"你在连VPN服务器"
# 不知道你在干什么

# 重要: VPN加密你的流量
# 但VPN提供商也能看到你的流量 → 选靠谱的

# 常用协议:
# WireGuard — 现代，快，简单
# OpenVPN — 老牌，兼容性好
# IPSec — 企业级标准
```

## 防火墙

```python
# 控制"什么东西能进，什么东西能出"

# 规则示例:
# 允许: 任何人访问 80端口(HTTP)
# 允许: 任何人访问 443端口(HTTPS)
# 拒绝: 所有人访问 22端口(SSH)（只允许特定IP）
# 允许: 从内网访问 3306端口(MySQL)
# 拒绝: 所有其他入站连接

# 防火墙类型:
# 包过滤: 检查IP+端口（简单）
# 状态检测: 跟踪连接状态（常用）
# 应用层: 检查HTTP内容（WAF）
```

## IDS/IPS

```python
# IDS (入侵检测系统):
# 看流量 → 发现可疑模式 → 报警
# 不做阻止（只监控）

# IPS (入侵防御系统):
# 发现攻击 → 自动阻断连接
# 实时防御

# Snort: 开源的IDS/IPS
# Suricata: 现代替代品（支持多线程）
```

## 今日收获
- HTTPS = 非对称交换密钥 → 对称加密通信
- TLS 1.3 = 更快更安全的现代标准
- SSH密钥 = 比密码安全（推荐所有服务器用）
- VPN = 加密你的所有流量（但信任VPN提供商）
- 防火墙 = 入站出站规则，IDS = 监控，IPS = 阻断
