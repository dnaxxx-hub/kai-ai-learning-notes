## 核心安全工具

### 1. nmap — 端口扫描

```bash
# 扫描目标开放了哪些端口
nmap -sV target.com
# -sV: 检测服务版本

# 常见端口:
# 22 - SSH
# 80 - HTTP
# 443 - HTTPS
# 3306 - MySQL
# 6379 - Redis
# 8080 - 常见Web代理
```

### 2. Wireshark — 抓包分析

```bash
# 捕获和分析网络流量
# 可以: 看HTTP请求内容 / 检查TLS握手 / 识别异常流量

# 关键: 不要在自己的网络之外抓包（法律问题）
# 本地调试: 看自己应用的网络请求
```

### 3. Burp Suite — Web代理

```bash
# Web渗透测试的标准工具

# 功能:
# - 拦截和修改HTTP请求
# - 自动扫描漏洞
# - 暴力破解/字典攻击
# - 解码/编码器
# - Repeater（重放请求手动测试）
```

### 4. Metasploit — 漏洞利用框架

```bash
# "漏洞利用的瑞士军刀"

# 使用场景: 在授权环境中测试系统是否容易受攻击
```

## 防御策略

### 开发阶段

```python
# 1. 安全培训 — 每个开发者都要懂OWASP Top 10
# 2. 安全代码审查 — 自动化+人工
# 3. SAST (静态应用安全测试) — 代码扫描工具
# 4. 依赖检查 — 检查第三方库有没有已知漏洞
```

### 部署阶段

```python
# 1. DAST (动态应用安全测试) — 运行时的漏洞扫描
# 2. WAF (Web应用防火墙) — 过滤恶意流量
# 3. 最小化部署 — 只开需要的端口/服务
# 4. 容器安全 — 镜像扫描/运行时安全
```

### 运营阶段

```python
# 1. 日志监控 — 异常行为检测
# 2. 漏洞管理 — 持续扫描+修复
# 3. 备份策略 — 3-2-1规则（3份/2种介质/1份异地）
# 4. 应急响应 — 被攻击了怎么办
# 5. 渗透测试 — 定期请人攻击自己的系统
```

## 个人安全最佳实践

```python
# 1. 密码管理器（Bitwarden/1Password）
# 2. 双因素认证（能开都开）
# 3. 软件及时更新（零日漏洞无法防，已知漏洞必须修）
# 4. 不点陌生链接/附件
# 5. 敏感操作从干净环境操作
# 6. 备份重要数据
# 7. 公共WiFi用VPN
```

## 今日收获
- 渗透测试 = 模拟黑客攻击 → 找漏洞 → 修复
- 核心工具：nmap/Wireshark/Burp Suite/Metasploit
- 安全贯穿整个开发生命周期：开发→部署→运营
- **没有银弹**，安全是持续的过程
- 个人的安全习惯比任何技术防御都重要
