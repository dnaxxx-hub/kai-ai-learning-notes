## 1. 什么是格（Lattice）

### 1.1 数学定义

**格**是 $\mathbb{R}^n$ 中的一个**离散加法子群**。通俗说：格是 $\mathbb{R}^n$ 中一组点，这些点由若干个基向量的**整数线性组合**构成，且点与点之间有"空隙"（离散性）。

**形式定义**：给定 $n$ 个线性无关的向量 $b_1, b_2, \ldots, b_n \in \mathbb{R}^n$，格 $\mathcal{L}$ 是这些向量的所有整数线性组合：

$$\mathcal{L}(b_1, \ldots, b_n) = \left\{\sum_{i=1}^n x_i b_i \mid x_i \in \mathbb{Z}\right\}$$

**关键性质**：
- **加法封闭**：两个格点相加仍在格中
- **离散性**：存在一个最小距离，任何两个不同格点的距离不小于该值
- **基不唯一**：同一个格可以有不同的一组基

### 1.2 格基（Lattice Basis）

一组基向量 $B = [b_1 | b_2 | \cdots | b_n] \in \mathbb{R}^{n \times n}$。

**好基 vs 坏基**：
- "好基"：向量接近正交，长度短 → 便于密码学中构造困难问题
- "坏基"：向量长且夹角小 → 用于加密，别人难以从中恢复出好基

```
好基（近似正交）：        坏基（狭长）：
    ↑                      ↗
   /                       /
  /   →                   /
 →                       → 
```

### 1.3 二维格示例

最简单的格：**整数格** $\mathbb{Z}^2$，即二维平面上所有整数坐标点 $(x, y)$，其中 $x, y \in \mathbb{Z}$。

```
    |   .   .   .   .   .
    |   .   .   .   .   .
    |   .   .   .   .   .
    |   .   .   .   .   .
    |   .   .   .   .   .
    +---------------------->
```

基向量可以是 $b_1 = (1, 0)$，$b_2 = (0, 1)$，这是"好基"。
也可以是 $b_1 = (2, 1)$，$b_2 = (1, 1)$，这是"坏基"（但生成同一个格！）。

> 🔑 **格密码的核心洞察**：同一个格有"好基"和"坏基"。好基容易做困难问题，坏基很难。如果你有坏基，在上面找最短向量很难；如果你有好基，就容易。

## 2. 格上的困难问题

格密码的安全基础建立在几个**格困难问题**上。

### 2.1 SVP — 最短向量问题（Shortest Vector Problem）

**定义**：给定格 $\mathcal{L}$ 的一组基，找格中**长度最短的非零向量**。

```
输入：格基 B
输出：v ∈ ℒ\{0}，使得 ‖v‖ 最小

难度：NP-hard（在精确意义下）
        在近似意义下（找近似最短），也是困难的
```

**几何意义**：想象一堆格点，找到离原点最近的那个（除了原点自己）。

```
  短向量 →  ← 更短向量（SVP 解）
   .  .  .  .
   .  .  .  .
   .  .  .  .
   .  .  .  .
```

### 2.2 CVP — 最近向量问题（Closest Vector Problem）

**定义**：给定格 $\mathcal{L}$ 的一组基和一个目标点 $t \in \mathbb{R}^n$，找到格中**离 t 最近的格点**。

```
输入：格基 B，目标点 t（不一定在格上）
输出：v ∈ ℒ，使得 ‖v - t‖ 最小

难度：也是 NP-hard
        比 SVP 至少一样难（CVP 可以归约到 SVP）
```

**几何意义**：你站在平面上任意一点，找最近的格点。

```
        x ← 目标点 t
    .   .       .
        ↑
     最近格点 v  .
    .   .       .
```

### 2.3 LWE — 带误差学习（Learning With Errors）

这是**现代格密码中最核心的困难问题**。

**定义**：给定 $n$ 维向量 $s \in \mathbb{Z}_q^n$（秘密），分布如下：

$$\text{LWE 分布：} (A, b = A \cdot s + e \pmod{q})$$

其中：
- $A$：$m \times n$ 随机矩阵（$m \gg n$），$\mathbb{Z}_q$ 上的均匀随机
- $s$：秘密向量，$\mathbb{Z}_q^n$
- $e$：小误差向量，从离散高斯分布或小均匀分布采样
- $q$：模数（通常是一个较大的素数）

**困难问题**：给定多组 $(A, b)$ 样本，恢复 $s$。

**为什么困难？**

如果没有 $e$，$b = A \cdot s$ 是一个**线性方程组**，高斯消元即可解出 $s$。

有了 $e$，问题变成：
- 每个等式 $b_i = \langle a_i, s\rangle + e_i$
- $e_i$ 很小但未知
- 你无法确定哪个解是正确的，因为调整 $s$ 一点就产生另一个"几乎正确"的解

> 💡 **直觉**：LWE 可以看作是一个**带噪线性系统**。误差把精确解变成了一个"模糊区域"，求精确解是 NP-hard。

**密码学中的 LWE 悖论**：私钥 $s$ 本身很"小"（分量在 $\{-1,0,1\}$ 或很小的范围），但 $A$ 是均匀随机的。拥有私钥的人可以用 $s$ 来"消除噪声"；没有私钥的人必须解困难问题。

### 2.4 Ring-LWE — 环上的 LWE

Ring-LWE 是 LWE 在**多项式环**上的版本，大幅提高了效率。

**定义**：在多项式环 $R_q = \mathbb{Z}_q[x]/(x^n + 1)$ 上：

$$\text{Ring-LWE：} b(x) = a(x) \cdot s(x) + e(x) \pmod{q, x^n+1}$$

其中 $a(x), s(x), e(x)$ 都是环上的多项式。

**好处**：
- 一个 Ring-LWE 样本 = $n$ 个并行 LWE 样本（因为按系数展开就是 LWE）
- 密钥大小从 $O(n^2)$ 降到 $O(n)$
- 运算使用 NTT（数论变换）加速，接近 $O(n \log n)$

**多项式结构**：
```
a(x) = a₀ + a₁·x + a₂·x² + ... + a_{n-1}·x^{n-1}
s(x) = s₀ + s₁·x + s₂·x² + ... + s_{n-1}·x^{n-1}
e(x) = e₀ + e₁·x + e₂·x² + ... + e_{n-1}·x^{n-1}
b(x) = a(x)·s(x) + e(x) (mod q, mod x^n+1)
```

## 3. 格密码应用

格密码在**后量子密码学**中占据统治地位。NIST 已标准化的三个格密码方案：

### 3.1 Kyber — 密钥封装机制（KEM / ML-KEM）

**NIST 标准：FIPS 203 (ML-KEM)**

- **基础**：Module-LWE（MLWE），在模块 $R_q^k$ 上做 LWE
- **用途**：密钥封装（类似 ECDH，但能抵抗量子攻击）
- **规模**：Kyber-512 公钥 800B，密文 768B（比 RSA 小多了）

**基本原理**（类似 Diffie-Hellman 但基于 LWE）：
```
Alice:                          Bob:
  s_A, e_A ← χ (小高斯噪声)      s_B, e_B ← χ
  b_A = A·s_A + e_A              b_B = A·s_B + e_B
  → 发送 b_A                                           ← 发送 b_B
  共享密钥 = s_A^T·b_B            共享密钥 = b_A^T·s_B
            ≈ s_A^T·A·s_B                   ≈ s_A^T·A·s_B
```

两边计算的密钥不完全相等（有噪声），需要用**纠错/压缩**来对齐。

### 3.2 Dilithium — 数字签名（ML-DSA）

**NIST 标准：FIPS 204 (ML-DSA)**

- **基础**：Module-LWE + Fiat-Shamir 变换（把身份识别协议变成签名）
- **用途**：数字签名
- **特点**：签名约 2.4KB，公钥约 1.3KB（ML-DSA-65）

**设计思路**：
1. 证明者知道一个"短向量"（私钥）
2. 使用 Fiat-Shamir 变换将交互式证明转为非交互式签名
3. 拒绝采样保证签名不泄露私钥信息

### 3.3 Falcon — 紧凑签名

- **基础**：NTRU 格签名 + GPV 框架
- **特点**：签名极小（~666 Bytes for Falcon-512），但实现复杂
- **现状**：NIST 已选择 Dilithium 为主标准，Falcon 进入第二轮

### 3.4 全同态加密（FHE）

格密码是**全同态加密（Fully Homomorphic Encryption, FHE）**的基石。

**FHE 能力**：对加密数据做**任意计算**，结果解密后等于对明文计算的加密结果。

```
E(a) ○ E(b) = E(a ○ b)  其中 ○ 可以是 +, ×, 任意函数
```

**主要方案**：
| 方案 | 基础 | 特点 |
|------|------|------|
| **CKKS** | RLWE | 近似计算，适合浮点数/机器学习 |
| **BFV** | RLWE | 精确整数计算 |
| **TFHE** | LWE | 布尔电路，快速，门电路级 |
| **BGV** | RLWE | 整数的层级同态加密 |

**为什么格能支持 FHE？**
- LWE 密文中的噪声在运算中增长
- 加法：噪声线性增长（小）
- 乘法：噪声平方增长（大）
- **Bootstrapping**（自举）：把密文解密后再加密的过程（在加密状态下），重置噪声

## 4. LWE 加解密原理解析

### 4.1 密钥生成

```
输入：安全参数 n（维度），模数 q
输出：私钥 s，公钥 (A, b)

1. 随机生成矩阵 A ← ℤ_q^{n×n}
2. 采样小向量 s ∈ ℤ_q^n（从 {-1,0,1} 或离散高斯分布）
3. 采样小误差向量 e（离散高斯分布）
4. 计算 b = A·s + e (mod q)
5. 私钥：s
   公钥：(A, b)
```

公钥看上去均匀随机，但实际上包含了"嵌入的私钥信息"——只是被噪声隐藏了。

### 4.2 加密

```
输入：公钥 (A, b)，明文消息 m ∈ {0,1}
输出：密文 (c₁, c₂)

1. 随机采样向量 r ∈ ℤ_q^n（小元素）
2. 随机采样误差 e₁, e₂（小高斯噪声）
3. 计算：
   c₁ = A^T·r + e₁  (mod q)
   c₂ = b^T·r + e₂ + ⌊q/2⌋·m  (mod q)
                      ↑ 把 bit 编码到高位
4. 输出密文 (c₁, c₂)
```

**编码技巧**：
- 消息是 1 bit：$m \in \{0, 1\}$
- 编码：如果 $m=0$，加 0；如果 $m=1$，加 $q/2$
- 这样密文被"拉到"两个不同的区域

### 4.3 解密

```
输入：私钥 s，密文 (c₁, c₂)
输出：明文 m

1. 计算：
   d = c₂ - s^T·c₁  (mod q)

2. 推导：
   d = c₂ - s^T·c₁
     = (b^T·r + e₂ + ⌊q/2⌋·m) - s^T·(A^T·r + e₁)
     = (A·s + e)^T·r + e₂ + ⌊q/2⌋·m - s^T·A^T·r - s^T·e₁
     = s^T·A^T·r + e^T·r + e₂ + ⌊q/2⌋·m - s^T·A^T·r - s^T·e₁
     = e^T·r + e₂ - s^T·e₁ + ⌊q/2⌋·m
     = small_noise + ⌊q/2⌋·m

3. 判断：
   if |d| < q/4  →  m = 0
   if |d| > q/4  →  m = 1
```

**为什么能解密？**
噪声项 $e^T·r + e₂ - s^T·e₁$ 远小于 $q/4$（如果参数选得合理），所以：
- $m=0$ 时，$d \approx 0$（小噪声）
- $m=1$ 时，$d \approx q/2$（加噪声扰动）

判断 d 离 0 还是 q/2 更近即可。

```
q 轴：
0        q/4       q/2       3q/4       q
├──────────┼──────────┼──────────┼──────────┤
← m=0 区域 →   ← m=1 区域 →   ← m=0 区域 →
```

### 4.4 参数选择

关键参数：
- **n**：维度（安全强度正相关，~256-1024）
- **q**：模数（~$n^2$ 到 $n^3$ 量级）
- **噪声分布**：离散高斯，标准差 $\sigma \approx 3-8$
- **安全性与效率的平衡**：n 越大越安全但越慢

### 5.2 密钥交换（LWE-based Diffie-Hellman）

类似 DH 但基于 LWE：
```
Alice 生成: sA, eA, bA = A·sA + eA   → 发送 bA
Bob   生成: sB, eB, bB = A·sB + eB   → 发送 bB

Bob   计算: K_B = bA^T·sB
```

## 6. 格密码 vs 传统公钥密码

| 特性 | RSA/ECC | 格密码 |
|------|---------|--------|
| **量子抵抗** | ❌ 被 Shor 算法破解 | ✅ 目前无量子加速攻击 |
| **安全假设** | 大整数分解/离散对数 | LWE/SVP/CVP (NP-hard) |
| **密钥大小** | 小（256b-4KB） | 中（~1-3KB） |
| **计算速度** | 快 | 中等（尤其 Ring-LWE 很快） |
| **最坏情况安全** | ❌ | ✅ （格问题的最坏情况困难性归约到平均情况） |
| **FHE 支持** | ❌ | ✅ 天然支持 |

## 8. 格密码核心概念速查表

| 概念 | 定义 |
|------|------|
| **格 (Lattice)** | $\mathbb{R}^n$ 中的离散加法子群，整数线性组合 |
| **基 (Basis)** | 生成格的线性无关向量组 |
| **SVP** | 找格中最短非零向量 |
| **CVP** | 找格中离给定点最近的格点 |
| **LWE** | 带误差的线性系统，解 s 困难 |
| **Ring-LWE** | 多项式环上的 LWE，更高效 |
| **Kyber (ML-KEM)** | 基于 MLWE 的密钥封装，NIST 标准 |
| **Dilithium (ML-DSA)** | 基于 MLWE 的数字签名，NIST 标准 |
| **FHE** | 全同态加密，基于 RLWE 的密文计算 |
| **Bootstrapping** | FHE 中重置密文噪声的机制 |
| **离散高斯** | LWE 中误差采样常用分布 |
| **模数 q** | 密码运算的模数，决定安全与效率 |

---

> **格密码是后量子时代的密码标准**。LWE 问题在量子计算机上不存在已知的亚指数攻击，且其最坏情况困难性与平均情况困难性之间存在安全性归约，理论基础非常坚实。
