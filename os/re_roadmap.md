# 体系结构与逆向工程 — 学习路线图

## 为什么学这个？
现有24个方向覆盖纯算法/系统/ML，但**底层硬件级理解**是空白的。
理解 CPU 怎么跑代码、内存怎么布局、二进制怎么执行 — 这些知识是"朝下看"的视角，
与现有的"朝上看"（应用/框架/架构）形成互补。

## 路线

### Phase 1: 计算机体系结构深潜 (4课)
1. CPU流水线 + 分支预测 + 乱序执行 (己有部分笔记，深化)
2. 缓存层级 + 一致性协议 (MESI/MOESI)
3. 虚拟内存 + TLB + 页表深度
4. 中断/异常/系统调用全过程

### Phase 2: x86-64 汇编实战 (4课)
5. x86-64 寄存器模型 + 寻址模式 + 常用指令
6. 调用约定 + 栈帧 + 函数调用全过程
7. SIMD (SSE/AVX) 高级操作
8. 手写汇编与 C 混合编程

### Phase 3: 逆向工程 (4课)
9. PE/ELF 文件格式深度解析
10. 静态分析 (Ghidra/IDA/objdump)
11. 动态调试 (WinDbg/x64dbg/GDB)
12. 常见逆向手法（反调试/反反调试/代码混淆）

### Phase 4: 底层安全实践 (4课)
13. 栈溢出/ROP/ASLR 绕过原理
14. Shellcode 编写
15. Fuzzing 实践
16. VMP/虚拟化保护分析

- 一个完整的 PE 分析工具 (Python)
