# 课时4：Shor 算法

## 一、问题背景：因数分解

给定一个 N = p × q（p、q 为大素数），求 p 和 q。

**经典算法**：数域筛法（NFS），时间复杂度 O(exp(c(log N)^{1/3}(log log N)^{2/3}))——亚指数但非多项式。

**Shor 算法**：时间复杂度 O((log N)³)——**多项式时间**！对 RSA 密码系统构成根本性威胁。

## 二、Shor 算法框架

### 2.1 步骤概述

```
输入：合数 N
输出：N 的一个非平凡因子

1. 若 N 为偶数，直接返回 2
2. 若 N = a^b，用经典方法求根
3. 随机选 1 < a < N，计算 gcd(a,N)，若 ≠ 1 则返回该因子
4. **量子部分**：用量子相位估计求 a 模 N 的阶 r（周期）
5. **经典部分**：用 r 计算因子
```

### 2.2 关键数学原理

选择 a，考虑模指数函数：
```
f(x) = a^x mod N
```
f(x) 是周期函数，周期 r：
```
a^r ≡ 1 (mod N)
```

如果 r 为偶数且 a^{r/2} ≠ -1 mod N，则：
```
a^r - 1 = (a^{r/2} - 1)(a^{r/2} + 1) ≡ 0 (mod N)
```
所以 gcd(a^{r/2} ± 1, N) 给出 N 的因子。

## 三、量子部分：周期发现

### 3.1 量子线路

```
|0⟩^⊗n ——H^⊗n———•———QFT†——— 测量
                  |
|1⟩^⊗m ————————U_f———————
```

其中 U_f|x⟩|y⟩ = |x⟩|y⊕a^x mod N⟩

### 3.2 算法流程

1. 初始化两个寄存器：2n 比特（n ≈ log₂N）
2. 第一个寄存器应用 H^⊗n，产生叠加态：
   ```
   (1/√(2ⁿ)) Σ_{x=0}^{2ⁿ-1} |x⟩|0⟩
   ```
3. 应用模指数 U_f：
   ```
   (1/√(2ⁿ)) Σ_{x=0}^{2ⁿ-1} |x⟩|a^x mod N⟩
   ```
4. 测量第二个寄存器，坍缩到某个 |y⟩，第一个寄存器变为：
   ```
   (√(r)/√(2ⁿ)) Σ_{k=0}^{⌊(2ⁿ-1)/r⌋} |x₀ + kr⟩
   ```
   其中 x₀ 是满足 a^{x₀} ≡ y mod N 的最小值

5. 对第一个寄存器应用逆量子傅里叶变换（QFT†）
6. 测量第一个寄存器，得到相位 φ ≈ s/r（s 为随机整数）

### 3.3 连分式展开

从测量值 m = φ × 2ⁿ 恢复 r：
```
用连分式展开 m/2ⁿ，找到分母 ≤ N 的最佳近似
这个分母就是 r 或 r 的因子
```

## 四、经典后处理

### 4.1 从 r 求因子

```
若 r 为偶数且 a^{r/2} ≠ -1 mod N：
    p = gcd(a^{r/2} - 1, N)
    q = gcd(a^{r/2} + 1, N)
否则重新选 a
```

### 4.2 成功概率
- 随机选 a 时，r 为偶数且 a^{r/2} ≠ -1 的概率 ≥ 3/4
- QFT 测量给出正确 r 的概率 ≥ O(1/log(r))
- 只需重复 O(log r) ≈ O(log N) 次

## 五、RSA 破解原理

### 5.1 RSA 回顾
- 公钥：N = pq, 加密指数 e
- 私钥：解密指数 d = e⁻¹ mod φ(N)
- 破解 RSA = 求 d = 分解 N

### 5.2 Shor 的威胁
- 2048 位 RSA：经典需要 ~10¹⁵ 年
- 相同规模量子计算机：~数秒（约数亿量子门）
- 一旦大规模容错量子计算机建成，RSA 将被彻底打破

## 关键结果
- Shor 算法是量子计算最具代表性的优势证明
- 量子计算机对 RSA 的威胁推动了**后量子密码学**（PQC）的发展
- 当前 NIST 已标准化基于格的加密/签名方案（CRYSTALS-Kyber/Dilithium）
