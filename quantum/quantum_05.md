# 课时5：量子傅里叶变换 (QFT)

## 一、QFT 定义

### 1.1 数学定义
量子傅里叶变换将计算基映射到傅里叶基：

```
QFT|j⟩ = (1/√N) Σ_{k=0}^{N-1} ω^{jk} |k⟩
```
其中 ω = e^{2πi/N}，N = 2ⁿ，n 为量子比特数。

### 1.2 矩阵表示
```
QFT_N = (1/√N) [ω^{jk}]_{j,k=0}^{N-1}
```

#### 2 比特示例 (N=4)
```
QFT₄ = ½ [1 1 1 1; 1 i -1 -i; 1 -1 1 -1; 1 -i -1 i]
```

#### 3 比特 QFT 作用于 |001⟩
```
QFT|001⟩ = ½[|000⟩ + i|010⟩ - |100⟩ - i|110⟩ + |001⟩ + i|011⟩ - |101⟩ - i|111⟩]
         （经归一化：共 8 个分量，每项系数 ±1/2√2 或 ±i/2√2）
```

## 二、QFT 线路实现

### 2.1 乘积表示
```
QFT|j₁j₂...jₙ⟩ = (1/√2ⁿ) (|0⟩ + e^{2πi0.jₙ}|1⟩) 
                          ⊗ (|0⟩ + e^{2πi0.j_{n-1}jₙ}|1⟩)
                          ⊗ ...
                          ⊗ (|0⟩ + e^{2πi0.j₁j₂...jₙ}|1⟩)
```
其中 0.j₁j₂...jₖ = Σ_{l=1}^{k} j_l/2^l 是二进制小数表示。

### 2.2 线路结构

QFT 使用 H 门和受控旋转门 R_k：
```
R_k = [1 0; 0 e^{2πi/2^k}]
```

线路：
```
|j₁⟩ —H——R₂——R₃——...Rₙ————•——SWAP—— 
                             |
|j₂⟩ —————————————•—————————|———————
                   |         |
|j₃⟩ —————————•————R₂——————|———————
              |              |
⋮             ⋮             ⋮
|jₙ⟩ ——————————————H———————•———————
```

### 2.3 复杂度
- 经典 FFT：O(N log N)，其中 N = 2ⁿ
- 量子 QFT：O(n²) = O((log N)²)，**指数级加速**
- 使用近似 QFT 可进一步降低到 O(n log n)

### 2.4 逆 QFT (QFT†)

QFT 的逆变换，通过反转线路并取共轭转置：
- 将受控旋转角度取负：R_k → R_k†
- 反转门的执行顺序

```
QFT† = QFT^{-1} = (1/√N) Σ_{j,k=0}^{N-1} ω^{-jk} |j⟩⟨k|
```

## 三、量子相位估计 (QPE)

### 3.1 问题定义
给定酉算子 U 和其特征向量 |u⟩，求特征值：
```
U|u⟩ = e^{2πiφ}|u⟩
```
其中 φ ∈ [0,1) 是待估计的相位。

### 3.2 算法线路

```
|0⟩^⊗t —H^⊗t———————•—————QFT†——— 测量（得到 φ 的 t 比特近似）
                     |
|u⟩ ———————————————U^{2^j}—————— 
```

### 3.3 算法步骤

1. 初始化 t 个辅助比特和 |u⟩：

2. 对辅助比特应用 H^⊗t：
   ```
   (1/√(2ᵗ)) Σ_{k=0}^{2ᵗ-1} |k⟩|u⟩
   ```

3. 应用受控 U^{2^j} 门：
   ```
   (1/√(2ᵗ)) Σ_{k=0}^{2ᵗ-1} e^{2πikφ}|k⟩|u⟩
   ```

4. 辅助比特的状态恰好是：
   ```
   (1/√(2ᵗ)) Σ_{k=0}^{2ᵗ-1} e^{2πikφ}|k⟩
   ```

5. 应用逆 QFT，测量得到 φ 的 t 比特近似

### 3.4 精度与成功概率

如果 φ 精确到 t 比特，QPE 给出精确结果。
如果 φ 不是 t 比特二进制小数，测量以概率 ≥ 4/π² 给出 t 比特精度近似。

### 3.5 QPE 的应用

QPE 是量子计算的**核心子程序**，用于：
- Shor 算法中的周期发现
- 量子化学中的哈密顿量本征值求解
- 量子机器学习中的特征值估计

## 关键结果
- QFT 是实现量子指数级加速的核心组件
- QPE 所需门数：O(t²)，经典等效需要 O(2ᵗ) 步
- Kitaev 的迭代相位估计可在 O(t log t) 门内实现等价功能
