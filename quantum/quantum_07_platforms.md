## 超导量子比特

### 原理
基于超导约瑟夫森结的非线性电感，形成可控制的量子二能级系统。

```
基础物理：
超导环 → 约瑟夫森结 → LC振荡器 → 非线性 → 量子比特
```

### 主要实现
| 类型 | 特点 | 代表 | 现状 |
|------|------|------|------|
| Transmon | 电荷噪声不敏感 | Google/IBM | 主流 |
| Fluxonium | 更低退相干 | 实验室 | 研究 |
| Xmon | 更好的耦合 | Google | 被Sycamore取代 |

### 代表系统
- **Google Sycamore**：53比特，实现量子霸权
- **IBM Eagle**：127比特
- **IBM Osprey**：433比特
- **Google Willow**：105比特（码距d=7的表面码）

### 优缺点
| 优点 | 缺点 |
|------|------|
| 门速度：10-100ns | T1短：~100μs |
| 芯片级集成 | 需要极低温（10mK） |
| 制造工艺成熟 | 串扰问题随规模增大 |
| 两比特门成熟 | 需要大量布线(每个比特1个微波线) |

## 离子阱

### 原理
用电磁场囚禁离子，利用离子的内能级或振动模式作为量子比特。

```
激光或微波控制
    ↓
┌─────┐
│ Ion │ ← 电磁场囚禁
└─────┘
    ↑
激光冷却
```

### 代表性
- **IonQ Aria**：25比特，99.96%双门保真度
- **Quantinuum H2**：56比特
- **Honeywell**：10比特量子电荷耦合架构

### 优缺点
| 优点 | 缺点 |
|------|------|
| 极长相干时间 (秒级) | 门速度慢 (μs) |
| 全连接性 (任意门) | 难扩展到大量离子 |
| 最高门保真度 | 需要超高真空 |
| 完全相同的量子比特 | 激光系统复杂 |

## 光量子计算

### 原理
利用光子（光的量子）作为飞行量子比特。

```
偏振编码：|H⟩ = |0⟩, |V⟩ = |1⟩
路径编码：上路= |0⟩, 下路= |1⟩
时间仓编码：早= |0⟩, 晚= |1⟩
```

### 代表
- **Xanadu Borealis**：216压缩态模式
- **USTC 九章**：光子玻色采样实现量子优势

### 优缺点
| 优点 | 缺点 |
|------|------|
| 室温运行 | 双光子门困难（需非线性） |
| 天然适合光子网络 | 光子损耗 |
| 极高的时钟频率 | 难以确定性生成 | 
| 成熟的硅光技术 | 测量导致坍缩 |

## 拓扑量子计算

### 原理
利用任意子的非阿贝尔统计特性，实现拓扑保护的量子比特。

```
二个任意子的缠绕 → 量子门
拓扑保护 → 自然纠错
```

### 现状
- **Microsoft StationQ**：马约拉纳费米子实验
- 2023年：宣布首次观测到拓扑量子比特
- 仍处于基础物理验证阶段

### 理想的优势
| 优点 | 挑战 |
|------|------|
| 天然抗噪声 | 尚未证明存在 |
| 无需QEC一层 | 制造极其困难 |
| 门精度极高 | 温度要求苛刻 |
| 理论上最稳定 | 操作速度慢 |

## 新兴平台

### 中性原子阵列
- **QuEra**：256个中性原子
- 用光镊阵列囚禁原子
- 可重排阵列，全局控制
- T1长达数秒

### NV色心
- 室温量子比特
- 自旋-光子界面
- 量子传感应用为主
- 可扩展性有限

## 平台选择策略

```
短期（2025-2027）：超导 + 离子阱 继续主导
中期（2028-2030）：中性原子追赶，拓扑技术验证
长期（2030+）：拓扑可能胜出，但不确定
```

### 应用匹配
| 应用 | 适合平台 | 理由 |
|------|---------|------|
| 化学模拟 | 超导、离子阱 | 深度浅，高保真 |
| 优化问题 | 中性原子 | 大数量子比特 |
| 密码学 | 离子阱、超导 | 高保真长电路 |
| 量子网络 | 光量子、NV | 光子接口 |

## 总结
- 超导量子比特当前规模最大，IBM/Google领跑
- 离子阱的保真度最高，适合高精度应用
- 光量子室温运行，适合量子网络
- 拓扑量子计算是最终目标但还需关键突破
- 中性原子正在快速追赶，性价比潜力大
- 不同物理平台适合不同的应用场景
