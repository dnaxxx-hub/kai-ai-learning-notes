# 课时3：量子算法基础

## 一、Deutsch-Jozsa 算法

### 1.1 问题定义
给定一个布尔函数 f: {0,1}ⁿ → {0,1}，已知 f 要么是**常值**（对所有输入输出相同），要么是**平衡**（恰好一半输入输出 0，一半输出 1）。

**经典复杂度**：最坏情况需要 2ⁿ⁻¹ + 1 次查询
**量子复杂度**：只需 1 次查询！

### 1.2 算法线路

```
|0⟩^⊗n ———H^⊗n———U_f———H^⊗n——— 测量
|1⟩ —————H———————————————    （辅助比特，可忽略测量）
```

其中 U_f|x⟩|y⟩ = |x⟩|y⊕f(x)⟩

### 1.3 算法步骤

1. 初始化 n+1 个量子比特：|0⟩^⊗n|1⟩
2. 对所有比特应用 H 门：
   ```
   |ψ₁⟩ = (1/√(2ⁿ)) Σ_{x∈{0,1}ⁿ} |x⟩ ⊗ (|0⟩-|1⟩)/√2
   ```
3. 应用 Oracle U_f：
   ```
   |ψ₂⟩ = (1/√(2ⁿ)) Σ_x (-1)^{f(x)}|x⟩ ⊗ (|0⟩-|1⟩)/√2
   ```
4. 对前 n 比特再次应用 H 门：
   ```
   |ψ₃⟩ = (1/2ⁿ) Σ_x Σ_z (-1)^{f(x) + x·z} |z⟩ ⊗ (|0⟩-|1⟩)/√2
   ```
5. 测量前 n 比特：
   - 结果为 |0⟩^⊗n ⟹ f 是**常值**（所有 (-1)^{f(x)} = 1）
   - 结果为非零 ⟹ f 是**平衡的**

### 1.4 为什么只需要一次查询？
相位编码技巧（phase kickback）：将 f(x) 信息编码到 |x⟩ 的相位中，无需逐次查询。

## 二、Grover 搜索算法

### 2.1 问题定义
在 N = 2ⁿ 个无序元素中搜索一个标记元素。设标记态为 |t⟩。

**经典复杂度**：O(N) 次查询
**量子复杂度**：O(√N) 次查询（**平方加速**）

### 2.2 算法步骤

1. 初始化：|ψ₀⟩ = H^⊗n|0⟩^⊗n = (1/√N) Σ_x |x⟩
2. 重复 O(√N) 次 Grover 迭代：
   a. **Oracle**：标记目标态
      ```
      O|x⟩ = (-1)^{f(x)}|x⟩
      其中 f(t)=1, 其他 f(x)=0
      ```
   b. **扩散算子**：关于平均值的翻转
      ```
      D = 2|s⟩⟨s| - I, 其中 |s⟩ = (1/√N) Σ_x|x⟩
      ```

### 2.3 几何解释

在由 |t⟩（目标态）和 |s'⟩（非目标态的平均）张成的二维子空间中：
- |ψ₀⟩ 与 |t⟩ 的初始夹角为 θ = arcsin(2/√N)
- 每次 Grover 迭代旋转 2θ
- 经过 k ≈ (π/4)√N 次迭代后，|ψ⟩ ≈ |t⟩

### 2.4 平方加速证明

设 M 为标记态数量：
- 迭代次数：k ≈ (π/4)√(N/M)
- 当 M=1：k ≈ (π/4)√N ≈ O(√N)
- 成功概率：sin²((2k+1)θ) → 接近 1

## 三、算法比较

| 算法 | 经典 | 量子 | 加速比 |
|------|------|------|--------|
| Deutsch-Jozsa | O(2ⁿ) | O(1) | 指数级 |
| Grover 搜索 | O(N) | O(√N) | 平方级 |
| Shor 因数分解 | 亚指数 | O((log N)³) | 指数级 |

## 关键结果
- Deutsch-Jozsa 是第一个展示量子指数级加速的算法（虽然问题人为）
- Grover 搜索的平方加速已被证明是最优的（不可能有更快量子算法）
- Oracle 模型是理解量子算法的重要框架
