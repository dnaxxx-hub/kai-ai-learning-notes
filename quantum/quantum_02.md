# 课时2：纠缠 & Bell态

## 一、纠缠态 (Entanglement)

### 1.1 什么是纠缠
如果两个量子比特的整体态无法写成两个单比特态的**张量积**：
```
|ψ⟩ ≠ |a⟩ ⊗ |b⟩
```
则称这两个量子比特是**纠缠的**。

### 1.2 Bell 态（最大纠缠态）

四个 Bell 态构成正交基：
```
|Φ⁺⟩ = (|00⟩ + |11⟩)/√2
|Φ⁻⟩ = (|00⟩ - |11⟩)/√2
|Ψ⁺⟩ = (|01⟩ + |10⟩)/√2
|Ψ⁻⟩ = (|01⟩ - |10⟩)/√2
```

**制备 Bell 态**：H 门 + CNOT
```
|00⟩ → H⊗I → (|0⟩+|1⟩)|0⟩/√2 → CNOT → (|00⟩+|11⟩)/√2 = |Φ⁺⟩
```

### 1.3 纠缠的性质
- 对其中一个比特测量会**即时**影响另一个（非局域性）
- 不可用于超光速通信（No-Communication Theorem）
- 纠缠是量子计算优势的核心资源

## 二、Bell 不等式与 CHSH

### 2.1 经典局域实在论
局域隐变量理论认为：测量结果由预先存在的"隐变量"决定，且测量一个粒子不影响另一个。

### 2.2 CHSH 不等式
Clauser-Horne-Shimony-Holt 不等式，用于实验检验贝尔不等式：
```
S = E(a,b) + E(a,b') + E(a',b) - E(a',b') ≤ 2
```
其中 E(a,b) 是测量方向 a 和 b 的相关函数。

### 2.3 量子力学预测
对纠缠态 |Φ⁻⟩ 取特定的测量角度：
```
S_Q = 2√2 ≈ 2.828 > 2
```
实验上已多次验证 S_Q > 2，**否定**了局域隐变量理论。

### 关键意义
- 量子纠缠产生比任何经典关联更强的关联
- CHSH 游戏：量子策略获胜概率 cos²(π/8) ≈ 85.4%，经典策略 ≤ 75%

## 三、量子隐形传态 (Quantum Teleportation)

### 3.1 协议概述
Alice 有一个未知量子态 |ψ⟩ = α|0⟩ + β|1⟩，想传给 Bob。
只需要 2 个经典比特 + 1 对纠缠态，不需要传输量子比特本身。

### 3.2 协议步骤

**初始状态**（3 量子比特）：
```
|ψ₀⟩ = |ψ⟩_A ⊗ |Φ⁺⟩_{AB}
     = (α|0⟩ + β|1⟩)_A ⊗ (|00⟩ + |11⟩)_{AB}/√2
```

**步骤 1**：Alice 对 qubit 0（未知态）和 qubit 1（纠缠对的一半）做 CNOT

**步骤 2**：Alice 对 qubit 0 做 H 门

**步骤 3**：Alice 测量 qubit 0 和 qubit 1，得到 2 比特经典结果 m₁m₂

**步骤 4**：Alice 将结果通过经典信道发送给 Bob

**步骤 5**：Bob 根据收到信息对 qubit 2 应用校正门：
```
00 → Z⁰X⁰ = I   (无需操作)
01 → Z⁰X¹ = X   (应用 X 门)
10 → Z¹X⁰ = Z   (应用 Z 门)
11 → Z¹X¹ = ZX  (先 X 后 Z)
```

### 3.3 完整的数学推导

初始三比特态展开：
```
|ψ₀⟩ = α|0⟩_A|0⟩_A|0⟩_B + α|0⟩_A|1⟩_A|1⟩_B
     + β|1⟩_A|0⟩_A|0⟩_B + β|1⟩_A|1⟩_A|1⟩_B
     （除以√2，下标略）

经过 CNOT(0,1) + H(0) 后：
= ½ [  |00⟩(α|0⟩+β|1⟩) + |01⟩(α|1⟩+β|0⟩)
     + |10⟩(α|0⟩-β|1⟩) + |11⟩(α|1⟩-β|0⟩) ]
```

Alice 测量后，Bob 的态和校正门如上所述。

### 3.4 关键要点
- 隐形传态**不违反**不可克隆定理（原态在 Alice 处被破坏）
- 不实现超光速通信（需要经典信道，受光速限制）
- 是分布式量子计算和量子网络的基础协议

## 关键结果
- 纠缠态不能用局域操作和经典通信（LOCC）从可分态制备
- Bell 不等式的违反已通过数十年的实验验证（2022年诺贝尔物理学奖）
- 隐形传态已在光纤、卫星等不同平台实现
