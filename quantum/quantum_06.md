# 课时6：量子纠错 & NISQ

## 一、为什么需要量子纠错

### 1.1 量子噪声
量子比特易受退相干和环境噪声影响：
- **退相位**：相对相位的随机翻转
- **振幅阻尼**：激发态|1⟩自发衰减到|0⟩
- **比特翻转**：|0⟩↔|1⟩的随机翻转

### 1.2 不可克隆定理
不能直接复制量子态来"备份"（不像经典纠错）。

**解决方案**：用多个物理量子比特编码一个**逻辑量子比特**。

## 二、三比特比特翻转码 (Bit-Flip Code)

### 2.1 编码

最简单的纠错码，保护单比特翻转错误：

```
|0⟩_L = |000⟩             # 逻辑 |0⟩
|1⟩_L = |111⟩             # 逻辑 |1⟩
```

编码线路：
```
|ψ⟩ = α|0⟩ + β|1⟩ 
  → CNOT(0,1), CNOT(0,2)
  → α|000⟩ + β|111⟩
```

### 2.2 纠错过程

**症状检测（Syndrome Measurement）**：
```
测量 Z⊗Z⊗I   → 比较第 0 和 1 比特
测量 I⊗Z⊗Z   → 比较第 1 和 2 比特
```

**症状表**：
| Z₁Z₂ | Z₂Z₃ | 错误比特 | 纠正操作 |
|------|------|---------|----------|
| +1   | +1   | 无      | 无       |
| -1   | +1   | 比特 0  | X₀       |
| -1   | -1   | 比特 1  | X₁       |
| +1   | -1   | 比特 2  | X₂       |

### 2.3 局限性
- 只能纠正比特翻转（X 错误），不能纠正相位翻转（Z 错误）
- 可通过改变编码基保护相位翻转：|0⟩_L=|+++⟩, |1⟩_L=|---⟩

## 三、表面码 (Surface Code)

### 3.1 基本概念
表面码是目前最有前途的量子纠错方案，基于二维网格结构。

```
• — Z — • — Z — • — Z — •
X       X       X       X
• — Z — • — Z — • — Z — •
X       X       X       X
• — Z — • — Z — • — Z — •
```

- **数据量子比特**：位于格点（•）
- **测量量子比特**（辅助）：位于面中心（X 顶点和 Z 面）
- **X 稳定子**：每个顶点的 4 个邻居的 X⊗X⊗X⊗X
- **Z 稳定子**：每个面的 4 个角点的 Z⊗Z⊗Z⊗Z

### 3.2 关键指标

| 参数 | 意义 |
|------|------|
| d (码距) | 表面码边长，d = 3,5,7,... |
| 物理比特数 | ~2d² |
| 逻辑错误率 | ~(ε/ε_th)^{(d+1)/2} |
| 阈值 ε_th | ≈ 1% (每个物理门的错误率) |

### 3.3 优势
- 只需要**近邻相互作用**（适合超导芯片）
- 高阈值（~1%），当前硬件可达到
- 可扩展：更大的 d → 更低逻辑错误率

## 四、NISQ 时代

### 4.1 NISQ 定义
**Noisy Intermediate-Scale Quantum**（含噪中等规模量子）设备，由 John Preskill 在 2018 年提出。

特征：
- 50-1000 物理量子比特
- 门保真度 ~99-99.9%（不足以做全纠错）
- 无法运行 Shor 等需要深线路的算法

### 4.2 NISQ 设备限制

| 限制 | 典型值 | 影响 |
|------|--------|------|
| 相干时间 T₁/T₂ | 10-100μs | 最大线路深度 |
| 单比特门保真度 | 99.9% | 数十万门内可用 |
| 两比特门保真度 | 99-99.5% | 主要瓶颈 |
| 测量保真度 | 95-99% | 限制重复测量 |
| 连接性 | 近邻耦合 | 需要 SWAP 路由 |

### 4.3 NISQ 算法

**变分量子本征求解器 (VQE)**：
```
H(θ) 的期望值 E(θ) = ⟨ψ(θ)|H|ψ(θ)⟩
用经典优化器最小化 E(θ)
```

**量子近似优化算法 (QAOA)**：
- 交替应用问题哈密顿量和混合哈密顿量
- 解决组合优化问题（MaxCut 等）

**量子机器学习 (QML)**：
- 参数化量子线路用作神经网络
- 在图像分类、生成模型中有探索

### 4.4 NISQ 未来

- 量子纠错阈值尚未在实用规模上实现
- 当前路线图：增加物理比特数 → 提升保真度 → 量子纠错
- 预计需要 ~1000 个逻辑量子比特才能展示有意义的量子优势
- 表面码是主流纠错方案，Google/IBM 都在推进

## 关键结果
- 量子纠错的核心思想：用冗余编码 + 稳定子测量
- 表面码具有高阈值（~1%）和近邻耦合的工程优势
- NISQ 时代的目标：展示"量子霸权"并寻找近期应用
- 容错量子计算机预计还需要 10-20 年
