# 量子噪声与退相干

> 量子计算第5课 — 量子系统的天敌

## 退相干基础

### 经典 vs 量子
- **经典计算**：信号可以无休止保持（如DRAM刷新）
- **量子计算**：量子态会随时间自发丢失信息

### 退相干的后果
1. **叠加态坍缩**：|0⟩+|1⟩ 变成纯 |0⟩ 或 |1⟩
2. **纠缠丢失**：纠缠对变成经典关联
3. **相位随机化**：相对相位信息丢失
4. **门保真度下降**：量子门操作误差累积

## 量子噪声类型

### 主要噪声源

| 噪声类型 | 来源 | 影响 | 缓解 |
|----------|------|------|------|
| T1（能量弛豫） | 与环境的能量交换 | |0⟩态衰减 | 更好隔离 |
| T2（退相位） | 相位信息丢失 | 能级抖动 | 动力学解耦 |
| 退极化 | 完全混合态 | 任意方向 | 纠错 |
| 振幅阻尼 | 能量耗散 | 仅T1过程 | 高Q谐振器 |
| 相位阻尼 | 仅相位丢失 | 仅T2过程 | 材料纯度 |

### T1 时间（能量弛豫）

量子比特从激发态 |1⟩ 衰减到基态 |0⟩ 的时间常数。

```
P(|1⟩) = exp(-t/T1)

典型值：
超导量子比特：10-100μs
离子阱：100ms-1s
NV色心：1-10ms
```

### T2 时间（退相位）

量子比特态叠加的相对相位随机化的时间常数。

```
T2*（不纯）：非均匀展宽，来自静态噪声
T2（纯）：均匀退相干，来自动态噪声
T2 ≤ 2·T1
```

## 噪声模型

### 退极化信道

```python
import numpy as np

def depolarizing_channel(rho, p):
    """
    退极化信道：以概率 p 替换为完全混合态
    rho: 密度矩阵
    p: 退极化概率
    """
    d = rho.shape[0]  # 维度
    return (1 - p) * rho + p * np.eye(d) / d

# 单比特退极化
rho_0 = np.array([[1, 0], [0, 0]])  # |0⟩⟨0|
rho_noisy = depolarizing_channel(rho_0, 0.1)
print(rho_noisy)
```

## 动力学解耦

### 核心思想
通过施加脉冲序列，平均掉低频噪声的影响。

### Hahn Echo（自旋回波）

```
演化时间 τ → π 脉冲 → 演化时间 τ → 测量

效果：抵消静态退相位
```

### CPMG 序列

```
π/2 → τ → π → 2τ → π → 2τ → π → τ → 测量

CPMG 比 Hahn Echo 更有效：
1. 多个 π 脉冲消除更高阶噪声
2. 对时域噪声更鲁棒
3. 可扩展为 DD 序列
```

### 动力学解耦（DD）

```
┌─── D 序列 ───┐
|   τ ─ πx ─ τ ─ πx |  (周期 T = 2τ)

┌─── XY-4 序列 ───┐
|   τ ─ πx ─ τ ─ πy ─ τ ─ πx ─ τ ─ πy |

┌─── 级联 DD ───┐
|   更高阶噪声抑制
```

## 量子纠错

### 纠错的基本逻辑

```
量子信息 → 编码 → 噪声 → 错误检测 → 错误纠正 → 解码
```

### 关键差异 vs 经典纠错
| 方面 | 经典纠错 | 量子纠错 |
|------|---------|---------|
| 编码 | 比特复制 | 纠缠编码 |
| 检测 | 奇偶校验 | 稳定子测量 |
| 纠错 | 翻转错误位 | Pauli修正 |
| 测量 | 可破坏性测量 | 伴生测量（不坍缩数据） |
| 连续误差 | 离散 | 投影到离散 |

### 表面码（Surface Code）

```
d = 3 (码距)
┌───┬───┬───┐    ● 数据量子比特
│ ● │ ● │ ● │    □ X-稳定子
├───┼───┼───┤    ○ Z-稳定子
│ ● │ ● │ ● │
├───┼───┼───┤
│ ● │ ● │ ● │
└───┴───┴───┘
```

- **码距 d**：可纠正 (d-1)/2 个错误
- **容错阈值**：~1%（即物理门错误率低于1%可有效纠错）
- **开销**：每个逻辑比特需 2d²-1 个物理比特

## 阈值定理

### 核心结论
如果物理量子门的错误率低于某个阈值，量子纠错可以实现任意低的逻辑错误率。

```
物理错误率 < 阈值 → 纠错 → 逻辑错误率 = 物理^d

典型阈值：表面码 ~0.5-1%
           Steane码 ~0.01%
```

## 总结
- T1和T2是量子比特质量的核心指标，超导量子比特的T1通常在10-100μs
- 动力学解耦（CPMG/DD序列）可以抑制低频噪声
- 量子纠错将物理错误投影到离散Pauli错误，通过稳定子检测纠正
- 表面码是目前最实用的QEC方案，码距越大纠错越强
- 阈值定理保证：只要物理错误率够低，纠错可以把逻辑错误率压到任意小
