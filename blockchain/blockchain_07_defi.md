## 1. AMM — 跟自动售货机做交易

### 订单簿 vs AMM

传统交易所用**订单簿**——买方和卖方各自挂单，系统撮合。

```
传统订单簿：
  卖单：1 BTC @ $60,100, 1 BTC @ $60,200 ...
  买单：1 BTC @ $60,000, 1 BTC @ $59,900 ...

AMM 自动贩售机：
  你塞 $200 → 弹出 (~0.003 ETH)
  贩售机自动调整价格
```

AMM 没有订单簿，它用**流动性池（Liquidity Pool）**和一个数学公式来定价。

### 恒定乘积公式 x * y = k

AMM 的核心公式极其简单：

```
x = 池中 Token A 数量
y = 池中 Token B 数量
k = 恒定乘积（保持不变）
```

**核心原理**：每次交易必须保持 `x * y = k` 不变。

```python
# Python 模拟 Uniswap V2 的交换逻辑
def swap_x_to_y(x_reserve, y_reserve, x_in):
    """用 x_in 个 Token A 换出多少个 Token B"""
    k = x_reserve * y_reserve              # 恒定乘积
    x_new = x_reserve + x_in                # 新的 x 储备
    y_new = k / x_new                       # 新的 y 储备
    y_out = y_reserve - y_new               # 换出的 y 数量
    return y_out

# 举例：ETH/USDC 池
eth_reserve = 100    # 100 ETH
usdc_reserve = 200000  # 200,000 USDC (假设 ETH = $2000)
k = 100 * 200000  # = 20,000,000

# 你买入 1 ETH
eth_in = 1
usdc_out = swap_x_to_y(eth_reserve, usdc_reserve, eth_in)
print(f"买入 1 ETH 需要支付 {usdc_out:.2f} USDC")
# → 大约 2020.20 USDC（滑点约 1%）
```

### 滑点与深度

我理解滑点的本质：**交易量越大，价格变动越大**。

```
池深 100 ETH / 200,000 USDC：
买 1 ETH → 单价约 $2,020（滑点 1%）
买 10 ETH → 单价约 $2,222（滑点 11%）

池深 10,000 ETH / 20,000,000 USDC：
买 1 ETH → 单价约 $2,002（滑点 0.1%）
买 10 ETH → 单价约 $2,020（滑点 1%）
```

池子越深 = 流动性越好 = 滑点越小。

### 无常损失（Impermanent Loss）

LP（流动性提供者）存入资产赚手续费，但可能亏在**无常损失**上：

```
你存入池子：1 ETH + 2000 USDC（ETH = $2000）
ETH 涨到 $4000：
  如果你持有不存 → 值 $6000
  如果你存在池里 → 值 ~$5656（AMM 自动卖了一部分 ETH）
  无常损失 ≈ 5.7%
```

**关键洞察**：无常损失是机会成本。ETH 价格波动越大，损失越高。如果只波动回原价，损失消失（所以叫"无常"）。

### Uniswap V3 集中流动性

V3 的创新是我见过最优雅的 DeFi 设计之一：

```solidity
// V3 在指定价格范围内提供流动性
// 例如：ETH 在 $1800-$2200 之间我才提供流动性
// 资金效率比 V2 高 100-1000 倍
// 但如果价格跳出这个范围，你的头寸全部变成一种代币
```

**类比**：V2 像在整条街上摆摊，V3 像只在人最多的路口摆摊。

## 2. 借贷协议：Aave 与 Compound

### 超额抵押

DeFi 借贷的核心是**超额抵押**：

```
你存入：2 ETH（价值 $4000）
你能借出：最多 1500 USDC（LTV = 75%）
清算线：如果你的仓位价值 < 清算阈值，别人可以清算你
```

### 利率模型

```
资金利用率 U = 借出的钱 / 存入的总金额

当 U < 80%：利率缓慢上升
当 U > 80%：利率急剧上升（抑制借贷 + 鼓励存款）

目的是吸引更多存入或用高利率驱逐借款人，保持流动性
```

### 闪电贷（Flash Loan）

这是 DeFi 最神奇的特性——**无需抵押即可借款，只要在同一笔交易中归还**：

```
1. 从 Aave 借出 1000 万 USDC    ← 不需要抵押！
2. 在 Uniswap 上套利            ← 做任何操作
3. 还回 1000 万 USDC + 手续费   ← 必须在同一笔交易内完成
4. 如果第 3 步失败，整个交易回滚  ← 原子性保证安全
```

```
闪电贷就像一个时间循环：
你向宇宙借了所有能量
去完成使命
在时间重启前还回去
还不上 → 时间线删除（交易回滚）
```

**本质**：以太坊交易的原子性（要么全做，要么全不做）让这成为可能。

## 3. 稳定币：DAI 与 MakerDAO

### 为什么需要稳定币？

加密货币波动太大，没人愿意用 BTC 买咖啡。稳定币提供**加密世界内的稳定价值存储**。

### 三类稳定币

| 类型 | 例子 | 机制 | 风险 |
|------|------|------|------|
| 法币抵押 | USDC, USDT | 1:1 储备美元 | 中心化、审计风险 |
| 加密抵押 | DAI | 超额抵押 ETH | 智能合约风险 |
| 算法稳定币 | UST(已崩) | 套利激励 | 死亡螺旋 |

### DAI 的抵押债仓（CDP / Vault）

```
你抵押 1.5 ETH（价值 $3000）
你铸造 1000 DAI（抵押率 300%）

如果 ETH 跌到 $1333：
  抵押率 = 2000 / 1000 = 200% → 触发清算
  清算人还你的 1000 DAI，拿走你的 1.5 ETH（+13% 折扣）
```

```solidity
// 简化版 DAI 铸造
contract SimpleCDP {
    // user → vault info
    mapping(address => Vault) public vaults;

    struct Vault {
        uint256 collateral;  // 抵押品数量 (ETH)
        uint256 debt;        // 已铸造的 DAI
    }

    // ETH 价格喂价来自 Chainlink 预言机
    function depositAndMint() public payable {
        uint256 daiAmount = (msg.value * getEthPrice() * 66) / 100; // 66% LTV
        vaults[msg.sender] = Vault({
            collateral: msg.value,
            debt: daiAmount
        });
        _mint(msg.sender, daiAmount); // 铸造 DAI
    }
}
```

### 为什么 UST 崩了而 DAI 没崩

**UST（Terra Luna）**：算法稳定币，依赖 LUNA 代币的套利者维持价格。当恐慌发生时，所有人都逃离，套利失效→死亡螺旋。

**DAI**：超额抵押在 ETH 上，即使 ETH 跌 50%，DAI 仍有超额保证金。本质区别：**DAI 有实实在在的抵押物，UST 只有信仰**。

## 4. 流动性挖矿与收益农场

Yield Farming = 把资产存入 DeFi 协议赚取收益：

```
你存入 USDC → Aave → 赚存款利息 + AAVE 代币奖励
                   → 用 aUSDC 做抵押借出 ETH → 做 LP 赚手续费
                   → 把 LP Token 再质押到别的协议 ...
                   → 这叫 "乐高组合"（Composability）
```

**风险**：
- 智能合约漏洞
- 无常损失
- 代币价格归零
- 多层层叠的清算风险

## 5. 新手必须理解的关键洞察

1. **AMM 的滑点 vs CEX 的价差**：CEX 看买卖价差，AMM 看池子深度。池子越深交易越便宜
2. **协议不能保证收益**：DAI 的存款利率是市场决定的，不是 Maker 承诺的
3. **闪电贷是攻击者的武器**：历史上大多数 DeFi 黑客都用了闪电贷放大攻击
4. **预言机操纵**：如果价格喂价源（如 Uniswap 池）被操纵，清算机制会误清算

## 总结

这一课我理解了 DeFi 三大核心：

- **AMM** 用 `x * y = k` 替代了传统订单簿，像一台自动贩售机自动报价。V3 的集中流动性把资金效率提升了 100-1000 倍
- **借贷协议**以超额抵押为基础，闪电贷利用交易原子性实现无需抵押的借款
- **稳定币** DAI 靠超额抵押维持稳定，而算法稳定币本质上是庞氏结构

DeFi 最让我惊叹的是 **Composability（可组合性）**——代币可以当乐高一样层层叠叠，组合出从未有过的新型金融产品。但这也意味着攻击面随组合增长，安全始终是头号课题。
