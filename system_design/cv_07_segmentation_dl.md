## 语义分割经典架构

### FCN（全卷积网络，2015）

```python
# 核心思想: 去掉全连接层 → 全用卷积层
# 
# 传统CNN: Conv → Conv → FC → 1×1 (分类结果)
# FCN:     Conv → Conv → Conv → Conv → H'×W' (分割图)
#
# 问题: 多次池化后特征图变小了
# 解决: 反卷积（转置卷积）上采样回原图尺寸
#
# 跳层连接: 浅层细节 + 深层语义
```

### U-Net (2015) — 生物医学分割标杆

```python
# 结构: 编码器-解码器 + 跳层连接
#
# 编码器(下采样): Conv → Pool → Conv → Pool → ...  
# 解码器(上采样): Conv → Up → Conv → Up → ...
#
# 跳层连接: 编码器的特征直接传给对应解码器层
# → 保留精细的空间信息（边界清晰）

# U-Net至今仍是医学图像分割的首选
```

### DeepLab系列

```python
# 核心贡献: 空洞卷积 (Dilated/Atrous Convolution)
#
# 普通卷积: 3×3核覆盖3×3区域
# 空洞卷积(rate=2): 3×3核覆盖5×5区域（中间有空洞）
#
# 好处: 扩大感受野，不增加参数量，不降低分辨率

# DeepLabV3+: 空洞卷积 + ASPP (不同rate并行) + 编码器-解码器
```

## 实例分割

### Mask R-CNN (2017) — Faster R-CNN + 分割

```python
# 在Faster R-CNN基础上 新增一个分支
#
# Faster R-CNN:        分类 + 框回归
# Mask R-CNN:          分类 + 框回归 + 掩码预测
#
# 新增: RoIAlign（替代RoIPooling）
# RoIPooling有量化误差 → 分割边界不准
# RoIAlign用双线性插值 → 亚像素精度

# Mask R-CNN = 实例分割的事实标准
```

## 全景分割

```python
# 全景分割 = 语义分割 + 实例分割
# 
# 语义分割部分: 标出所有"天空"、"道路"、"建筑"
# 实例分割部分: 区分"车1"和"车2"
#
# 挑战: 可数对象(人/车)用实例分割
#       不可数区域(天空/道路)用语义分割
#       两个分支要协调

# 代表: Panoptic FPN, UPSNet
```

## 对比

| 模型 | 任务 | 年份 | 核心创新 |
|------|------|------|---------|
| FCN | 语义 | 2015 | 全卷积+上采样 |
| U-Net | 语义 | 2015 | 编码器-解码器+跳层 |
| DeepLab | 语义 | 2016 | 空洞卷积 |
| Mask R-CNN | 实例 | 2017 | RoIAlign+多任务 |
| Panoptic FPN | 全景 | 2019 | 统一框架 |

## 今日收获
- 语义分割 = 像素级分类
- U-Net的跳层连接 = 保留空间细节的关键
- 空洞卷积 = 不降分辨率的同时增大感受野
- Mask R-CNN = 实例分割的事实标准
- 全景分割 = 语义+实例的统一
