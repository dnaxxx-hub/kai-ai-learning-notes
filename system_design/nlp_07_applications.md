## 核心NLP任务

### 1. 命名实体识别（NER）

```python
# 识别文本中的"实体"：人名/地名/机构名/时间/金额...

# "张三在北京的阿里巴巴工作"
#  PER     LOC     ORG

# 传统: BiLSTM + CRF
# CRF保证标签序列的合法性（B-PER不能直接接I-LOC）
# 现在: BERT + 线性分类器（更简单，效果更好）

# 难点: 
# - 嵌套实体（"中国人民解放军"包含"人民"）
# - 歧义（"苹果"是水果还是公司）
```

### 2. 关系抽取

```python
# 实体之间的关系
#
# "马云创建了阿里巴巴" → (马云, 创建, 阿里巴巴)
#                       ↑实体   关系    ↑实体
#
# 应用: 知识图谱构建
# 方法: BERT + 两个实体标记 → 关系分类
```

### 3. 文本摘要

```python
# 把长文本浓缩成短文本

# 抽取式: 从原文中选最重要的句子
# 生成式: 模型自己写出摘要（GPT擅长的）

# 抽取式更安全（不胡说八道）
# 生成式更灵活（可以换说法）

# 难点: 忠实度（模型不要自己编造）
```

### 4. 机器翻译

```python
# 历史上NLP最重要的应用
# Google翻译每天翻译1000亿词

# 传统: 统计机器翻译（SMT, 词组表+规则）
# 2016: Google Neural Machine Translation → Seq2Seq+Attention
# 现在: Google Translate用Transformer

# 难点:
# - 罕见词/低频术语
# - 多义词（bank=银行/河岸）
# - 语法结构不同的语言（主谓宾vs主宾谓）
```

### 5. 对话系统

```python
# 三种对话系统:

# 1. 任务型: 
#    "帮我订到北京的机票"
#    → 意图识别 + 槽填充 + 对话管理

# 2. 问答型:
#    "什么是注意力机制"
#    → 检索(FAQ/知识库) 或 生成(GPT)

# 3. 闲聊型:
#    "今天心情不好"
#    → 情感共鸣 + 生成回复

# ChatGPT = 三者合一的终极方案
```

### 6. 情感分析

```python
# 判断文本的情感倾向

# 粗粒度: 正面/负面/中性
# 细粒度: 1-5星评分
# 方面级: "手机很好但电池不行" → 质量:正, 电池:负

# 应用: 舆情监控、产品评价分析
```

## 评测基准

```python
# GLUE / SuperGLUE: 分类和推理任务集
# SQuAD: 阅读理解（从文中找答案）
# CoNLL: NER和词性标注
# BLEU: 翻译质量（看n-gram重合度）
# ROUGE: 摘要质量（看召回率）
# Perplexity: 语言模型困惑度（越低越好）
```

## 今日收获

# 核心NLP任务:
