# 第11课：搜索算法 — 二分/三分/分治

> 日期: 2026-05-08
> 代码: `search_algo.py`

## 1. 二分查找变体

| 变体 | 功能 | 实现 |
|------|------|------|
| 标准 | arr[mid]==target → 返回 | low<=high |
| lower_bound | 第一个 >= target | low<high, [low,high) |
| upper_bound | 第一个 > target | 同bisect_right |
| 旋转数组 | 先判断有序半区 | 比较arr[low]和arr[mid] |
| 平方根 | 浮点数二分 | high-low > eps |

## 2. 三分查找

- 适用于单峰函数 (只有一个极值点)
- 每步缩小 2/3
- 不适用于单调函数或非单峰函数

## 3. 分治: 最近点对 O(N log N)

### 思路
1. 按x排序, 中分
2. 递归求左右最小距离 d
3. 合并: 只用检查中线两侧 d 范围内的点
4. 按y排序后, 对每个点只需检查其后7个点

### 复杂度
- 暴力: O(N²)
- 分治: O(N log N) — 缓存不友好但理论快

## 运行结果

```
二分:
  标准/左右边界/旋转数组/平方根 全部通过 ✓

三分:
  凸函数 -(x-3)²+10 → max=3.0 ✓
  绝对值函数 -|x-7|+20 → max=7.0 ✓

最近点对:
  N=10/50/100: 分治 vs 暴力 全一致 ✓
  N=1000: 分治=9.89ms (暴力需~1s)
```
