# CNN架构演进：从AlexNet到EfficientNet

> 日期：2026-05-07 19:42 | 课程：CV路线 Phase 3-1
> 目标：理解CNN是怎么一步步变强的

## 演进路线

```
LeNet (1998) → AlexNet (2012) → VGG (2014) → GoogLeNet (2014)
→ ResNet (2015) → DenseNet (2017) → SENet (2018) → EfficientNet (2019)
```

## 关键节点

### LeNet-5 (1998) — 开山之作

```python
# Yann LeCun | 手写数字识别
# 结构: Conv → Pool → Conv → Pool → FC → FC
# 5层: 2个卷积 + 2个池化 + 2个全连接

# 当时只能识别32×32的灰度图
# 但CNN的基本结构定了下来
```

### AlexNet (2012) — 深度学习元年

```python
# Alex Krizhevsky | ImageNet夺冠（错误率26%→15%）
#
# 关键创新:
# 1. GPU训练（两块GTX 580，训练了6天）
# 2. ReLU激活函数（解决sigmoid梯度消失）
# 3. Dropout（防止过拟合）
# 4. 数据增强（翻转/裁剪/颜色变换）
# 5. 重叠池化（步长小于核大小 → 更平滑）

# 意义: 证明了深度CNN可行 → 深度学习爆发
```

### VGGNet (2014) — 越深越好

```python
# Oxford | 证明了:
# 用多个3×3小卷积核代替大卷积核(7×7/11×11)
# → 更深，参数量更少，效果更好

# VGG-16: 16层, 1.38亿参数
# VGG-19: 19层, 1.44亿参数

# 贡献: 简洁统一的架构（全是3×3卷积+2×2池化）
# 代价: 参数量太大（第一个FC层就有1亿参数）
```

### GoogLeNet / Inception (2014) — 更有效率

```python
# Google | 思考: 选多大的卷积核最好？
# 答: 都试试！
# 
# Inception模块: 1×1 + 3×3 + 5×5 + 池化 并行
# 每个核检测不同尺度的特征

# 关键: 1×1卷积降维
# 先用1×1把通道数减下来 → 再做3×3/5×5
# 参数量从1.38亿降到400万
```

### ResNet (2015) — 残差革命

```python
# 何恺明 | Microsoft
# 
# 问题: VGG-19比VGG-16好，那VGG-22呢？——不，更差
# 梯度消失: 层太深 → 梯度传不回去
#
# 残差连接:
# output = F(input) + input
# 梯度可以直接跳过卷积层回到input
# → 可以有效训练152层（甚至1000+层）

# ResNet-152: 还是比VGG-16参数量少
# 而且效果远好于VGG
```

### EfficientNet (2019) — 最优组合

```python
# Google | 神经架构搜索找到的
# 
# 关键洞察: 网络宽度/深度/分辨率要一起调整
# 之前都是单独调整其中一个
# EfficientNet找到三者同时增长的最优比例

# EfficientNet-B7: 参数量小，精度最高
# 至今仍是"小模型高精度"的标杆
```

## 可视化

| 架构 | 参数 | 创新点 | 历史意义 |
|------|------|--------|---------|
| AlexNet | 60M | GPU+ReLU+Dropout | 深度学习爆发的导火索 |
| VGG | 138M | 小卷积核堆叠 | 简洁且可扩展 |
| Inception | 4M | 多尺度并行 | 参数效率高 |
| ResNet | 25M | 残差连接 | 让超深网络训练成为可能 |
| EfficientNet | 66M | NAS+复合缩放 | 效率最优 |

## 今日收获
- CNN演进核心: 越来越深，越来越高效
- 残差连接 = 2010年代最重要的CV创新
- 1×1卷积 = 降维利器
- 参数少 ≠ 效果差（Inception打脸了VGG）
