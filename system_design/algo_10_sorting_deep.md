# 第10课：排序算法深度解析

> 日期: 2026-05-08
> 代码: `sorting_deep.py`

## 四种排序

| 算法 | 平均时间 | 最坏 | 空间 | 稳定 | 特点 |
|------|---------|------|------|------|------|
| 快排 | O(N log N) | O(N²) | O(log N) | ✗ | 实践中最快(缓存友好) |
| 归并 | O(N log N) | O(N log N) | O(N) | ✓ | 稳定, 链表友好 |
| 堆排 | O(N log N) | O(N log N) | O(1) | ✗ | 原地, 没有最坏 |
| 基数 | O(d(N+k)) | 同上 | O(N+k) | ✓ | 整数/定长字符串 |

## 关键实现细节

### 快排分区
- **Hoare**: 选中间为pivot, 双向扫描, 交换次数~3x少
- **Lomuto**: 选末尾为pivot, 单向扫描, 实现简单但慢
- 排序本身不稳定，除非用Stable Partition

### 归并
- 自顶向下: 递归拆分, 合并时需要额外空间
- 自底向上: 迭代合并, 避免了递归栈

### 堆排
- 建堆: O(N) (从最后一个非叶节点下沉)
- 取最大: O(N log N)
- 注意: 建堆=O(N)而不是O(N log N)

### 基数排
- LSD: 从最低位开始, 稳定排序每位的数字
- MSD: 从最高位开始, 递归

## 性能

```
N=  100: 内置~0ms, 快排~0.1ms, 归并~0.1ms, 堆排~0.1ms
N= 1000: 内置~0.1ms, 快排~0.9ms, 归并~1.5ms, 堆排~1.5ms
N=10000: 内置~1.4ms, 快排~11ms, 归并~18ms, 堆排~21ms
```

Python内置排序(Timsort)遥遥领先 — 混合快排+归并+插入。
