## RNN在NLP中的三种模式

### 1. 多对一（文本分类）

```python
# 输入: 词序列 [w₁, w₂, ..., w_n]
# 输出: 一个类别

# 例子: 情感分析
# "这部电影太棒了" → 正面
# "这个电影真无聊" → 负面

# 结构: 每个词输入 → RNN累积信息 → 最后一个隐状态h_n → 分类器
```

### 2. 多对多（同步 — 序列标注）

```python
# 输入: 词序列 [w₁, w₂, ..., w_n]
# 输出: 标签序列 [y₁, y₂, ..., y_n]

# 例子: NER（命名实体识别）
# "张三 | 在 | 北京 | 工作" 
#  PER     O    LOC    O
# (人名)      (地点)

# 结构: 每个时间步输出一个标签
```

### 3. 多对多（异步 — 机器翻译）

```python
# 输入: 词序列 [w₁, w₂, ..., w_m]  (中文)
# 输出: 词序列 [y₁, y₂, ..., y_n]  (英文)
# 注意: 输入和输出长度不同！

# 结构: 编码器-解码器（Seq2Seq）
# 编码器: 读完整个句子 → 生成一个"语义向量"
# 解码器: 从语义向量开始 → 逐词生成翻译

# 这就是下一课的内容
```

## BiLSTM（双向LSTM）

```python
# 标准LSTM: 从左到右 → 只能看到"之前的词"
# 
# 问题: "我今天去银行____"
# 如果是"银行上班" → "上班"
# 如果是"银行划船" → "划船" 
# 要理解"银行"是金融还是河岸，需要看后面的词
#
# BiLSTM: 从左到右 + 从右到左
# 每个位置 → 拼接 前向h + 后向h
# → 每个词同时看到上下文
```

## 实际应用对比

| 任务 | 模型 | 为什么用这个 |
|------|------|------------|
| 情感分类 | BiLSTM + Attention | 长文本，需关注关键词 |
| 命名实体识别 | BiLSTM + CRF | 需要标签之间的约束 |
| 词性标注 | BiLSTM | 每个位置独立预测 |
| 机器翻译 | Transformer | RNN太慢，无法并行 |

## ELMo (2018) — 深度上下文的词表示

```python
# 之前的Word2Vec: "bank"在中国和河岸里是同一个向量
# 
# ELMo: 每个词的向量根据上下文动态生成
#
# "I go to the bank to deposit money" → bank=金融机构
# "I sit on the river bank" → bank=河岸
#
# 结构: 双向LSTM的多层表示
# 
# 但ELMo已经被BERT替代了
```

## 今日收获
- RNN在NLP = 三种模式（分类/标注/生成）
- BiLSTM = 看到整个上下文（前向+反向）
- ELMo = 上下文相关的词表示（2018, 但已过时）
- RNN在NLP中的位置: BERT出现前的主角，现在是配角
