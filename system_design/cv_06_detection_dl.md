# 深度学习目标检测：R-CNN系列 → YOLO → SSD

> 日期：2026-05-07 19:43 | 课程：CV路线 Phase 3-2
> 目标：理解"两阶段 vs 单阶段"检测的区别

## 核心分水岭

```
两阶段   R-CNN系列:  先找候选区域 → 再分类回归(慢但准)
单阶段   YOLO/SSD:  直接一步预测(快但略差)
```

## 两阶段：R-CNN系列

### R-CNN (2014)

```python
# 1. 选择性搜索 → 2000个候选框
# 2. 每个框缩放到固定大小 → 喂进CNN
# 3. CNN提取特征 → SVM分类 + 框回归

# 问题: 2000个框都要跑CNN → 非常慢（每张图47秒）
# 而且三个模块是分开训练的
```

### Fast R-CNN (2015)

```python
# 关键改进: 整张图只跑一次CNN
#
# 1. 整张图 → CNN → 特征图
# 2. 候选框映射到特征图 → RoI池化
# 3. RoI池化把不同大小的框变成固定尺寸
# 4. 统一预测: 分类 + 框回归（合并到一个网络）

# 速度: 从47秒降到0.3秒/张
```

### Faster R-CNN (2015)

```python
# 关键: 候选框也用CNN生成（而不是选择性搜索）
#
# 新增RPN (Region Proposal Network):
# 在特征图上滑动 → 每个位置生成k个锚框
# RPN判断: 这个框有没有物体？
# RPN回归: 框应该怎么调整？
#
# 真正实现端到端: 一张图 → 一个网络 → 检测结果
# 速度: 0.2秒/张

# Faster R-CNN = 两阶段检测的巅峰
```

## 单阶段：YOLO和SSD

### YOLO (2016) — 你看一次就够了

```python
# 思想: 把检测当成回归问题
#
# 1. 把图分成 S×S 网格
# 2. 每个网格预测 B个边界框
# 3. 每个框预测: x, y, w, h, confidence, 类别概率

# YOLOv1: 45帧/秒（实时！）
# 当时Faster R-CNN只有7帧/秒

# 缺陷: 小目标检测差（网格太粗）
```

### YOLO演进

```python
# YOLOv2 (2017): 锚框+批量归一化 → 更快更准
# YOLOv3 (2018): 多尺度检测+残差 → 小目标改善
# YOLOv4 (2020): Bag of Freebies → 各种trick叠加
# YOLOv5 (2020): PyTorch实现（非官方）→ 社区标准
# YOLOv8 (2023): 统一框架：检测/分割/姿态估计

# YOLO = 工业界最流行的检测器（没有之一）
```

### SSD (2016)

```python
# Single Shot MultiBox Detector
#
# 类似YOLO的单阶段，但用多尺度特征图:
# 浅层特征 → 检测小目标
# 深层特征 → 检测大目标
#
# 比YOLOv1准，比YOLOv1慢
# 现在基本被YOLO系列替代
```

## 对比

| 模型 | 类型 | 速度 | 精度 | 应用场景 |
|------|------|------|------|---------|
| Faster R-CNN | 两阶段 | 7fps | 高 | 精度优先 |
| YOLO | 单阶段 | 45~几百fps | 中高 | 实时场景 |
| SSD | 单阶段 | 22fps | 中 | 历史产品 |

## 今日收获
- 两阶段 = 先RPN找候选框 → 再分类（Fast/Faster R-CNN）
- 单阶段 = 一步预测框+类（YOLO/SSD）
- **YOLO = 工业首选**（速度快，精度够）
- Faster R-CNN的核心贡献：RPN（区域提议网络）
- YOLO = You Only Look Once，刷新了实时检测的极限
