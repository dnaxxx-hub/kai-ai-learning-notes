# 第9课：字符串算法 — KMP / Z-function / Trie

> 日期: 2026-05-08
> 代码: `string_algo.py`

## 1. KMP (Knuth-Morris-Pratt)

### π函数 (部分匹配表)
- `pi[i]` = `pattern[:i+1]` 的最长公共前后缀长度
- 构建: O(M)
- 匹配失败时按π跳转，不回溯文本指针

### KMP搜索
- 双指针 i (文本) 和 j (模式)
- 匹配失败: j = pi[j-1] (跳转)
- 完全匹配: 记录位置, j = pi[j-1] (继续搜索)

## 2. Z-function (Z算法)

- `z[i]` = s 和 s[i:] 的最长公共前缀
- 用 [l, r) 区间复用已匹配信息
- 字符串匹配: pattern + '$' + text 后查 z[i] == len(pattern)

### KMP vs Z算法
| | KMP | Z算法 |
|--|-----|-------|
| π函数构建 | O(M) | 拼接后O(N+M) |
| 匹配过程 | 不额外构造 | 需拼接字符串 |
| 辅助空间 | O(M) | O(N+M) |
| 实际速度 | 快(少分配) | 略慢 |

## 3. Trie (字典树)

- 每个节点代表一个前缀
- 插入/查找 O(L) (L=单词长度)
- 支持前缀匹配、自动补全

## 运行结果

```
── KMP ──
  "ABABDABACDABABCABAB" 找 "ABABCABAB" → [10] ✓
  10000字中找100字模式 → 9901处匹配 ✓

── Z ──
  Z(aaabaab) = [0,2,1,0,2,1,0] ✓
  与KMP结果完全一致 ✓

── Trie ──
  8个单词插入, 精确搜索/前缀搜索/自动补全全部正确 ✓

── 性能 ──
  N=100000: KMP=3.58ms, Z=8.86ms (KMP快~2.5x)
  Trie 10000词: insert=8.4ms, search=2.9ms
```
