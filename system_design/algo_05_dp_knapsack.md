## 三种背包

| 类型 | 限制 | 递推方向 | 复杂度 |
|------|------|----------|--------|
| 0/1 背包 | 每件最多1次 | 逆序 | O(NC) |
| 完全背包 | 每件无限次 | 正序 | O(NC) |
| 多重背包 | 每件有限次 | 二进制优化→0/1 | O(NC·logK) |

## 核心递推

**0/1背包** (空间优化一维):
```
for i in 0..N-1:          # 遍历物品
    for c in C..w_i:       # 逆序! 保证每件最多选1次
        dp[c] = max(dp[c], dp[c-w_i] + v_i)
```

**完全背包** (只需改变方向):
```
for i in 0..N-1:
    for c in w_i..C:       # 正序! 允许重复选取
        dp[c] = max(dp[c], dp[c-w_i] + v_i)
```

**多重背包 — 二进制优化**:
- 将 `limit` 拆分为 `1, 2, 4, ..., k` 的分组
- 每个分组 = 0/1背包的一个物品
- 示例: limit=10 → 分组 1,2,4,3 (覆盖0~10任意数量)

## 运行结果

```
── 1. 0/1 背包 ──
  物品: 重量=[2,3,4,5,9], 价值=[3,4,5,7,10], 容量=15
  最大价值: 19 (选中物品0,1,2,3, 总重14)
  暴力验证最优: 19 == 19 ✓

── 2. 完全背包 ──
  物品: 重量=[2,3,5], 价值=[3,5,8], 容量=10
  最大价值: 16 (选2个物品1+2个物品0, 总重10)
  验证: 16==16 ✓

── 3. 多重背包 ──
  物品: 重量=[2,3,5], 价值=[3,5,8], 限=[3,2,2], 容量=12
  最大价值: 19 (选3个物品0+2个物品1, 总重12)
  超限?=False ✓

── 4. 暴力验证 ──
  DP结果=13 == 暴力最优=13 ✓

── 5. 性能 ──
  N= 10: 0/1=0.6ms, 完全=0.5ms, 多重=1.1ms
  N= 50: 0/1=2.2ms, 完全=1.7ms, 多重=4.5ms
  N=100: 0/1=3.9ms, 完全=2.9ms, 多重=6.4ms
```

## 关键发现
1. 0/1背包和完全背包的唯一区别: **更新方向** (逆序 vs 正序)
2. 完全背包价值约为0/1背包的5倍 (无限次选取)
3. 二进制优化将多重背包等价转换为0/1背包，正确性已验证
4. 路径重建需要额外存储 `selected` 或 `count` 矩阵
