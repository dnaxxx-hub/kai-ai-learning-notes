# 博弈论 Game Theory

## Nash 均衡

### 纯策略 Nash 均衡
策略组合 $(s_1^*,...,s_n^*)$ 使得每个玩家 $i$ 的单方面偏离不会获益：
$$u_i(s_i^*, s_{-i}^*) \geq u_i(s_i, s_{-i}^*), \quad \forall s_i \in S_i$$

**存在性**（纯策略）：有限博弈、凹博弈等，不一定总有纯策略 Nash 均衡。

### 混合策略 Nash 均衡
玩家以概率分布 $\sigma_i$ 随机选择纯策略。均衡条件：每个玩家在支撑集上的纯策略收益相等且不小于非支撑集策略收益。

**例：猜拳**
- 玩家 1 选择石头/剪刀/布的概率均为 $1/3$
- 收益矩阵对称，混合均衡使对手无偏离动机
- 假设玩家 1 以 $(p, 1-p)$ 选正面/反面 → 解 $E_1[\text{正面}] = E_1[\text{反面}]$ 得 $p^*$

**Nash 存在定理**：任何有限博弈（有限玩家、有限策略）存在混合策略 Nash 均衡。

## 零和博弈与 Minimax 定理

零和博弈：$u_1(a,b) + u_2(a,b) = 0$，即 $u_1 = -u_2$。

### Minimax 定理（von Neumann, 1928）
$$\max_{\sigma_1} \min_{\sigma_2} u_1(\sigma_1, \sigma_2) = \min_{\sigma_2} \max_{\sigma_1} u_1(\sigma_1, \sigma_2) = v$$
$v$ 是博弈的**值**。换言之，在混合策略下，零和博弈的 max-min 和 min-max 相等。

**含义**：先手并不劣势，安全策略即最优策略。

## 演化博弈与复制动力学

### 复制者方程（Replicator Dynamics）
$$\dot{x}_i = x_i \left( f_i(x) - \bar{f}(x) \right)$$
- $x_i$：策略 $i$ 在种群中的比例
- $f_i(x)$：策略 $i$ 的适应度（收益）
- $\bar{f}(x)$：平均适应度

**ESS（演化稳定策略）**：如果种群大部分采用 $x$，少数突变 $y$ 入侵失败。
- 定义：$u(x,x) \geq u(y,x)$，且等号时 $u(x,y) > u(y,y)$

## 拍卖理论

### 基本设定
每个 bidder 对物品有私人估值 $v_i$，提交出价 $b_i$。

### 拍卖类型对比

| 类型 | 规则 | 支付 | 占优策略 |
|------|------|------|---------|
| **英式拍卖** | 价格上升直到只剩一人 | 最后报价 | — |
| **一价密封** | 最高价者得，支付自己出价 | $b_{(1)}$ | 低报（小于估值） |
| **二价密封** (Vickrey) | 最高价者得，支付第二高出价 | $b_{(2)}$ | **出真实估值** |
| **VCG** | 广义 Vickrey，多物品 | 外部性定价 | 出真实估值 |

**收入等价定理**：在标准假设下（风险中性、独立私人估值、对称），所有有效拍卖给卖家带来相同期望收入。

### VCG 机制
在组合拍卖中，每个竞标者支付其对其他竞标者造成的外部性：
$$p_i = (V_{-i} - V) + b_i$$
其中 $V$ 是最优分配总价值，$V_{-i}$ 是无 $i$ 时的最优分配总价值。

## 在 ML 中的应用

### 对抗训练与 GAN
生成器 $G$ 与判别器 $D$ 的零和博弈：
$$\min_G \max_D V(D,G) = \mathbb{E}_{x \sim p_{\text{data}}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1-D(G(z)))]$$

**均衡点**：$D^*(x) = \frac{p_{\text{data}}(x)}{p_{\text{data}}(x) + p_g(x)}$，此时 $p_g = p_{\text{data}}$，博弈值 $v = -\log 4$。

**实际困难**：Nash 均衡难以收敛，需引入梯度惩罚（WGAN）、一致性正则等。

### Actor-Critic 多 Agent
- **Actor**（策略网络）：选择行动 $\pi_\theta(a|s)$，类似玩家的混合策略
- **Critic**（价值网络）：估计状态价值 $V(s)$ 或动作价值 $Q(s,a)$

**多 Agent RL** 中：
- 每个 agent 的策略 $\pi_i$ 构成联合策略 $\pi$，目标是找到 **Markov 完美均衡**
- MADDPG 使用集中式 Critic 缓解环境非平稳性
- QMIX / VDN 假设总价值可分解为各 agent 贡献之和
