# 移动开发 — 路线图

## 课程一览

| 课时 | 主题 | 核心内容 |
|:----:|------|----------|
| 1 | Flutter/Dart基础 | Widget树/三棵树/渲染管道/Key |
| 2 | Flutter布局 | Constraints/Flex/Stack/自定义布局 |
| 3 | Flutter状态管理 | setState/Provider/Riverpod/BLoC对比 |
| 4 | Flutter原生桥接 | Platform Channel/Pigeon/Dart FFI |
| 5 | Kotlin/Android基础 | Compose/Activity/ViewModel/Lifecycle |
| 6 | Android架构 | MVVM/MVI/Clean Arch/Hilt/Room |
| 7 | 混合开发与性能 | 热更新/包体积/JS Bridge |
| 8 | 发布与监控 | 签名/CI/CD/Crashlytics/APM |

## 进阶路径

### Flutter 深度
- 引擎层：Skia/Impeller渲染
- Platform Channel 性能优化
- Dart FFI with C/C++
- Flutter Web + Desktop

### Android 深度
- Compose 自定义Layout
- NDK开发
- Performance Profiling
- Kotlin Multiplatform

### 全栈移动
- Flutter + Firebase全栈
- 跨平台Native Module
- 移动端安全
- 性能监控体系

## 学习建议
- Flutter 学习曲线比原生平缓，适合快速原型
- 但生产级App需要深入理解Dart FFI和Platform Channel
- 从 flutter create 开始，用 Provider/Riverpod 做状态管理
- CI/CD 和 APM 是上线前必须配置的基础设施
