# 特征提取：SIFT/HOG/颜色直方图

> 日期：2026-05-07 19:39 | 课程：CV路线 Phase 1-2
> 目标：理解"怎么从图像中提取有意义的特征"

## 核心问题

```
滤波后得到了"干净图像"，但计算机还不知道图像里有什么。
需要把图像变成"特征向量"——让机器学习能处理的形式。
```

## 特征需要具备什么

| 特性 | 含义 | 为什么 |
|------|------|--------|
| 鲁棒性 | 光照变化不影响 | 同一个物体白天晚上要能识别 |
| 尺度不变 | 大小变化不影响 | 近处远处都能匹配 |
| 旋转不变 | 角度变化不影响 | 物体正着侧着都能认 |
| 区分性 | 不同物体特征不同 | 猫和狗要能分开 |

## 经典特征提取方法

### 1. 颜色直方图（Color Histogram）

```python
# 最简单: 统计每种颜色出现在多少个像素中
# 
# RGB三个通道各分16个bin:
# 特征向量 = 16×3 = 48维
#
# 好处: 对旋转不敏感，简单
# 坏处: 完全不考虑空间信息（"红鸟"和"红花"无法区分）
```

### 2. HOG（方向梯度直方图）

```python
# 思想: 物体的形状靠边缘的分布来描述
#
# 步骤:
# 1. 把图像分成小块 (cells) 8×8
# 2. 每块内统计梯度方向直方图 (9个bin)
# 3. 相邻块归一化 (block normalization)
# 4. 串联所有块的特征 = 最终特征向量

# HOG最著名的应用: 行人检测
```

### 3. SIFT（尺度不变特征变换）— 最经典的特征

```python
# SIFT的四个步骤:

# 1. 尺度空间极值检测
#    在不同尺度(模糊程度)下找"关键点"
#    → 找到在任何尺度下都突出的点
#
# 2. 关键点定位
#    去除低对比度的点
#    去除边缘响应（避免把线误认成特征点）
#
# 3. 方向分配
#    统计关键点周围的梯度方向 → 给每个点分配主方向
#    → 实现旋转不变性
#
# 4. 特征描述
#    在关键点周围16×16区域统计梯度直方图
#    → 128维特征向量
#
# SIFT的128维向量 = 每个特征点的"指纹"
```

### SURF — SIFT的加速版

```python
# SIFT太慢 → SURF用积分图加速
# 效果差不多，速度快3倍
# 但现在都被深度学习特征取代了
```

## 什么时候用什么

| 场景 | 推荐 | 原因 |
|------|------|------|
| 图像检索 | SIFT | 尺度旋转不变 |
| 行人检测 | HOG + SVM | 效果稳定、快 |
| 图像分类（不是深度学习）| 颜色直方图 + HOG | 简单组合 |
| 物体识别（2012后）| CNN特征 | 远强于手工特征 |

## 深度学习时代

```python
# 2012年AlexNet之后:
# 手工特征 (SIFT/HOG) → CNN特征 (卷积层输出的特征图)

# CNN的优势:
# - 自动学习特征（不需要人设计）
# - 层次化（浅层=边缘纹理，深层=物体部件）
# - 端到端（特征提取+分类一起学）

# 但SIFT的思想影响了CNN:
# - 池化 = 空间不变性
# - 卷积核 = 特征检测器
```

## 今日收获
- 特征提取 = 图像 → 向量
- 手工特征三要素：鲁棒性/不变性/区分性
- SIFT是手工特征的巅峰（128维特征点描述子）
- HOG靠梯度方向分布描述形状
- 2012年后CNN特征全面超越手工特征
