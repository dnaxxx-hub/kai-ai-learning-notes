# 目标检测经典方法

> 日期：2026-05-07 19:41 | 课程：CV路线 Phase 2-2
> 目标：理解"怎么在图上找到物体在哪"

## 核心问题

```
分类:     "这是一只猫"
检测:     "猫在 (x1,y1)-(x2,y2) 这个框里"
分割:     "猫的精确轮廓在这里"
```

## 检测 = 分类 + 定位

```
目标检测的输出:  (类别, 边界框)
边界框 = [x_min, y_min, x_max, y_max]  (矩形框)
```

## 经典方法（深度学习之前）

### 滑动窗口（最朴素）

```python
# 1. 用一个窗口在图上滑动
# 2. 每个窗口位置 → 放入分类器（HOG+SVM等）
# 3. 检查窗口内是否有目标

# 问题:
# - 窗口大小固定（目标可能比窗口大或小）
# - 计算量太大（每个位置都跑分类器）

# 金字塔 + 滑动窗口:
# 多尺度缩放图像 → 每层都跑滑动窗口
# 计算量再乘10倍
```

### 选择性搜索（Selective Search）

```python
# 改进: 不滑动所有位置
# 而是"先找到可能是目标的区域"

# 步骤:
# 1. 基于颜色/纹理/大小/形状 生成候选区域
# 2. 合并相似的相邻区域
# 3. 输出 ~2000个候选框（比滑动窗口少太多）

# 这就是R-CNN的思路
```

### 非极大值抑制（NMS）

```python
# 问题: 一个目标被多个框包围
# 
# NMS算法:
# 1. 把框按得分从高到低排序
# 2. 取最高分的框
# 3. 删除与该框IoU > 阈值(0.5)的其他框
# 4. 重复直到所有框处理完

# 关键参数: IoU阈值（太高→框不干净，太低→漏检）
```

## 评价指标

### IoU（交并比）

```python
# 预测框和真实框的:
# 交集面积 / 并集面积

# IoU > 0.5 → 算检测正确 (PASCAL VOC标准)
# IoU > 0.75 → 严格标准 (MS COCO标准)
```

### mAP（平均精度均值）

```python
# 所有类别的AP取平均
# AP = 不同召回率下精度的平均值
# 
# 简单理解: 既要准（框到的都是目标）
#           也要全（所有目标都被框到）
```

## 今日收获
- 检测 = 分类 + 定位（比纯分类多了"在哪"）
- 滑动窗口 = 暴力搜索 → 计算量灾难
- NMS = 去重关键操作
- IoU = 检测质量的核心指标
- R-CNN = 选择性搜索 + CNN，深度学习的开端
