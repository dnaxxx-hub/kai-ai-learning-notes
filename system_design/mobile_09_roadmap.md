# 移动开发学习路线图

## 学习路径总览

```
Dart 基础 → Flutter 基础 → 布局系统 → 状态管理 
→ 原生通信 → Android 原生(Kotlin) → 架构模式 
→ 混合开发 → 发布与监控
```

## 阶段一：基础（第1-2周）

| 主题 | 学习内容 | 实践项目 |
|------|----------|----------|
| Dart 语言 | 类型系统、异步、Mixin、泛型 | 小型 CLI 工具 |
| Flutter 基础 | Widget、三棵树、渲染管道 | 待办事项 App |

## 阶段二：核心（第3-4周）

| 主题 | 学习内容 | 实践项目 |
|------|----------|----------|
| 布局系统 | Row/Column/Flex/Stack/自定义布局 | 响应式仪表盘 |
| 状态管理 | Provider/Riverpod | 天气 App（含位置、网络） |

## 阶段三：进阶（第5-6周）

| 主题 | 学习内容 | 实践项目 |
|------|----------|----------|
| 原生通信 | MethodChannel/Pigeon/FFI | 相机滤镜 App |
| Android 原生 | Kotlin + Jetpack Compose | 原生页面嵌入 Flutter |

## 阶段四：架构（第7-8周）

| 主题 | 学习内容 | 实践项目 |
|------|----------|----------|
| 架构模式 | MVVM/MVI/Clean Architecture | 完整电商 App |
| 数据库与后台 | Room/WorkManager | 离线缓存 + 后台同步 |

## 阶段五：工程化（第9-10周）

| 主题 | 学习内容 | 实践项目 |
|------|----------|----------|
| 混合开发 | 原生嵌入 Flutter、性能优化 | 原生 App 增量迁移 |
| 发布监控 | CI/CD/Fastlane/Crashlytics | 自动发布流水线 |

## 推荐资源

- **Flutter 官方文档**: docs.flutter.dev
- **Kotlin 官方文档**: kotlinlang.org
- **Android 开发者**: developer.android.com
- **好书推荐**: 《Flutter 实战》《Android 进阶指北》
