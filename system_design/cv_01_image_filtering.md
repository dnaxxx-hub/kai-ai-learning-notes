## 图像滤波

### 为什么需要滤波

```python
# 原始的图像有噪音 → 先降噪再处理
# 需要找到边缘 → 用边缘检测滤波器
# 需要模糊背景 → 用模糊滤波器
```

### 均值滤波

```python
# 最简单: 用邻域的平均值代替中心像素
# 核: 3×3 全1/9 的矩阵

# 效果: 模糊，去噪音
# 问题: 边缘也被模糊了
```

### 高斯滤波

```python
# 加权平均: 离中心越远，权重越小
# 核: 基于高斯函数生成

# 效果: 比均值滤波更自然
# 参数: σ控制模糊程度
```

### 中值滤波

```python
# 用邻域的中位数代替中心像素
# 效果: 去椒盐噪音特别有效
# 边缘保留比均值好
```

### Sobel边缘检测

```python
# 核心思想: 检测像素值的"突变"
# 水平边缘: 用垂直梯度检测
# 垂直边缘: 用水平梯度检测

# 两个3×3核:
# Gx = [[-1,0,1], [-2,0,2], [-1,0,1]]  # 垂直边缘
# Gy = [[-1,-2,-1], [0,0,0], [1,2,1]]  # 水平边缘

# 最终边缘强度 = sqrt(Gx² + Gy²)
```

## 今日收获
- 图像 = 矩阵/张量（数值到视觉的映射）
- 卷积滤波 = 小核在图像上滑动
- 均值/高斯 = 平滑去噪（但模糊边缘）
- 中值 = 去噪保边
- Sobel = 最基础的边缘检测
