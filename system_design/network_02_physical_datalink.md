# 物理层 + 数据链路层

## 物理层（Layer 1）

**职责**：在物理介质上传输原始比特流。

### 常见物理介质
- **双绞线**（RJ-45网线）：Cat5e(1Gbps) / Cat6(10Gbps) / Cat6a / Cat7
- **光纤**：单模（长距离，激光）/ 多模（短距离，LED）
- **无线**：2.4GHz / 5GHz / 6GHz WiFi
- **同轴电缆**：老式宽带/Cable Modem

### 关键特性
- 定义电压、频率、引脚、线序
- 不关心比特的含义，只负责传输 0 和 1
- 集线器(Hub)是纯物理层设备（已淘汰）

## 数据链路层（Layer 2）

**职责**：将比特组装成帧，提供节点到节点的可靠传输。

### 以太网帧结构

```
┌─────────┬─────────┬──────────┬──────────────┬─────────┐
│ 前导码  │ 目标MAC │ 源MAC   │ 类型/长度    │ 数据    │  FCS  │
│  8字节  │  6字节  │  6字节  │   2字节      │46-1500B │ 4字节 │
└─────────┴─────────┴──────────┴──────────────┴─────────┘
```

- **目标 MAC**: 接收方网卡物理地址
- **源 MAC**: 发送方网卡物理地址
- **类型/长度**: 上层协议类型(0x0800=IPv4, 0x0806=ARP, 0x86DD=IPv6)
- **数据**: 上层IP包(最小46字节,最多1500字节 = MTU)
- **FCS**: 帧校验序列, CRC32 检测传输错误

### MAC 地址

```
格式: XX:XX:XX:XX:XX:XX (6字节, 48位)
例:   00:1A:2B:3C:4D:5E

前3字节 = OUI (厂商ID, 如 00:1A:2B = Intel)
后3字节 = NIC (厂商分配的序列号)

特性:
- 全球唯一（理论上）
- 固化在网卡 ROM 中
- 可通过软件修改（MAC欺骗）

地址类型:
- 单播: 第一个字节最低位=0, 发往单台设备
- 多播: 第一个字节最低位=1, 发往一组设备
- 广播: FF:FF:FF:FF:FF:FF, 发往所有设备
```

### ARP 协议（Address Resolution Protocol）

**作用**：已知 IP 地址 → 获取 MAC 地址

```
工作原理:
1. 主机A 广播 ARP请求: "谁的IP是 192.168.1.2?"
2. 主机B 收到后, 发现是自己, 回复单播 ARP响应: "我是, 我的MAC是 AA:BB:CC:DD:EE:FF"
3. 主机A 将 IP-MAC 映射存入 ARP缓存

ARP缓存:
$ arp -a                    # Windows/macOS/Linux 查看
$ ip neigh                  # Linux 专用

ARP报文结构:
┌────────┬──────┬────────┬────────┬──────────┬──────────┐
│ 硬类型 │ 协类型│ 硬长度 │ 协长度 │ 操作类型  │ 发送方  │
│   2B   │  2B  │  1B   │  1B   │   2B    │ MAC+IP  │
└────────┴──────┴────────┴────────┴──────────┴──────────┘
操作类型: 1=请求, 2=响应
```

**ARP欺骗攻击**：攻击者伪造ARP响应, 将目标IP映射到攻击者MAC, 实现中间人攻击。

### 交换机 vs 集线器

| 特性 | 集线器(Hub) | 交换机(Switch) |
|------|------------|--------------|
| 工作层级 | 物理层 | 数据链路层 |
| 转发方式 | 广播所有端口 | 根据MAC表精确转发 |
| 带宽 | 共享（所有端口平分） | 独享（每个端口独立） |
| 冲突域 | 一个(所有端口共享) | 每端口一个 |
| 当前状态 | 已淘汰 | 广泛使用 |

**交换机工作原理**：
1. 收到帧, 记录源MAC对应端口到MAC地址表
2. 查目标MAC → 找到对应端口 → 单播转发
3. 目标MAC未知 → 广播洪泛(Flooding)
4. 广播帧 → 广播到所有端口（除接收端口）

### VLAN（虚拟局域网）

**为什么需要VLAN？**
- 广播域太大 → 广播风暴
- 安全和隔离需求

**工作原理**：在以太网帧中插入VLAN Tag (802.1Q标准)

```
标准以太网帧: [MAC][MAC][类型][数据][FCS]
带VLAN的帧:   [MAC][MAC][VLAN Tag][类型][数据][FCS]
                         │
                   ┌─────┴──────┐
                   │ 2字节      │ 2字节    │
                   │ 0x8100     │ PRI+DEI+VID │
                   └────────────┴──────────┘
- VID (VLAN ID): 12位, 1-4094 (0和4095保留)
- Access端口: 连接终端, 打上/剥离VLAN Tag
- Trunk端口: 连接交换机间, 透传多个VLAN
```

### MTU（最大传输单元）

- 标准以太网 MTU = **1500 字节**
- 如果IP包大于MTU → 分片(Fragmentation)
- 路径MTU发现: 发送DF位=1的包探测最小MTU

### 实操命令

```bash
# 查看网卡MAC地址
ip link show                  # Linux
ifconfig                      # macOS
ipconfig /all                 # Windows

# 查看ARP缓存
arp -a                        # 所有平台

# 查看交换机MAC表（需要登录交换机）
show mac address-table        # Cisco
display mac-address           # Huawei

# 查看VLAN配置
show vlan brief               # Cisco
display vlan                  # Huawei

# 测试MTU
ping -M do -s 1472 8.8.8.8    # Linux, 逐步增大s值找出MTU
ping -f -l 1472 8.8.8.8       # Windows
```
