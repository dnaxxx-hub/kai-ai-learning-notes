## 1. 计算几何基础

### 1.1 向量基础

向量是计算几何的核心工具。在二维平面中，向量 $\vec{v} = (x, y)$。

**向量加减法**：
- 加法：$(x_1 + x_2, y_1 + y_2)$
- 减法：$(x_1 - x_2, y_1 - y_2)$ — 向量 $\overrightarrow{AB} = B - A$

### 1.2 点积（Dot Product）

$$\vec{a} \cdot \vec{b} = x_1x_2 + y_1y_2 = |\vec{a}||\vec{b}|\cos\theta$$

**用途**：
- 判断角度：$\vec{a} \cdot \vec{b} > 0$ 表示夹角 < 90°（锐角），= 0 表示直角，< 0 表示钝角
- 投影长度：$\vec{b}$ 在 $\vec{a}$ 上的投影为 $(\vec{a} \cdot \vec{b}) / |\vec{a}|$
- 判断两个向量的方向一致性

### 1.3 叉积（Cross Product）

$$\vec{a} \times \vec{b} = x_1y_2 - x_2y_1 = |\vec{a}||\vec{b}|\sin\theta$$

**用途**（二维叉积返回标量，代表有向面积）：
- **方向判断**：$\vec{a} \times \vec{b} > 0$ 表示 $\vec{b}$ 在 $\vec{a}$ 的逆时针方向（左转）
  - $< 0$ 表示顺时针方向（右转）
  - $= 0$ 表示共线
- **有向面积**：三角形 $\triangle ABC$ 的有向面积为 $\frac{1}{2} \overrightarrow{AB} \times \overrightarrow{AC}$
- **点在直线哪一侧**：核心工具

### 1.4 精度处理（eps）

浮点数比较不能直接用 `==`，需要使用 epsilon：

```python
EPS = 1e-9

def sgn(x):
    """符号函数：正数返回1，负数返回-1，接近0返回0"""
    return 0 if abs(x) < EPS else (1 if x > 0 else -1)
```

**常见比较**：
- `sgn(x) == 0` — x 等于 0
- `sgn(a - b) == 0` — a 等于 b
- `sgn(a - b) > 0` — a > b
- `sgn(cross(a, b))` — 方向判断

## 2. 凸包（Convex Hull）

给定点集，凸包是包含所有点的最小凸多边形。

### 2.1 Graham Scan 算法（极角排序+单调栈）

**步骤**：
1. 找到最下最左的点（y最小，y相同取x最小）作为起点 $P_0$
2. 将其他点按相对于 $P_0$ 的极角排序（极角相同按距离）
3. 用单调栈维护凸包：
   - 将 $P_0$ 和排序后的前两个点入栈
   - 遍历剩余点，检查栈顶两点与新点的转向：
     - 如果是**左转**（逆时针），入栈
     - 如果是**右转**（顺时针）或共线，弹出栈顶，继续检查
4. 栈中即为凸包顶点

**时间复杂度**：$O(n \log n)$（排序的瓶颈）

**关键判断**：对于栈顶 $S_{t-1}$、$S_t$ 和新点 $P$，检查叉积 $\overrightarrow{S_{t-1}S_t} \times \overrightarrow{S_tP}$：
- $> 0$：左转，入栈
- $\le 0$：右转或共线，出栈

### 2.2 Andrew 算法（上下凸壳）

**步骤**：
1. 将所有点按 x 坐标排序（x相同按 y 排序）
2. **下凸壳**：从左到右扫描，用单调栈维护
3. **上凸壳**：从右到左扫描，用单调栈维护
4. 合并下凸壳和上凸壳（去掉首尾重复点）

**优点**：
- 不需要极角排序中 atan2 的精度问题
- 只需求点积/叉积，更稳定
- 对共线点处理更自然

**时间复杂度**：$O(n \log n)$

### 2.3 两种算法对比

| 特性 | Graham Scan | Andrew |
|------|------------|--------|
| 排序方式 | 极角排序 | 按坐标排序 |
| 遍历方式 | 单次扫描 | 两次扫描（上下） |
| 精度 | 极角排序可能有精度问题 | 更稳定 |
| 实现复杂度 | 稍复杂 | 简洁 |

## 3. 旋转卡壳（Rotating Calipers）

**核心思想**：用两条平行线"卡"住凸包，旋转这两条线来测量凸包的各种性质。

### 3.1 凸包直径（最远点对）

**算法**：
1. 先求凸包
2. 从凸包上的第一条边开始，找到离这条边最远的点（对踵点）
3. 枚举所有边，每次移动边时，同时对踵点也沿凸包前进
4. 记录所有边-对踵点距离的最大值

**对踵点推进条件**：
- 对于边 $(P_i, P_{i+1})$ 和对踵点 $P_j$
- 检查 $|(P_{i+1} - P_i) \times (P_{j+1} - P_i)| > |(P_{i+1} - P_i) \times (P_j - P_i)|$
- 如果成立，说明 $P_{j+1}$ 比 $P_j$ 离当前边更远，$j$ 前进

**注意**：凸包直径一定出现在对踵点对之间，共有 $O(n)$ 对对踵点对。

**时间复杂度**：$O(n)$（凸包构建 $O(n \log n)$，旋转卡壳 $O(n)$）

### 3.2 凸包宽度

宽度是凸包的最小宽度，即平行线间的最小距离。
- 也是用旋转卡壳，对每条边求其到最远点的距离
- 取最小值即为凸包宽度

## 4. 最近点对（Closest Pair）

**问题**：给定 $n$ 个点，找出欧几里得距离最近的两个点。

**分治算法** $O(n \log n)$：

1. **预处理**：按 x 坐标排序
2. **分治**：
   - 如果点数 $\le 3$，暴力求解
   - 按 x 坐标中位数分成左右两部分
   - 递归求解左右两半的最小距离 $d_1$ 和 $d_2$
   - 当前最小距离 $d = \min(d_1, d_2)$
3. **合并**：
   - 筛选出 x 坐标与中线距离 $< d$ 的点（带状区域）
   - 将这些点按 y 坐标排序
   - 对带状区域中的每个点，只检查与其 y 坐标差 $< d$ 的后续点（最多 7 个）
   - 更新 $d$

**关键优化**：合并时按 y 排序后，每个点只需检查后续常数个点（通常 ≤ 7），实现 $O(n)$ 的合并。

**时间复杂度**：$O(n \log n)$

**为什么最多检查 7 个点**：在 $d \times 2d$ 的矩形内，最多只能放下 8 个两两距离 ≥ d 的点（抽屉原理）。

## 5. 线段相交（Segment Intersection）

### 5.1 跨立实验（两步骤）

判断两条线段 $AB$ 和 $CD$ 是否相交：

**步骤1：快速排斥实验（范围检查）**
- 如果两线段的包围盒不相交，则不可能相交
- 条件：$\max(A.x, B.x) < \min(C.x, D.x)$ 或反向，或 y 方向类似
- 快速排除不相交的情况

**步骤2：跨立测试（叉积检查）**
- 点 $C$ 和 $D$ 必须分别在 $AB$ 的两侧（或线上）
  - $(B - A) \times (C - A)$ 与 $(B - A) \times (D - A)$ 异号（或为 0）
- 点 $A$ 和 $B$ 必须分别在 $CD$ 的两侧（或线上）
  - $(D - C) \times (A - C)$ 与 $(D - C) \times (B - C)$ 异号（或为 0）

**返回结果**：
- 严格相交：两个叉积都 < 0（异号）
- 端点相交（非严格）：叉积为 0 且点在线上
- 不相交：其他情况

### 5.2 叉积为 0 的情况

当叉积为 0 时，表示点在线段所在的直线上：
- 检查该点是否在线段上（坐标范围判断）
- 如果是，则属于端点相交

## 6. 多边形面积（Shoelace Formula / 鞋带公式）

### 6.1 公式

对于依次排列的 $n$ 个顶点 $(x_0,y_0), (x_1,y_1), ..., (x_{n-1},y_{n-1})$：

$$S = \frac{1}{2} \left| \sum_{i=0}^{n-1} (x_i y_{i+1} - x_{i+1} y_i) \right|$$

其中 $(x_n, y_n) = (x_0, y_0)$。

### 6.2 原理

- 本质上是向量叉积的累加（三角形剖分）
- 每个项 $x_i y_{i+1} - x_{i+1} y_i$ 是相邻两个顶点与原点构成的有向面积的两倍
- 取绝对值保证面积为正

### 6.3 有向面积

去掉绝对值得到有向面积：
- 正数：顶点按逆时针排列
- 负数：顶点按顺时针排列

**用途**：
- 判断多边形顶点顺序
- 计算任意简单多边形的面积

### 6.4 时间复杂度

$O(n)$

## 7. 半平面交（Half-plane Intersection）

**问题**：给定若干半平面（直线的一侧），求它们的交集（通常是一个凸多边形或空集）。

### 7.1 半平面的表示

直线 $Ax + By + C = 0$ 将平面分为两部分：
- $Ax + By + C > 0$：一侧
- $Ax + By + C < 0$：另一侧

更常用的是用**方向向量 + 左侧**表示：
- 通过两点 $(p_1, p_2)$ 确定直线方向，取直线左侧为半平面
- 叉积判断点在直线的哪一侧

### 7.2 算法：极角排序 + 双端队列

**步骤**：
1. **表示半平面**：每条直线用 $(p_1, p_2)$ 表示，$p_1 \to p_2$ 左侧为有效区域
2. **极角排序**：按直线的极角（方向角）排序，极角相同时保留限制更紧的
3. **双端队列**：
   - 用 deque 维护当前有效的半平面
   - 每次加入新半平面时：
     a. 检查队尾两个半平面的交点是否在新半平面内
     b. 检查队首两个半平面的交点是否在新半平面内
     c. 如果不在，弹出队尾/队首
4. **后处理**：
   - 用队首半平面裁剪队尾，用队尾半平面裁剪队首
   - 剩余的交点即为交集多边形顶点

**关键操作**：
- 求两条直线的交点
- 判断点是否在半平面内（叉积的符号）

**时间复杂度**：$O(n \log n)$

### 7.3 注意事项

- 如果交集为空（无解），返回空多边形
- 半平面交的结果可能是凸多边形、线段、点或空集
- 初始时可能需要添加一个足够大的包围框（边界半平面）来限制结果范围

## 8. 常见技巧与陷阱

### 8.1 精度问题
- 始终使用 `sgn()` 函数比较浮点数
- 避免使用 `atan2` 做极角排序（可用 `cross` 的比较器代替）
- 选择合适的 EPS（通常 1e-9 到 1e-12）

### 8.2 边界情况
- **共线点**：凸包算法中是否保留共线点
- **重复点**：去重处理
- **所有点共线**：凸包是线段
- **点数不足**：凸包至少需要 3 个点

### 8.3 整数 vs 浮点数
- 很多几何问题可以用整数运算避免精度问题
- 叉积和点积在整数范围内是精确的
- 涉及距离/角度时必然引入浮点数

### 8.4 方向判断
- 叉积是判断"左转/右转"的核心工具
- 一个点是否在多边形内可以用射线法（偶数次交叉法）
