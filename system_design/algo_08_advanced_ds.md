## 1. 线段树 (Segment Tree)

### 结构
- 完全二叉树，每个节点代表一个区间
- 叶子节点 = 单个元素
- 内部节点 = 子节点聚合（和/最大值/最小值等）

### 操作
| 操作 | 复杂度 |
|------|--------|
| 构建 | O(N) |
| 区间查询 | O(log N) |
| 单点更新 | O(log N) |

### 实现要点
- 数组索引: root=0, left=2*node+1, right=2*node+2
- 区间划分: [l,m), [m,r) 左闭右开
- 递归实现, 4N空间保证安全

## 2. 树状数组 (Fenwick Tree)

### 核心思路
- `lowbit(i) = i & -i` — 取最低位的1
- 节点 `tree[i]` 覆盖区间 `[i-lowbit(i), i)`
- 求前缀和: 累加 tree[i], i -= lowbit(i)
- 单点更新: 更新 tree[i], i += lowbit(i)

### 对比
| 特性 | 线段树 | 树状数组 |
|------|--------|----------|
| 更新 | 单点/区间 | 单点 |
| 查询 | 区间 | 前缀和 |
| 空间 | 4N | N+1 |
| 复杂度 | O(log N) | O(log N) |
| 实现难度 | 中等 | 简单 |

## 3. 带权并查集

在普通并查集基础上, 维护每个节点到根的距离/权重。

### 应用场景
- 相对关系推理 (谁比谁重多少)
- 图染色 (谁和谁同色/异色)
- 集合内部差异化
