## 1. 数位DP (Digit DP)

### 核心思想
数位DP用于解决「统计区间 [L, R] 内满足某条件的数字个数」的问题。核心思路是将数字按数位（十进制的每一位）逐位处理，利用「记忆化」避免重复计算具有相同限制状态的子问题。

### 状态定义
一般形式：`dfs(pos, tight, leading_zero, extra_conditions...)`

- `pos`：当前要处理的数位（从高位到低位）
- `tight`：上界约束标志 —— 前面对齐是否与R一致，0=已自由（后续0-9随意），1=仍受限（不能超过R的当前位）
- `leading_zero`：前导零标志 —— 目前是否还在填充前导零（影响到某些条件判断，如数位和、数字0的计数等）
- `extra_conditions`：根据具体问题添加的附加条件（如是否出现过'49'、数位和、余数等）

### 转移方程
```
def dfs(pos, tight, status):
    if pos == len(digits):
        return 1 if condition_met(status) else 0
    if not tight and dp[pos][status] != -1:
        return dp[pos][status]
    
    limit = digits[pos] if tight else 9
    total = 0
    for d in range(0, limit + 1):
        new_tight = tight and (d == limit)
        total += dfs(pos + 1, new_tight, new_status(d, status))
    
    if not tight:
        dp[pos][status] = total
    return total
```

### 经典问题：统计[L,R]内不含"49"的数字个数
- 状态：`prev` = 前一位数字（用于检测是否出现4后跟9）
- 附加条件：`has_49` 标志是否已出现过49
- 转移：当 `prev == 4 and d == 9` 时标记 `has_49 = True`

### 复杂度分析
- 状态总数：O(位数 × 状态数 × 2(tight)) ≈ O(len × 10 × 2)
- 每次转移枚举 0-9：O(10)
- 总复杂度：O(len × 状态数 × 10) ≈ O(12 × 10 × 10) ≈ O(1200)
- 极快，远小于暴力枚举

## 2. 树形DP (Tree DP)

### 核心思想
在树结构上执行动态规划。通常以 DFS 遍历树，子树的信息递推到父节点。分为自底向上（后序DFS）和自顶向下（换根DP）。

### 2.1 树的最大独立集 (Maximum Independent Set on Tree)
**问题**：在树中选取尽可能多的节点，使得任意两个被选节点不相邻（没有边直接连接）。

**状态定义**：
- `dp[u][0]`：以 u 为根的子树，**不选** u 时的最大独立集大小
- `dp[u][1]`：以 u 为根的子树，**选** u 时的最大独立集大小

**转移方程**：
```
dp[u][0] = sum(max(dp[v][0], dp[v][1]))     // 不选u，子节点可选可不选
dp[u][1] = 1 + sum(dp[v][0])                 // 选u，子节点都不能选
```
答案：`max(dp[root][0], dp[root][1])`

### 2.2 树的直径 (Diameter of Tree)
**问题**：求树中最长路径的长度（路径上的边数）。

**方法**：DP两遍或单次DFS。
- 对每个节点u，记录从u到子树中最远叶子的距离 `down[u]`
- 同时记录经过u的最长路径 = `max(down[v1] + down[v2] + 2)` 即两个最深子树的深度之和
- 全局最大值即为直径

### 复杂度分析
- 每个节点访问一次：O(N)
- 每条边遍历一次：O(N)
- 总复杂度：O(N)

## 3. 状态压缩DP (Bitmask / State Compression DP)

### 核心思想
当状态可以用「集合的子集」表示时，用一个整数的二进制位来代表元素是否被选择。状态总数从 O(n!) 降到 O(n·2ⁿ)。

### 3.1 旅行商问题 (TSP)
**问题**：给定 n 个城市和城市间的距离，求从某个城市出发经过每个城市恰好一次再回到起点的最短路径。

**状态定义**：
- `dp[mask][v]`：已经访问过的城市集合为 `mask`（二进制第i位=1表示已访问），当前在 v 城市的最小距离

**初始状态**：
- `dp[1<<start][start] = 0`，其它为无穷大

**转移方程**：
```
// 从城市 u 走到未访问的城市 v
if not (mask & (1 << v)):
    new_mask = mask | (1 << v)
    dp[new_mask][v] = min(dp[new_mask][v], dp[mask][u] + dist[u][v])
```

**最终答案**：
```
for v in range(n):
    ans = min(ans, dp[(1<<n)-1][v] + dist[v][start])   // 回到起点
```

### 复杂度分析
- 状态数：O(n · 2ⁿ)
- 每次转移检查所有目标城市：O(n)
- 总复杂度：O(n² · 2ⁿ)
- n ≤ 20 时可接受（约 400 × 1e6 ≈ 4亿，实际通常用 n ≤ 16）

## 4. 概率DP (Probability DP)

### 核心思想
状态转移依赖于随机事件的概率。概率DP利用「期望的线性性」和「全概率公式」，通过DP求解期望值或概率。

定义 `dp[state]` 表示从某个状态开始的期望步数或到达目标的概率，然后按状态递推。

### 4.1 赌徒破产问题 (Gambler's Ruin)
**问题**：赌徒初始有 i 元，每次以概率 p 赢1元，以概率 q=1-p 输1元。求赌徒在输光（0元）或赢得 N 元前破产（输光）的概率。

**状态定义**：
- `dp[i]` = 当前有 i 元时最终破产的概率

**边界条件**：
- `dp[0] = 1`（已经破产）
- `dp[N] = 0`（已经达到目标）

**转移方程**（公平游戏 p=q=0.5）：
```
dp[i] = p * dp[i+1] + q * dp[i-1]
=> dp[i] = 0.5 * dp[i+1] + 0.5 * dp[i-1]
=> dp[i] 是等差数列: dp[i] = 1 - i/N
```

**非公平游戏 (p ≠ q)**：
```
dp[i] = p * dp[i+1] + q * dp[i-1]
=> 解递推: dp[i] = ((q/p)^i - (q/p)^N) / (1 - (q/p)^N)
```

### 4.2 期望DP：随机游走期望步数
**问题**：从位置 0 出发，每次等概率向前走1步或2步，求到达或超过位置 N 的期望步数。

**状态定义**：
- `dp[i]` = 从位置 i 到达目标的期望步数

**转移方程**：
```
dp[i] = 1 + 0.5 * dp[min(i+1, N)] + 0.5 * dp[min(i+2, N)]
dp[N] = 0   // 已到达
```

### 复杂度分析
- 状态数：O(N)
- 每个状态转移：O(1)
- 总复杂度：O(N)
- 注意：当状态图有环时（如赌徒问题），需要解线性方程组或使用高斯消元

## 总结对比

| DP类型 | 适用场景 | 状态数 | 时间复杂度 |
|--------|---------|--------|-----------|
| 数位DP | 区间统计 | O(len × 状态) | O(len × 状态 × 10) |
| 树形DP | 树结构问题 | O(N) | O(N) |
| 状态压缩DP | 子集/排列优化 | O(n·2ⁿ) | O(n²·2ⁿ) |
| 概率DP | 随机过程/期望 | O(N) | O(N) |
