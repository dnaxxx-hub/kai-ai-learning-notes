# 编译器实战 04 — 语义分析

## 概述
语义分析确保程序在语义上合法：类型匹配、变量/函数已声明、作用域正确。

## 设计
### 符号表 (SemanticAnalyzer)
- 作用域链：进入 Block 时创建新作用域，退出时销毁
- 记录变量名 → 类型的映射
- 记录函数签名（参数类型 + 返回类型）

### 检查项目
1. **变量引用检查** — 使用前必须已声明
2. **函数定义检查** — 调用前必须已定义（允许递归）
3. **类型兼容性** — 算术运算两侧同类型；条件表达式必须为 bool
4. **return 类型匹配** — 函数返回值的类型与声明一致
5. **赋值类型匹配** — 右侧表达式类型与左侧变量类型一致

### 类型推断
- 整数 + 浮点 → 浮点提升
- 二元运算两侧类型必须兼容
- 比较运算产生 bool 类型

### 输出
遍历 AST，对每个节点派发 `visit_xxx` 方法，返回类型信息。
