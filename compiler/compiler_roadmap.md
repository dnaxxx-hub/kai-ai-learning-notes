# 编译原理 — Phase 4 波次3 学习路线图

> 目标：从上到下理解编译器，不仅能实现一个能用的，还能说出每一层的设计取舍

## 进度

| 课 | 内容 | 状态 |
|----|------|------|
| 1 | 词法分析与正则引擎 | ✅ 完整实现（NFA→DFA→模拟） |

## 路线（6课）

### 1. 词法分析与正则引擎
- 正则表达式 → NFA (Thompson构造)
- NFA → DFA (子集构造)
- DFA最小化
- 手写 Lexer vs auto-generator 的tradeoff
- **产出**：一个能解析JSON/配置文件的mini lexer

### 2. 语法分析与上下文无关文法
- CFG / 推导 / 语法树
- 递归下降解析（手写 Parsing）
- LL(1) / FIRST / FOLLOW
- 消除左递归 / 提取左公因子
- **产出**：表达式解析器（支持优先级 + 括号）

### 3. LR解析与Parser Generator
- LR(0) → SLR(1) → LALR(1) → LR(1)
- shift/reduce 冲突解决
- LR解析表构造
- **产出**：为简单语言写LR parser

### 4. 语义分析与中间表示（IR）
- 抽象语法树（AST） vs 三地址码（TAC/IR）
- 符号表 / 作用域 / 类型检查
- 静态单赋值（SSA）形式
- **产出**：AST → TAC 的转换器

### 5. 代码生成与优化
- 指令选择（树覆盖 / 贪心）
- 寄存器分配（图着色 / 线性扫描）
- 窥孔优化 / 常量折叠 / 死代码消除
- 循环优化（LICM / 强度削减）
- **产出**：一个能生成x86-like汇编的简单后端

### 6. 实战：Tiny Compiler 完整链
- 从源码 → 词法 → 语法 → IR → 优化 → 汇编
- 参考 nand2tetris / lcc / wcc
- **产出**：一个能编译C子集的mini compiler
