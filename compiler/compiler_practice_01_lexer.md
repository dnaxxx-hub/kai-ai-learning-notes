# 编译器实战 01 — 词法分析器 (Lexer)

## 概述
词法分析器将 MiniLang 源代码字符串拆分为 Token 流，是编译流程的第一步。

## 设计
### Token 类型
- 关键字: `func`, `var`, `if`, `else`, `while`, `return`, `true`, `false`, `print`
- 类型: `int`, `float`, `bool`, `string`
- 字面量: NUMBER, STRING
- 标识符: IDENTIFIER
- 操作符与分隔符: `+`, `-`, `*`, `/`, `=`, `==`, `!=`, `<`, `>`, `<=`, `>=`, `&&`, `||`, `!`, `(`, `)`, `{`, `}`, `:`, `;`, `,`, `->`

### 状态机
逐个字符遍历，按以下规则分组：
1. 空白符跳过
2. `//` 到行尾为注释，跳过
3. 字母/下划线开头 → 标识符或关键字
4. 数字开头 → 数值字面量
5. `"` → 字符串字面量
6. 其他 → 操作符/分隔符（支持多字符操作符如 `==`, `->`）

### Token 定义
```python
Token = namedtuple('Token', ['type', 'value', 'line', 'column'])
```
