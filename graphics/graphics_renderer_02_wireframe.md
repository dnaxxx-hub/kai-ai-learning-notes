> 从零实现 3D 软渲染器系列 · 第二篇

## 1. Bresenham 画线算法

在像素网格上画出任意斜率的线段，只使用整数运算。

### 核心思想
- 从起点 (x0,y0) 到终点 (x1,y1)
- 每一行/列只画一个像素
- 根据误差项决定走向

### 算法步骤（0<斜率<1）
```
dx = x1-x0, dy = y1-y0
error = 2*dy - dx
for x = x0 to x1:
    plot(x, y)
    if error > 0:
        y += 1
        error -= 2*dx
    error += 2*dy
```

### 扩展处理
- 斜率 > 1：交换 x/y 角色
- 负斜率：对称处理

## 2. 线框立方体

### 2.1 立方体顶点定义
8 个顶点在局部坐标系 [-1,1]³：
```
// 前面 (z=1)  后面 (z=-1)
v0: (-1,-1, 1)  v4: (-1,-1,-1)
v1: ( 1,-1, 1)  v5: ( 1,-1,-1)
v2: ( 1, 1, 1)  v6: ( 1, 1,-1)
v3: (-1, 1, 1)  v7: (-1, 1,-1)
```

### 2.2 边定义
12 条边形成的 6 个面：
```
front: (0-1, 1-2, 2-3, 3-0)
back:  (4-5, 5-6, 6-7, 7-4)
edges: (0-4, 1-5, 2-6, 3-7)
```

### 2.3 渲染管线
```
for each 顶点:
    局部坐标 → 模型矩阵(M) → 世界坐标
    世界坐标 → 视图矩阵(V) → 相机坐标
    相机坐标 → 投影矩阵(P) → 裁剪坐标
    裁剪齐次除法 → NDC [-1,1]³
    视口变换 → 屏幕像素坐标

for each 边:
    画线 (x0,y0) → (x1,y1)
```

## 3. 三角形光栅化

### 3.1 边界函数法（Barycentric）
给定三角形 (A,B,C) 和点 P，求解重心坐标 (α,β,γ)：
```
P = α*A + β*B + γ*C
α + β + γ = 1
```

点 P 在三角形内 ⇔ α≥0, β≥0, γ≥0

### 3.2 边界函数计算
```
f_AB(P) = (P-A) × (B-A) 的 z 分量
...
β = f_AC(P) / f_AC(B)
γ = f_AB(P) / f_AB(C)
α = 1 - β - γ
```

### 3.3 扫描线填充
遍历三角形的包围盒(AABB)矩形：
```
xmin = floor(min(A.x,B.x,C.x))
xmax = ceil(max(A.x,B.x,C.x))
ymin = floor(min(A.y,B.y,C.y))
ymax = ceil(max(A.y,B.y,C.y))

for y = ymin to ymax:
    for x = xmin to xmax:
        if 点在三角形内:
            写入像素(x, y)
```

## 4. 背面剔除

### 法线计算
三角形 (v0,v1,v2) 的法线：
```
edge1 = v1 - v0
edge2 = v2 - v0
normal = normalize(cross(edge1, edge2))
```

### 剔除规则
相机方向 `view_dir`（从三角形指向相机）：
```
if dot(normal, view_dir) < 0:
    背面 → 剔除
```

**优化**：在屏幕空间做 → 检查三角形绕序
```
area = (v1.x-v0.x)*(v2.y-v0.y) - (v1.y-v0.y)*(v2.x-v0.x)
if area < 0: 背面 → 剔除
```

## 5. 深度缓冲 (Z-buffer)

### 是什么
- 一个与帧缓冲大小相同的 2D 数组
- 每个像素存储最近的深度值（z）

### 工作流程
```
初始化 z-buffer 为无穷大(1.0)
for each 三角形:
    for each 像素 (x,y):
        插值得到该像素的深度 z
        if z < z-buffer[x][y]:
            写入颜色
            更新 z-buffer[x][y] = z
```

### 深度插值
使用重心坐标 (α,β,γ) 插值深度：
```
z = α*z0 + β*z1 + γ*z2
```

**透视校正**：真正的 3D 线性插值需要在透视除法前进行：
```
z_recip = 1/z
1/z = α*(1/z0) + β*(1/z1) + γ*(1/z2)
```

## 6. 实现流程总结

```
for each frame:
    清空颜色缓冲 + 深度缓冲
    
    for each 三角形:
        顶点变换 (M → V → P → 视口)
        
        if 背面剔除:
            continue
        
        计算三角形包围盒
        
        for each 像素 in 包围盒:
            if 不在三角形内: continue
            
            插值深度 z
            if z-buffer 测试失败: continue
            
            写入颜色到帧缓冲
    
    帧缓冲 → PIL Image → 保存 PNG
```
