# 软渲染器实现总结

> 从零实现 Python 3D 软渲染器 · 代码实践篇

## 概述

在一周的理论学习之后，用 Python + Pillow 从零实现了一个完整的 3D 软渲染器。代码文件：
`code/soft_renderer.py`（单文件，约 420 行）

## 实现内容

### 1. 数学库 — Vec3 / Mat4

- **Vec3**：向量加减、点积/叉积、归一化、标量乘法
- **Mat4**：4×4 矩阵乘法、平移/旋转/缩放、透视投影矩阵、视口变换
- 齐次坐标处理：`Mat4 * Vec3` 自动做透视除法

### 2. Bresenham 画线算法

- 整数运算画线，处理 8 个方向
- 用于渲染立方体线框

### 3. 三角形光栅化

- **边界函数法**（Edge Function）计算重心坐标
- 对包围盒中的每个像素做测试
- **背面剔除**：根据三角形在屏幕空间的缠绕顺序（叉积面积 < 0 剔除）

### 4. Z-buffer 深度缓冲

- Z 值按重心坐标线性插值
- 正确处理三角形前后遮挡关系

### 5. 光照

- **兰伯特漫反射**：`diffuse = max(0, N·L)`
- **Blinn-Phong 高光**：半程向量 `H = (L+V).normalized()`，`spec = max(0, N·H)^32`

### 6. 纹理映射

- 每个三角形顶点固定 UV 坐标
- 重心坐标插值 UV
- 棋盘格纹理作为简单纹理生成示例

## 遇到的坑

1. **变量名冲突**：循环中使用 `w` 作为重心坐标，与图片宽度 `img.size[0]` 的变量名 `w` 冲突，导致 `zbuf[idx]` 索引为 float → 修复为 `img_w`
2. **`img.size` 返回 tuple**：`img.size[0]` 是 int，但之前用 `img.size` 直接赋值不够明确
3. **透视投影参数**：`near=0.1, far=10` 配合 `translate(0,0,-3)` 才能看到完整立方体
