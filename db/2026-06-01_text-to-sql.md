# Text-to-SQL 学习笔记

> 日期: 2026-06-01 | 技能: text-to-sql v1.0.1

## 核心逻辑

自然语言 → SQL查询的翻译桥接。核心流程：

1. **确认Schema** — 必须知道表名+列名+类型，绝不猜测
2. **意图→SQL子句映射** — 自然语言模式匹配到SQL子句
3. **JOIN处理** — 多表查询识别外键关系
4. **验证** — 列存在性、别名、JOIN条件、GROUP BY完整性

## 关键规则

| 禁止 | 必须 |
|------|------|
| 不猜测表名列名 | 用别名限定列引用（`t.column`） |
| 不用SELECT * | 请求schema后再写 |
| 不忽略GROUP BY | 给出查询+一句中文解释 |

## 对我自己的价值

- 这个技能的逻辑我已经天然具备了（我在做量化分析时经常写SQL风格的数据查询）
- 关键学习点：**需求确认先行** — 在写代码前先确认schema，这个习惯可以应用到其他编程场景

## 与已有知识的关系

- 和database-designer互补：一个写查询，一个设计表
- 和量化系统关系：ETF回测数据其实就是需要text-to-sql的场景
