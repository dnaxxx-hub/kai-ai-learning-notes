| 编号 | 主题 | 定位 | 前置 |

| 24 | 现代存储引擎 | 存储层底层原理 | B-Tree 基础 |

## 推荐学习路径

### 路径 A: 分布式数据库方向 (DBA / 后端架构)
```
17 → 18 → 19 → 20 → 23 → 24
```
侧重: 分布式理论基础 → NewSQL 架构认知 → 存储原理

### 路径 B: SQL 优化 & DB 运维方向
```
21 → 22 → 23 (热点部分) → 24
```
侧重: SQL 技能 → 调优实战 → 存储引擎理解

### 路径 C: 全面碾压 (全栈 DB 认知)
```
17 → 18 → 21 → 19 → 20 → 24 → 23 → 22
```
先扫清分布式理论，再搞 SQL 优化，然后深入 NewSQL 架构，最后用调优收尾
